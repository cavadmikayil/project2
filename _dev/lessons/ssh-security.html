{{i:lock-keyhole}} 2. SSH Konfiqurasiyası

SSH üçün RSA açarı lazımdır, açarı yaratmaq üçün isə cihazın defolt olmayan hostname-i və domain adı olmalıdır.

  1. Hostname və ip domain-name təyin edin.

  2. RSA açarı yaradın (ən azı 1024, tövsiyə 2048 bit) — SSH v2 üçün 768 bitdən böyük açar lazımdır.

  3. Lokal istifadəçi yaradın.

  4. VTY xətlərində lokal girişi və yalnız SSH-ı aktivləşdirin.

Router(config)# hostname R1
R1(config)# ip domain-name kollec.local
R1(config)# crypto key generate rsa modulus 2048
R1(config)# ip ssh version 2
R1(config)# username admin privilege 15 algorithm-type scrypt secret Guclu!Parol2026
R1(config)# line vty 0 15
R1(config-line)# login local
R1(config-line)# transport input ssh
R1(config-line)# exec-timeout 10 0

Qoşulmaq: ssh -l admin 192.168.1.1. transport input ssh Telnet-i tamamilə bağlayır; exec-timeout 10 dəqiqə fəaliyyətsizlikdən sonra sessiyanı bağlayır.

{{i:shield-check}} 3. Cihazın Möhkəmləndirilməsi

R1(config)# enable algorithm-type scrypt secret Enable!Parol2026
R1(config)# service password-encryption
R1(config)# security passwords min-length 10
R1(config)# login block-for 120 attempts 3 within 60
R1(config)# banner motd # Yalniz icazeli istifadeciler! Butun fealiyyet qeyde alinir. #
R1(config)# line console 0
R1(config-line)# login local
R1(config-line)# exec-timeout 5 0
R1(config)# no ip http server
R1(config)# no cdp run

Güclü enable parolu, qalan parolların gizlədilməsi, minimum uzunluq, 60 saniyədə 3 uğursuz cəhddən sonra 120 saniyəlik bloklama, xəbərdarlıq banneri, konsolun qorunması və lazımsız xidmətlərin söndürülməsi (CDP-ni yalnız etibarsız portlarda söndürmək də olar).

R1(config)# access-list 10 remark ADMIN-SEBEKESI
R1(config)# access-list 10 permit 192.168.99.0 0.0.0.255
R1(config)# line vty 0 15
R1(config-line)# access-class 10 in

SSH ilə yalnız idarəetmə şəbəkəsindən (192.168.99.0/24) qoşulmağa icazə verir. VTY xətlərinə ACL access-group ilə yox, access-class ilə tətbiq olunur.
