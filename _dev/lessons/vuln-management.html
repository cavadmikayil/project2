{{i:scan-search}} Giriş: Yamanmamış Zəiflik — Açıq Qapıdır

Hər gün yeni zəifliklər dərc olunur. Hücumçular açıq zəiflikləri avtomatlaşdırılmış alətlərlə internetdə axtarır — bəzən dərcdən bir neçə gün sonra. Vulnerability management — zəiflikləri davamlı tapmaq, qiymətləndirmək, aradan qaldırmaq və bunu ölçmək prosesidir.

{{i:book-open}} 1. CVE, CVSS, EPSS, KEV

TerminMənası
CVEHər ictimai zəifliyin unikal ID-si: CVE-2024-3400
CVSS0–10 texniki ciddilik balı: 9.0+ Critical, 7.0–8.9 High, 4.0–6.9 Medium
EPSSYaxın 30 gündə istismar olunma ehtimalı (0–100%)
CISA KEVReal hücumlarda artıq istismar olunduğu təsdiqlənmiş zəifliklər siyahısı
Zero-dayYaması hələ olmayan və ya ictimai məlum olmayan zəiflik
{{i:lightbulb}}

CVSS 9.8 olan, amma daxili, izolə edilmiş sistemdəki zəiflik ilə CVSS 7.5 olan, internetə açıq və KEV-də olan zəiflikdən hansı daha təcilidir? Çox vaxt ikincisi. Yalnız CVSS-ə baxmaq kifayət deyil.

{{i:repeat}} 2. Zəiflik İdarəetmə Dövrü

  1. Asset inventory: bilmədiyiniz cihazı qoruya bilməzsiniz — serverlər, şəbəkə cihazları, bulud resursları, proqramlar.

  2. Kəşf: müntəzəm skan (həftəlik/aylıq), agent əsaslı yoxlama, vendor bildirişləri.

  3. Qiymətləndirmə: ciddilik + istismar ehtimalı + aktivin əhəmiyyəti.

  4. Aradan qaldırma: yama, konfiqurasiya dəyişikliyi və ya müvəqqəti kompensasiya tədbiri (WAF qaydası, portu bağlamaq).

  5. Yoxlama: yenidən skan — həqiqətən düzəldilib?

  6. Hesabat və metrikalar.

{{i:radar}} 3. Skan Alətləri (Öz Şəbəkənizdə)

AlətNöv
NmapAktiv host və açıq port kəşfi, xidmət versiyaları
OpenVAS / GreenboneAçıq mənbə zəiflik skaneri
Nessus, Qualys, Rapid7Kommersiya zəiflik idarəetmə platformaları
Microsoft Defender Vulnerability ManagementAgent əsaslı — Windows proqram zəiflikləri
TrivyKonteyner image-ları və IaC faylları
 
# Öz serverlərinizin açıq portları və xidmət versiyaları
nmap -sV -p- 10.0.0.10
nmap -sV --top-ports 1000 10.0.0.0/24 -oN inventory-scan.txt

# Konteyner image-ında məlum zəifliklər
trivy image nginx:1.27

Skanı yalnız sizə aid və ya yazılı icazə verilmiş şəbəkələrdə aparın; istehsalat sistemlərində skan vaxtını komandalarla razılaşdırın. Authenticated (credential ilə) skan quraşdırılmış proqram versiyalarını görür və daha dəqiqdir.

{{i:shield}} Kompensasiya tədbiri

Yama dərhal mümkün deyilsə: portu bağlamaq, funksiyanı söndürmək, WAF qaydası, seqmentasiya.
