{{i:workflow}} Giriş: Cavab Verməkdən Hərəkət Etməyə

Adi chatbot mətn qaytarır. AI agent isə məqsədə çatmaq üçün addımları özü planlaşdırır və alətlərdən istifadə edir: fayl oxuyur, əmr işlədir, API çağırır, nəticəyə baxıb növbəti addımı seçir. Bu, IT avtomatlaşdırmasında böyük imkan və eyni zamanda yeni risk deməkdir.

{{i:repeat}} 1. Agent Dövrü

Məqsəd: "web01-də disk niyə dolub, yoxla və hesabat yaz"
   │
   ▼
┌──────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 1. Düşün /   │ ─► │ 2. Alət çağır     │ ─► │ 3. Nəticəni gör   │
│    planla    │    │  (df -h, du ...)  │    │  (müşahidə)       │
└──────────────┘    └──────────────────┘    └────────┬─────────┘
        ▲                                             │
        └────────── məqsədə çatılmayıbsa ◄────────────┘
   │
   ▼  məqsədə çatıldı → yekun hesabat

Agent hər addımda LLM-dən "növbəti hərəkət nədir?" soruşur, alətin nəticəsini kontekstə əlavə edir və dövr tapşırıq bitənə və ya limitə çatana qədər davam edir.

{{i:wrench}} 2. Alətlər (Tool / Function Calling)

Model aləti özü icra etmir: o, "bu aləti bu parametrlərlə çağırmaq istəyirəm" deyə strukturlaşdırılmış sorğu qaytarır, sizin proqramınız aləti icra edib nəticəni geri göndərir.

{
  "name": "get_disk_usage",
  "description": "Serverdə disk bölmələrinin istifadəsini qaytarır (yalnız oxuma).",
  "input_schema": {
    "type": "object",
    "properties": {
      "hostname": {"type": "string", "description": "Serverin adı, məs. web01"}
    },
    "required": ["hostname"]
  }
}

Alətin təsviri modelin onu nə vaxt və necə istifadə edəcəyini müəyyən edir — aydın ad, izah və parametr sxemi vacibdir. Oxuyan (read-only) alətləri dəyişən (write) alətlərdən ayırın.

{{i:plug-zap}} 3. Model Context Protocol (MCP)

MCP — AI tətbiqlərinin xarici alət və məlumat mənbələrinə standart üsulla qoşulması üçün açıq protokoldur. Bir dəfə yazılmış MCP server (məs. ticket sistemi, monitorinq, Git) MCP-ni dəstəkləyən müxtəlif AI klientlərində istifadə oluna bilər.

{{i:app-window}} MCP klient

AI tətbiqi (desktop assistent, IDE, agent).

{{i:server}} MCP server

Alətləri və resursları təqdim edir: "ticket-ləri axtar", "Grafana panelini oxu".

{{i:shield-alert}} Təhlükəsizlik

Hər MCP server agentə yeni imkan verir — yalnız etibarlı mənbələrdən, minimal icazə ilə qoşun.

{{i:shield-check}} 5. Agentlərə Nəzarət

{{i:user-check}}

Human-in-the-loop: dəyişiklik edən hərəkətlər (restart, silmə, firewall qaydası) insan təsdiqi ilə.

{{i:lock-keyhole}}

Minimal icazə: agentin hesabı yalnız lazım olan sistemlərə və əmrlərə çıxış əldə edir.

{{i:flask-conical}}

Sandbox: əvvəlcə test mühitində; istehsalata tədricən.

{{i:timer}}

Limitlər: maksimum addım sayı, vaxt və xərc limiti — sonsuz dövrün qarşısını alır.

{{i:scroll-text}}

Audit log: agentin hər düşüncəsi, alət çağırışı və nəticəsi qeyd olunur.

{{i:shield-alert}}

Prompt injection: agentin oxuduğu email, veb səhifə və ya ticket içindəki "təlimatlar" onu yoldan çıxara bilər — xarici məzmun əmr deyil, məlumatdır.
