{{i:list-filter}} Giriş: Tıxac Zamanı Nə Baş Verir?

İşarələnmiş (marking) trafik özü-özlüyündə heç nəyi sürətləndirmir. Fayda çıxış interfeysində gəlir: link dolanda paketlər növbələrə (queue) düşür və scheduler hansı növbədən nə qədər göndəriləcəyinə qərar verir. Tıxac yoxdursa, queuing mexanizmləri demək olar ki, işə düşmür.

{{i:zap}} 2. LLQ (Low Latency Queuing)

{{i:play}}

Priority növbə: səs paketləri dərhal göndərilir — gecikmə və jitter minimal olur.

{{i:ban}}

Daxili policer: priority sinfi ayrılmış limiti keçərsə artıq hissə atılır — digər siniflər ac qalmır.

{{i:gauge}}

Qalan siniflər: bandwidth və ya bandwidth percent ilə minimum pay alır.

{{i:scale}} 3. Shaping və Policing

Hər ikisi trafiki müəyyən sürətlə (CIR) məhdudlaşdırır, amma fərqli üsulla:

{{i:lightbulb}}

Nümunə: ofisin 1 Gbps portu var, amma provayder yalnız 200 Mbps satıb və artığını policing ilə atır. Routerdə 200 Mbps-ə shaping qurulmasa, TCP paketləri provayderdə itəcək; shaping ilə isə itki routerin öz növbələrində, QoS qaydalarına uyğun idarə olunur.

{{i:triangle-alert}} 4. Tail Drop və WRED

{{i:circle-x}} Tail drop

Növbə dolanda gələn bütün paketlər atılır. Bütün TCP axınları eyni anda sürəti azaldıb eyni anda artırır — TCP global synchronization — link növbə ilə boş və tıxanmış olur.

{{i:circle-check}} RED / WRED

Növbə dolmağa başlayanda paketləri təsadüfi və tədricən atır: yalnız bəzi TCP axınları yavaşlayır. WRED (Weighted) DSCP-yə baxır — atılma prioriteti yüksək olan (məs. AF13) daha əvvəl atılır.

{{i:terminal}} 5. Praktiki Əmrlər

R1(config)# class-map match-any VOICE
R1(config-cmap)# match dscp ef
R1(config)# class-map match-any BUSINESS
R1(config-cmap)# match dscp af31 af21

R1(config)# policy-map WAN-OUT
R1(config-pmap)# class VOICE
R1(config-pmap-c)# priority percent 20
R1(config-pmap)# class BUSINESS
R1(config-pmap-c)# bandwidth percent 40
R1(config-pmap-c)# random-detect dscp-based
R1(config-pmap)# class class-default
R1(config-pmap-c)# fair-queue

R1(config)# interface GigabitEthernet0/1
R1(config-if)# service-policy output WAN-OUT

Səsə linkin 20%-i qədər ciddi prioritet, biznes tətbiqlərinə minimum 40% və DSCP əsaslı WRED, qalan trafik ədalətli növbələmə ilə.

R1(config)# policy-map SHAPE-200M
R1(config-pmap)# class class-default
R1(config-pmap-c)# shape average 200000000
R1(config-pmap-c)# service-policy WAN-OUT

R1(config)# interface GigabitEthernet0/1
R1(config-if)# no service-policy output WAN-OUT
R1(config-if)# service-policy output SHAPE-200M

Bütün trafik 200 Mbps-ə shaping edilir və yaranan növbə daxilində WAN-OUT (LLQ) siyasəti tətbiq olunur — iç-içə (hierarchical) policy.

R1(config)# policy-map LIMIT-GUEST
R1(config-pmap)# class class-default
R1(config-pmap-c)# police cir 10000000 conform-action transmit exceed-action drop

R1(config)# interface GigabitEthernet0/2
R1(config-if)# service-policy input LIMIT-GUEST

R1# show policy-map interface GigabitEthernet0/2

Qonaq şəbəkəsinin gələn trafikini 10 Mbps-lə məhdudlaşdırır: limit daxilində olan ötürülür, artığı atılır. Sonuncu əmr conformed/exceeded sayğaclarını göstərir.
