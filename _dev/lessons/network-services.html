{{i:activity}} Giriş: Şəbəkəni İzləmək

Şəbəkəni idarə etmək üçün cihazların eyni vaxtı göstərməsi (NTP), baş verən hadisələrin mərkəzi yerdə qeydə alınması (Syslog) və vəziyyətin monitorinqi (SNMP) vacibdir. Vaxt səhvdirsə, loglardakı hadisələri müqayisə etmək və problemin səbəbini tapmaq demək olar ki, mümkün olmur.

{{i:clock}} NTP

UDP 123 — vaxt sinxronizasiyası.

{{i:scroll-text}} Syslog

UDP 514 — hadisə mesajlarının serverə göndərilməsi.

{{i:chart-column}} SNMP

UDP 161 (sorğular), UDP 162 (trap-lar) — monitorinq.

{{i:clock}} 1. NTP (Network Time Protocol)

NTP-də stratum vaxt mənbəyinə olan məsafəni göstərir: stratum 0 — atom saatı/GPS, stratum 1 — ona birbaşa qoşulmuş server, hər növbəti səviyyə +1. Maksimum 15; 16 "sinxron deyil" deməkdir. 

R1(config)# clock timezone AZT 4
R1(config)# ntp server 192.168.1.10 prefer
R1(config)# ntp server 192.168.1.11
R1(config)# ntp update-calendar
R1(config)# service timestamps log datetime msec localtime

Saat qurşağını (UTC+4) təyin edir, iki NTP server göstərir (birincisi üstün), aparat saatını yeniləyir və log mesajlarına millisaniyəli tarix əlavə edir.

R1(config)# ntp master 3

SW1(config)# ntp server 10.0.0.1

İnternetə çıxış olmayan laboratoriyada R1 öz saatına əsaslanan stratum 3 NTP server olur; switch-lər ondan sinxronlaşır.

{{i:lightbulb}}

Yadda saxlamaq üçün: "Every Awesome Cisco Engineer Will Need Ice cream Daily". Səviyyə təyin etdikdə həmin səviyyə və ondan daha ciddi (kiçik nömrəli) mesajlar göndərilir.

R1(config)# logging host 192.168.1.20
R1(config)# logging trap warnings
R1(config)# logging buffered 16384 informational
R1(config)# logging console critical
R1# terminal monitor

0–4 səviyyəli mesajları syslog serverə göndərir, 0–6-nı RAM buferində saxlayır, konsola yalnız 0–2-ni çıxarır. SSH sessiyasında logları görmək üçün terminal monitor lazımdır. Mesaj formatı: %FACILITY-SEVERITY-MNEMONIC.

{{i:chart-column}} 3. SNMP

{{i:monitor}} Manager (NMS)

Monitorinq serveri — cihazlara sorğu göndərir (Get/Set) və trap-ları qəbul edir.

{{i:cpu}} Agent

Cihazdakı proqram — MIB-dəki dəyərləri (OID) təqdim edir, hadisə olanda trap göndərir.

{{i:boxes}} MIB / OID

Monitorinq olunan dəyişənlərin iyerarxik bazası (məs. interfeys trafiki, CPU yükü).

VersiyaTəhlükəsizlikQiymətləndirmə
SNMPv1Açıq mətnli community stringKöhnəlib
SNMPv2cAçıq mətnli community string; bulk sorğularYalnız etibarlı şəbəkədə
SNMPv3İstifadəçi əsaslı autentifikasiya + şifrələmə (authPriv)Tövsiyə olunur
 
R1(config)# access-list 20 permit 192.168.1.30
R1(config)# snmp-server community Monitor2026 RO 20
R1(config)# snmp-server location Bina-A-Server-otagi
R1(config)# snmp-server contact admin@kollec.local
R1(config)# snmp-server enable traps
R1(config)# snmp-server host 192.168.1.30 version 2c Monitor2026

Yalnız NMS serverinə (192.168.1.30) read-only icazə verir və trap-ları ona göndərir. Heç vaxt "public"/"private" kimi defolt community istifadə etməyin.

R1(config)# snmp-server group ADMINS v3 priv
R1(config)# snmp-server user monitor ADMINS v3 auth sha Auth!Parol2026 priv aes 128 Priv!Parol2026
R1(config)# snmp-server host 192.168.1.30 version 3 priv monitor

authPriv səviyyəli qrup, SHA ilə autentifikasiya və AES-128 ilə şifrələnən istifadəçi yaradır.
