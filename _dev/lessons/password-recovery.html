{{i:key-square}} Giriş: Parolu Unutduq — İndi Nə?

Keçmiş administrator getdi, enable secret heç kimdə yoxdur. Cihazı fabrik vəziyyətinə qaytarsaq, bütün konfiqurasiya itəcək. Parol bərpası prosedurunda cihaz konfiqurasiyanı oxumadan yüklənir, biz daxil olub konfiqurasiyanı əl ilə yükləyir və yalnız parolu dəyişirik.

{{i:lock-keyhole}}

Prosedur yalnız konsol kabeli ilə və cihazın yanında işləyir — uzaqdan etmək mümkün deyil. Buna görə fiziki təhlükəsizlik (kilidli otaq, rack) parol qədər vacibdir.

{{i:circle-power}} 1. Router-in Yüklənmə Ardıcıllığı

  1. POST — ROM-dakı proqram CPU, yaddaş və interfeysləri yoxlayır.

  2. Bootstrap — ROM-dan yüklənir və config register-ə baxaraq IOS-u harada axtaracağına qərar verir.

  3. IOS-un tapılması — boot system əmrləri, sonra flash-dakı ilk etibarlı fayl, sonra TFTP. Heç biri tapılmasa cihaz ROMMON rejiminə düşür.

  4. IOS RAM-a açılır və işə düşür.

  5. Konfiqurasiya — NVRAM-dakı startup-config running-config-ə köçürülür. Yoxdursa (və ya register bunu əmr edirsə), cihaz setup dialoqu ilə açılır.

{{i:hash}} 2. Konfiqurasiya Registri

16 bitlik dəyər, 16-lıq say sistemində yazılır. Cihazın necə yüklənəcəyini idarə edir.

DəyərMənası
0x2102Standart: IOS flash-dan yüklənir, startup-config oxunur, konsol 9600 bod
0x2142IOS yüklənir, amma NVRAM-dakı startup-config nəzərə alınmır (6-cı bit) — parol bərpası üçün
0x2100Həmişə ROMMON rejiminə yüklənir
0x2101ROM-dakı məhdud boot image ilə yüklənir
 
R1# show version | include register
Configuration register is 0x2142

R1(config)# config-register 0x2102
R1# show version | include register
Configuration register is 0x2142 (will be 0x2102 at next reload)

Dəyişiklik yalnız növbəti yenidən yüklənmədə qüvvəyə minir.

{{i:router}} 3. Router-də Parol Bərpası

  1. Konsola qoşulun, cihazı söndürüb yandırın və ilk 60 saniyədə Break siqnalı göndərin (PuTTY: Ctrl+Break) — cihaz rommon 1 > rejiminə düşür.

  2. confreg 0x2142 və reset — cihaz konfiqurasiyasız açılır (setup dialoquna "no" deyin).

  3. enable — parol soruşulmur. copy startup-config running-config ilə köhnə konfiqurasiyanı yükləyin. Tərsinə köçürməyin! Əks halda boş konfiqurasiya əsl konfiqurasiyanın üstünə yazılar.

  4. Yeni enable secret və lazım olsa istifadəçi parollarını təyin edin.

  5. Register-i 0x2102-yə qaytarın, interfeysləri yoxlayın (no shutdown lazım ola bilər) və copy running-config startup-config.

rommon 1 > confreg 0x2142
rommon 2 > reset

Would you like to enter the initial configuration dialog? [yes/no]: no
Router> enable
Router# copy startup-config running-config
R1# configure terminal
R1(config)# enable secret YeniParol!2026
R1(config)# username admin privilege 15 algorithm-type scrypt secret YeniParol!2026
R1(config)# config-register 0x2102
R1(config)# interface range GigabitEthernet0/0 - 1
R1(config-if-range)# no shutdown
R1(config-if-range)# end
R1# copy running-config startup-config
R1# reload

Konfiqurasiya əl ilə köçürüləndə interfeyslər çox vaxt "administratively down" vəziyyətində qalır — show ip interface brief ilə yoxlayın.

{{i:network}} 4. Catalyst Switch-də Parol Bərpası

Switch-lərdə config register əvəzinə konfiqurasiya faylının adı müvəqqəti dəyişdirilir.

! Qida kabelini çıxarın, MODE düyməsini basıb saxlayaraq yenidən taxın,
! SYST LED-i yanıb-sönməyi dayandırana qədər saxlayın.
switch: flash_init
switch: dir flash:
switch: rename flash:config.text flash:config.old
switch: boot

Switch> enable
Switch# rename flash:config.old flash:config.text
Switch# copy flash:config.text system:running-config
SW1# configure terminal
SW1(config)# enable secret YeniParol!2026
SW1(config)# end
SW1# copy running-config startup-config

Switch config.text faylını tapmadığı üçün boş konfiqurasiya ilə açılır. Sonra fayl geri adlandırılır və əl ilə yüklənir. VLAN-lar ayrıca vlan.dat faylında saxlanılır və toxunulmaz qalır.

{{i:shield-check}} 5. Bərpanı Qadağan Etmək

{{i:ban}} no service password-recovery

ROMMON-a girişi bağlayır. Bərpa zamanı cihaz yalnız konfiqurasiyanı silməklə fabrik vəziyyətinə qaytarılmağa icazə verir — oğurlanmış cihazdan konfiqurasiya (parol hash-ları, VPN açarları) çıxarıla bilmir.

{{i:save}} Ehtiyat nüsxə

Bu rejimdə konfiqurasiyanın serverdə surəti olmalıdır, əks halda parol unudulanda hər şey itir.

{{i:lock}} Fiziki giriş

Konsol portuna çıxışı olan şəxs faktiki olaraq cihazın sahibidir.
