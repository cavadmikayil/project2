{{i:building}} Giriş: Mərkəzi İdarəetmə

200 kompüterli ofisdə hər kompüterdə ayrıca hesab yaratmaq mümkün deyil. Active Directory Domain Services (AD DS) istifadəçiləri, kompüterləri və qaydaları mərkəzdə saxlayır: işçi istənilən domen kompüterinə öz hesabı ilə daxil olur, admin isə bütün cihazlara siyasəti bir yerdən tətbiq edir.

{{i:user-check}} Autentifikasiya

Kerberos ilə — parol şəbəkədə göndərilmir, bilet (ticket) istifadə olunur.

{{i:settings}} Mərkəzi siyasət

Group Policy ilə parol qaydaları, proqram quraşdırma, USB məhdudiyyəti.

{{i:globe}} DNS-ə əsaslanır

AD DNS olmadan işləmir — klientlər Domain Controller-i DNS SRV qeydləri ilə tapır.

{{i:server}} 2. Domain Controller və FSMO Rolları

DC-lər bir-birinə dəyişiklikləri replikasiya edir (multi-master). Amma bəzi əməliyyatları yalnız bir DC edə bilər — bunlar FSMO rollarıdır.

RolSəviyyəVəzifəsi
Schema MasterForestAD sxemini dəyişmək
Domain Naming MasterForestDomen əlavə/silmək
PDC EmulatorDomainVaxt mənbəyi, parol dəyişikliyinin tez yayılması, hesab kilidlənməsi
RID MasterDomainYeni obyektlər üçün unikal ID blokları paylamaq
Infrastructure MasterDomainDomenlərarası istinadları yeniləmək
{{i:triangle-alert}}

Həmişə ən azı iki DC olsun. Tək DC xarab olarsa, heç kim daxil ola bilmir. DC-ni virtual maşın snapshot-undan geri qaytarmaq replikasiya problemləri yarada bilər — AD-ni öz backup üsulu ilə (System State) yedəkləyin.

{{i:list-checks}} 4. Group Policy (GPO)

GPO — OU-ya, domenə və ya site-a bağlanan parametrlər toplusudur. Tətbiq sırası: Local → Site → Domain → OU (LSDOU); sonra tətbiq olunan qalib gəlir.

Nümunə siyasətHarada
Parol uzunluğu, hesab kilidlənməsiDefault Domain Policy (Computer Configuration)
Şəbəkə diskini (mapped drive) qoşmaqUser Configuration → Preferences → Drive Maps
Proqram quraşdırmaq (.msi)Computer Configuration → Software Installation
USB yaddaşları qadağan etməkComputer Configuration → Administrative Templates → System → Removable Storage
Ekran kilidi 10 dəqiqəUser Configuration → Administrative Templates → Control Panel → Personalization

{{i:terminal}} 5. PowerShell ilə AD

# Rolu quraşdırmaq və yeni forest yaratmaq
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "corp.example.az"

# İstifadəçi yaratmaq
New-ADUser -Name "Aysel Mammadova" -SamAccountName aysel `
  -Path "OU=Muhasibat,OU=Users,OU=Baku,DC=corp,DC=example,DC=az" `
  -AccountPassword (Read-Host -AsSecureString "Parol") -Enabled $true

Add-ADGroupMember -Identity "GG-Muhasibat" -Members aysel
Get-ADUser aysel -Properties LastLogonDate, LockedOut
Unlock-ADAccount -Identity aysel

# 90 gündür daxil olmayan hesablar
Search-ADAccount -AccountInactive -TimeSpan 90.00:00:00 -UsersOnly

# DC sağlamlığı və replikasiya
dcdiag
repadmin /replsummary
netdom query fsmo

dcdiag DC testlərini, repadmin /replsummary replikasiya xətalarını, netdom query fsmo isə FSMO rollarının hansı DC-də olduğunu göstərir.
