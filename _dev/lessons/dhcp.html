{{i:server}} Giriş: DHCP Nə Edir?

DHCP (Dynamic Host Configuration Protocol) hostlara IP ünvanını, subnet maskasını, defolt gateway-i və DNS serverini avtomatik verir. Ünvan müəyyən müddətə — lease — icarəyə verilir. Server UDP 67, müştəri UDP 68 portundan istifadə edir.

{{i:router}} Cisco router

Kiçik şəbəkələrdə router özü DHCP server ola bilər.

{{i:hard-drive}} Mərkəzi server

Böyük şəbəkələrdə Windows/Linux DHCP server; router-lər isə relay kimi işləyir.

{{i:shield}} Təhlükəsizlik

Saxta DHCP serverlərindən qorunmaq üçün switch-lərdə DHCP Snooping aktivləşdirin.

{{i:repeat}} 1. DORA Prosesi

{{i:clock}}

Lease müddətinin 50%-i keçəndə müştəri eyni serverdən yeniləmə (renew) istəyir. Server cavab vermirsə 87.5%-də istənilən serverdən istəyir (rebind).

{{i:arrow-left-right}} 2. DHCP Relay

Router broadcast-ları ötürmür, ona görə başqa alt şəbəkədəki server Discover mesajını görmür. Müştərilərin qoşulduğu router interfeysində ip helper-address yazılır: router broadcast-ı qəbul edib serverə unicast kimi göndərir. 

PC (VLAN 10) ──Discover (broadcast)──► R1 Gi0/1 ──unicast──► DHCP server 10.0.0.5
                                     ip helper-address 10.0.0.5

{{i:terminal}} 3. Praktiki Əmrlər

R1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.10
R1(config)# ip dhcp pool LAN10
R1(dhcp-config)# network 192.168.10.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.10.1
R1(dhcp-config)# dns-server 8.8.8.8 1.1.1.1
R1(dhcp-config)# domain-name kollec.local
R1(dhcp-config)# lease 7

İlk 10 ünvanı (gateway, serverlər, printerlər üçün) istisna edir və 7 günlük lease ilə LAN10 pool-unu yaradır. excluded-address pool-dan əvvəl yazılmalıdır.

R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip helper-address 10.0.0.5

Switch(config)# interface vlan 20
Switch(config-if)# ip helper-address 10.0.0.5

Helper-address müştərilərə baxan interfeysdə (və ya L3 switch-də SVI-də) yazılır, serverə baxan interfeysdə yox.

R2(config)# interface GigabitEthernet0/0
R2(config-if)# ip address dhcp
R2(config-if)# no shutdown

C:\> ipconfig /release
C:\> ipconfig /renew
C:\> ipconfig /all

Router interfeysinin ünvanı DHCP ilə alması (məs. ISP-dən) və Windows-da ünvanın buraxılıb yenidən alınması.

show ip dhcp binding
show ip dhcp pool
show ip dhcp conflict
show ip dhcp server statistics
debug ip dhcp server events

Verilmiş ünvanlar (IP–MAC), pool-un doluluğu, konflikt olan ünvanlar, statistika və canlı hadisələr.

{{i:wrench}} 4. Tez-tez Rast Gəlinən Problemlər

{{i:circle-alert}}

Host 169.254.x.x alır: DHCP cavabı gəlmir — server, relay və ya VLAN yolunu yoxlayın.

{{i:circle-alert}}

helper-address yoxdur: server başqa subnetdədirsə Discover heç vaxt ona çatmır.

{{i:circle-alert}}

Pool dolub: show ip dhcp pool ilə istifadə olunan ünvan sayını yoxlayın.

{{i:circle-alert}}

Ünvan konflikti: statik IP pool daxilindədir — onu excluded-address-ə əlavə edin.

{{i:circle-alert}}

DHCP Snooping bloklayır: uplink port trust edilməyib.
