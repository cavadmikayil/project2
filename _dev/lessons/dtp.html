{{i:split}} Giriş: Şəbəkə Seqmentasiyası və Bağlantı

Bu dərs VLAN texnologiyasının əsas komponentlərini araşdırır: access portlar, VLAN trunking (802.1Q) və Cisco-nun Dynamic Trunking Protocol-u (DTP). Bu elementlər şəbəkəni məntiqi seqmentlərə bölür, switch-lər arasında bir neçə VLAN-ı bir kabel üzərindən daşıyır və cihazlararası əlaqəni idarə edir.

{{i:plug}} Access port

Bir VLAN, tag-sız frame-lər — kompüter, printer, kamera üçün.

{{i:git-merge}} Trunk port

Çoxlu VLAN, 802.1Q tag ilə — switch–switch, switch–router, switch–server (hypervisor).

{{i:handshake}} DTP

Portun trunk olub-olmayacağını qonşu ilə avtomatik danışır. Production-da adətən söndürülür.

{{i:plug}} 1. Access Portlar

Access port switch-də yalnız bir VLAN-a aid olan və son istifadəçi cihazlarını qoşmaq üçün istifadə olunan portdur. Bu portdan yalnız həmin VLAN-ın trafiki ötürülür və frame-lər tag-sız olur. IP telefon üçün əlavə olaraq voice VLAN təyin edilə bilər.

Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config-vlan)# exit
Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# switchport voice vlan 150
Switch(config-if)# no shutdown

! Bir neçə portu birlikdə
Switch(config)# interface range fa0/2 - 12
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10

VLAN 10-u yaradır və portları access rejimində VLAN 10-a qoşur. Mövcud olmayan VLAN təyin olunarsa, switch onu avtomatik yaradır.

show vlan brief
show interfaces FastEthernet0/1 switchport

show vlan brief VLAN-ları və onlara aid access portları göstərir (trunk portlar burada görünmür). switchport çıxışında Administrative/Operational Mode və Access VLAN-a baxın.

{{i:git-merge}} 2. VLAN Trunking (802.1Q)

Trunk port bir neçə VLAN-ın trafikini bir linkdən ötürür. IEEE 802.1Q frame-ə 4 baytlıq tag əlavə edir (içində 12 bitlik VLAN ID — 1–4094). Native VLAN-ın frame-ləri isə tag-sız gedir, ona görə hər iki tərəfdə eyni olmalıdır.

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport trunk encapsulation dot1q   ! yalnız ISL də dəstəkləyən köhnə switch-lərdə
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30
Switch(config-if)# switchport trunk allowed vlan add 40
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# no shutdown

allowed vlan 10,20,30 siyahını əvəz edir; mövcud siyahıya əlavə etmək üçün mütləq add yazın — əks halda digər VLAN-lar kəsilir.

show interfaces trunk
show interfaces GigabitEthernet0/1 switchport

show interfaces trunk dörd blok göstərir: mode və native VLAN, icazə verilən VLAN-lar, aktiv VLAN-lar və STP forwarding vəziyyətində olan VLAN-lar.

{{i:triangle-alert}}

Native VLAN mismatch: iki tərəfdə fərqli native VLAN olduqda CDP xəbərdarlıq verir və trafik səhv VLAN-a "sızır".

{{i:handshake}} 3. Dynamic Trunking Protocol (DTP) Modları

DTP Cisco-ya məxsus protokoldur və switch portları arasında trunk əlaqəsini avtomatik qurmağa kömək edir. Aşağıdakı cədvəl iki tərəfin modlarından asılı olaraq nəticəni göstərir.

Qonşu port moduAccessTrunkDynamic AutoDynamic Desirable
AccessAccessUyğunsuzAccessAccess
TrunkUyğunsuzTrunkTrunkTrunk
Dynamic AutoAccessTrunkAccessTrunk
Dynamic DesirableAccessTrunkTrunkTrunk
{{i:lightbulb}}

Yadda saxlama qaydası: auto + auto = access — iki passiv tərəf heç vaxt trunk təklif etmir. Müasir Catalyst switch-lərdə defolt mod adətən dynamic auto-dur.

switchport mode trunk — portu daimi trunk edir. DTP paketləri göndərməyə davam edir, amma qonşudan asılı olmayaraq trunk-dır.

Switch(config-if)# switchport mode trunk

switchport mode access — portu daimi access edir və DTP danışıqlarında iştirak etmir.

Switch(config-if)# switchport mode access

switchport mode dynamic desirable — aktiv şəkildə trunk təklif edir. Qonşu trunk, dynamic auto və ya dynamic desirable olarsa, trunk qurulur.

Switch(config-if)# switchport mode dynamic desirable

switchport mode dynamic auto — passivdir: yalnız qonşu trunk və ya dynamic desirable olarsa trunk qurulur.

Switch(config-if)# switchport mode dynamic auto

switchport nonegotiate — portda DTP paketlərinin göndərilməsini dayandırır. switchport mode trunk (və ya access) ilə birlikdə istifadə olunur.

Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport nonegotiate
show dtp interface FastEthernet0/1
show interfaces FastEthernet0/1 switchport

DTP statusu və portun inzibati (Administrative) və faktiki (Operational) rejimi.

{{i:shield-check}} 4. Tövsiyələr və Təhlükəsizlik

{{i:ban}}

DTP-yə güvənməyin: portları əl ilə access və ya trunk + nonegotiate edin — hücumçu DTP ilə öz portunu trunk edib bütün VLAN-lara çıxa bilər (switch spoofing).

{{i:tag}}

Native VLAN: istifadə olunmayan VLAN (məs. 999) seçin — double tagging (VLAN hopping) hücumuna qarşı.

{{i:list-filter}}

Allowed VLAN: trunk-da yalnız lazım olan VLAN-lar.

{{i:power-off}}

İstifadə olunmayan portlar: shutdown + ayrıca "parking" VLAN-a.
