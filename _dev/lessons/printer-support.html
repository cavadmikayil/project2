{{i:network}} 2. Şəbəkə Printerinin Qoşulması

  1. Printerə statik IP və ya DHCP rezervasiyası verin — IP dəyişəndə bütün kompüterlərdə çap dayanır.

  2. Printerin konfiqurasiya səhifəsini çap edin (IP, MAC, firmware).

  3. Kompüterdə Standard TCP/IP port ilə əlavə edin və istehsalçının driver-ini (və ya universal driver) seçin.

  4. Test səhifəsi çap edin.

ping 192.168.20.50
Test-NetConnection 192.168.20.50 -Port 9100     # RAW/JetDirect portu

Add-PrinterPort -Name "IP_192.168.20.50" -PrinterHostAddress "192.168.20.50"
Add-Printer -Name "Muhasibat-HP" -DriverName "HP Universal Printing PCL 6" -PortName "IP_192.168.20.50"
Get-Printer | Select Name, PortName, DriverName, PrinterStatus

Printer portları: 9100 (RAW/JetDirect), 631 (IPP), 515 (LPD). Veb interfeys adətən HTTP/HTTPS ilə açılır.

{{i:list-restart}} 3. Print Spooler: Donmuş Növbə

Sənəd növbədə "Printing" vəziyyətində qalıb və silinmir — ən çox rast gəlinən haldır. Həll: spooler xidmətini dayandırıb növbə fayllarını silmək.

net stop spooler
del /Q /F %systemroot%\System32\spool\PRINTERS\*
net start spooler

# PowerShell
Stop-Service Spooler -Force
Remove-Item "$env:SystemRoot\System32\spool\PRINTERS\*" -Force
Start-Service Spooler

Bu əmrlər bu kompüterdəki bütün çap növbəsini silir. Print server-də icra edilərsə, bütün istifadəçilərin sənədləri silinir — əvvəl xəbərdar edin.

{{i:server}} 4. Print Server və GPO ilə Paylama

{{i:server}} Mərkəzi idarəetmə

Windows Server-də Print Management: driver-lər bir yerdə, növbələr bir yerdə, çap statistikası.

{{i:users}} GPO ilə yerləşdirmə

Printerlər OU-ya görə avtomatik qoşulur — istifadəçi kabinetə gələndə öz şöbəsinin printerini görür.

{{i:shield-alert}}

Təhlükəsizlik: 2021-ci ildə "PrintNightmare" zəifliyi Print Spooler vasitəsilə sistemi ələ keçirməyə imkan verdi. Domain Controller-lərdə və çap etməyən serverlərdə Spooler xidmətini söndürün, Windows yeniləmələrini gecikdirməyin.
