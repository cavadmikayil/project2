{{i:map}} Giriş: Marşrutlaşdırma Protokolları

Statik marşrutlar kiçik şəbəkədə işləyir, amma 30 router-li şəbəkədə hər dəyişiklik saatlarla əl işi deməkdir. Dinamik marşrutlaşdırma protokolları router-lərə şəbəkə haqqında məlumat mübadiləsi etməyə, ən yaxşı yolu avtomatik seçməyə və link kəsiləndə alternativ yola keçməyə imkan verir. Bu dərsdə üç daxili protokolu — RIP, OSPF və EIGRP-ni müqayisə edirik.

{{i:chart-column}} 1. Administrative Distance (AD)

Router eyni şəbəkəni bir neçə mənbədən öyrənəndə ən etibarlısını administrative distance ilə seçir: kiçik AD — daha etibarlı. Aşağıdakı qrafik Cisco-nun defolt AD dəyərlərini göstərir.

MənbəADMənbəAD
Connected0OSPF110
Static1IS-IS115

EIGRP (daxili)90iBGP200

Seçim ardıcıllığı: əvvəlcə ən uzun prefiks (longest match), sonra ən kiçik AD, sonra protokolun öz metrikası.

{{i:layers}} 2. Protokol Növləri

{{i:signpost}} Distance vector

"Qonşum nə deyirsə, ona inanıram": router yalnız qonşunun gördüyü məsafə və istiqaməti bilir. Nümunə: RIP.

{{i:map}} Link-state

Hər router şəbəkənin tam xəritəsini (LSDB) toplayır və ən qısa yolu Dijkstra (SPF) ilə özü hesablayır. Nümunə: OSPF, IS-IS.

{{i:sparkles}} Advanced distance vector

Distance vector əsaslı, amma sürətli və ağıllı (DUAL alqoritmi). Nümunə: EIGRP.

IGP (RIP, OSPF, EIGRP) bir təşkilat daxilində, EGP (BGP) isə təşkilatlar və provayderlər arasında — internetin özündə işləyir.

{{i:ruler}} 3. Metrika Müqayisəsi

RIP — hop count

Keçilən router sayı. Maksimum 15; 16 — əlçatmaz. 1 Gbps və 10 Mbps linki eyni sayır.

OSPF — cost

Reference bandwidth / interfeys bandwidth (defolt 108 / bw). Yüksək bant — kiçik cost.

EIGRP — kompozit

Bandwidth, delay, reliability, load. Defolt olaraq yalnız bandwidth və delay (K1, K3).

{{i:timer}} 4. Konvergensiya Sürəti

Konvergensiya — topologiya dəyişikliyindən sonra bütün router-lərin marşrut cədvəllərini yeniləyib yenidən razılığa gəlməsi üçün lazım olan vaxt.

{{i:turtle}}

RIP — yavaş: dəyişikliklər periodik yeniləmələrlə yayılır; count-to-infinity-yə qarşı hold-down timer, split horizon, route poisoning istifadə olunur. Dəqiqələr çəkə bilər.

{{i:gauge}}

OSPF — sürətli: LSA-lar dərhal yayılır, hər router SPF-i yenidən hesablayır. Adətən saniyələr (BFD ilə daha tez).

{{i:zap}}

EIGRP — çox sürətli: DUAL əvvəlcədən hesablanmış ehtiyat yolu (feasible successor) saxlayır — varsa, keçid demək olar ki, anidir.

{{i:terminal}} 5. Praktiki Əmrlər

router rip
 version 2
 network 192.168.1.0
 network 192.168.2.0
 no auto-summary
 passive-interface GigabitEthernet0/1

RIPv2-ni aktivləşdirir, classful şəbəkələri elan edir, avtomatik xülasəni söndürür və LAN interfeysini passiv edir.

show ip protocols
show ip route rip
debug ip rip
router ospf 1
 router-id 1.1.1.1
 network 192.168.1.0 0.0.0.255 area 0
 network 10.0.0.0 0.0.0.255 area 0
 passive-interface default
 no passive-interface GigabitEthernet0/0

OSPF prosesi, router ID və şəbəkələr (wildcard ilə). Bütün interfeyslər passiv edilir, yalnız qonşuluq lazım olan açılır. Ətraflı: OSPF dərsi.

show ip protocols
show ip route ospf
show ip ospf neighbor
show ip ospf interface brief
show ip ospf database
router eigrp 100
 network 192.168.1.0 0.0.0.255
 network 10.0.0.0 0.0.0.255
 no auto-summary
 passive-interface GigabitEthernet0/1

EIGRP AS 100 — qonşularda AS nömrəsi eyni olmalıdır. Named mode (router eigrp CAMPUS) yeni tövsiyə olunan sintaksisdir.

show ip protocols
show ip route eigrp
show ip eigrp neighbors
show ip eigrp topology
show ip eigrp interfaces
