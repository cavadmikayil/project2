{{i:shield-check}} Giriş: İnternetə Açıq Server 5 Dəqiqədə Skan Olunur

Yeni cloud VM-in public IP-si bir neçə dəqiqə ərzində botlar tərəfindən skan edilir və SSH-a brute force başlayır. Hardening — hücum səthini minimuma endirmək: lazımsız hər şeyi söndürmək, qalanı sərtləşdirmək və baş verənləri qeydə almaq. İstinad standartları: CIS Benchmarks və DISA STIG.

{{i:minimize-2}} Minimal quraşdırma

Olmayan paketin zəifliyi olmur. Server üçün qrafik interfeys lazım deyil.

{{i:layers}} Defense in depth

Firewall + SSH açarları + fail2ban + SELinux + audit — biri keçilsə, digəri qoruyur.

{{i:scan-search}} Yoxlama

lynis audit system — pulsuz audit aləti, tövsiyələr və bal verir.

{{i:refresh-cw}} 1. Yeniləmələr və Servislər

# Avtomatik təhlükəsizlik yeniləmələri
apt install unattended-upgrades && dpkg-reconfigure -plow unattended-upgrades   # Ubuntu/Debian
dnf install dnf-automatic && systemctl enable --now dnf-automatic.timer          # RHEL

needrestart                               # yeniləmədən sonra restart tələb edən servislər
ls /var/run/reboot-required 2>/dev/null   # kernel yeniləndi — reboot lazımdır

systemctl list-unit-files --state=enabled # açılışda başlayanlar
systemctl disable --now cups avahi-daemon # lazımsızları söndür
ss -tulpn                                 # hər dinləyən portun səbəbi bilinməlidir

{{i:key-round}} 2. SSH Hardening

# /etc/ssh/sshd_config.d/10-hardening.conf
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
AllowGroups ssh-users
MaxAuthTries 3
LoginGraceTime 30
ClientAliveInterval 300
ClientAliveCountMax 2
X11Forwarding no
AllowTcpForwarding no

sshd -t && systemctl reload ssh          # əvvəl yoxla, sonra tətbiq et
{{i:triangle-alert}}

Parol girişini söndürməzdən əvvəl açarla girişi yeni pəncərədə test edin və köhnə sessiyanı bağlamayın. MFA üçün libpam-google-authenticator və ya FIDO2 açarları (ed25519-sk) istifadə oluna bilər.

{{i:ban}} 3. fail2ban

apt install fail2ban

# /etc/fail2ban/jail.local
[DEFAULT]
bantime  = 1h
findtime = 10m
maxretry = 5
ignoreip = 127.0.0.1/8 10.0.0.0/24      # öz şəbəkənizi bloklamayın

[sshd]
enabled = true

[nginx-http-auth]
enabled = true

systemctl enable --now fail2ban
fail2ban-client status sshd
fail2ban-client set sshd unbanip 203.0.113.7

fail2ban log-ları oxuyur və çoxlu uğursuz cəhd edən IP-ni firewall ilə müvəqqəti bloklayır. SSH açarı ilə giriş olduqda da log-ları təmiz saxlamağa kömək edir.

{{i:lock-keyhole}} 4. SELinux və AppArmor

Adi icazələr (DAC) sahibə hər şeyi etməyə imkan verir. MAC (Mandatory Access Control) isə hətta root prosesini də siyasətlə məhdudlaşdırır: sındırılmış nginx /etc/shadow-u oxuya bilmir.

getenforce                                 # Enforcing | Permissive | Disabled
ls -Z /var/www/html                        # kontekstlər
ausearch -m avc -ts recent                 # nə bloklandı
sealert -a /var/log/audit/audit.log        # izah və təklif

# Veb faylları qeyri-standart qovluqdadır
semanage fcontext -a -t httpd_sys_content_t "/srv/www(/.*)?"
restorecon -Rv /srv/www
# nginx 8080-də yox, 8081-də dinləsin
semanage port -a -t http_port_t -p tcp 8081
setsebool -P httpd_can_network_connect on  # proxy üçün

Problem olanda SELinux-u söndürməyin — setenforce 0 ilə müvəqqəti yoxlayıb düzgün kontekst və ya boolean tapın.

aa-status                                  # yüklənmiş profillər
aa-complain /etc/apparmor.d/usr.sbin.nginx # yalnız log (öyrənmə rejimi)
aa-enforce  /etc/apparmor.d/usr.sbin.nginx
journalctl -k | grep -i apparmor           # bloklamalar

{{i:scroll-text}} 5. Audit və Bütövlük Nəzarəti

# auditd: kritik faylların dəyişməsi və sudo istifadəsi
auditctl -w /etc/passwd -p wa -k identity
auditctl -w /etc/sudoers -p wa -k sudoers
auditctl -a always,exit -F arch=b64 -S execve -F euid=0 -k root_cmds
ausearch -k identity --start today
aureport --summary

# AIDE: fayl bütövlüyü (FIM)
aide --init && mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
aide --check                               # baseline-dan fərqlər

last -a | head; lastb | head               # uğurlu və uğursuz girişlər
