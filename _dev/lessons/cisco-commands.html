{{i:lightbulb}} 3. CLI Məsləhətləri

{{i:circle-help}}

? — mümkün əmrlər; sh ? — "sh" ilə başlayanlar; show ip ? — növbəti söz.

{{i:keyboard}}

Tab — əmri tamamlayır; ↑ / ↓ — tarixçə; Ctrl+A / Ctrl+E — sətrin əvvəli/sonu.

{{i:filter}}

Çıxışı filtrləmək: show run | include ip address, | section router, | begin interface.

{{i:repeat}}

Konfiqurasiya rejimindən show işlətmək: do show ip interface brief.

{{i:ban}}

no ip domain-lookup — yazı səhvi olan əmrin DNS kimi axtarılıb terminalı dondurmasının qarşısını alır.
