{{i:life-buoy}} Giriş: FHRP Nədir?

Kompüterlərdə bir default gateway yazılır. O router sıradan çıxsa, bütün VLAN internetsiz qalır — ikinci router olsa belə. First Hop Redundancy Protocol (FHRP) bu problemi həll edir: bir neçə router ortaq virtual IP və virtual MAC paylaşır; aktiv router nasaz olanda ehtiyat router onun yerini alır və istifadəçilər heç nə hiss etmir.

HSRP

Cisco-ya məxsus, ən geniş yayılmış.

VRRP

Açıq standart (RFC 5798) — multi-vendor.

GLBP

Cisco-ya məxsus; yükü bir neçə router arasında da bölür.

{{i:workflow}} 1. Necə İşləyir

  1. R1 (192.168.1.2) və R2 (192.168.1.3) eyni qrupdadır; virtual IP 192.168.1.1 — kompüterlərin gateway-i.

  2. Router-lər hello mesajları mübadiləsi edir; ən yüksək priority (bərabər olduqda ən yüksək IP) Active/Master olur.

  3. Active router virtual IP-nin ARP sorğularına virtual MAC ilə cavab verir (HSRPv1: 0000.0C07.ACxx, VRRP: 0000.5E00.01xx).

  4. Hold time ərzində hello gəlməsə, Standby router Active olur və gratuitous ARP göndərir — switch-lərin MAC cədvəli yenilənir.

  5. Kompüterlərin ARP cədvəli dəyişmir, çünki virtual MAC eyni qalır.

{{i:activity}} 3. HSRP Rolları və Anlayışlar

{{i:circle-check}}

Active: trafiki faktiki ötürən router; virtual IP/MAC-a cavab verir.

{{i:circle-pause}}

Standby: Active nasaz olanda dərhal yerinə keçməyə hazır router.

{{i:ear}}

Listen: qrupda olan, amma Active/Standby olmayan router-lər.

{{i:star}}

Preempt: daha yüksək prioritetli router bərpa olunanda Active rolunu geri alır.

{{i:radar}}

Object tracking: uplink kəsiləndə priority avtomatik azalır və Standby Active olur.

{{i:terminal}} 4. Praktiki Əmrlər

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.2 255.255.255.0
Router(config-if)# standby version 2
Router(config-if)# standby 1 ip 192.168.1.1
Router(config-if)# standby 1 priority 110
Router(config-if)# standby 1 preempt

! Uplink izlənməsi: Gi0/1 düşərsə priority 20 azalır (110 → 90)
Router(config)# track 10 interface GigabitEthernet0/1 line-protocol
Router(config-if)# standby 1 track 10 decrement 20

HSRP qrup 1, virtual IP 192.168.1.1; bu router 110 prioritetlə Active olur. Tracking olmadan internet linki kəsilsə də router Active qalar və trafik qara dəliyə düşər.

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.2 255.255.255.0
Router(config-if)# vrrp 1 ip 192.168.1.1
Router(config-if)# vrrp 1 priority 110
Router(config-if)# vrrp 1 preempt

VRRP qrup 1; bu router Master olmaq üçün prioriteti artırır. Yeni IOS XE versiyalarında VRRPv3 sintaksisi: fhrp version vrrp v3 → vrrp 1 address-family ipv4.
