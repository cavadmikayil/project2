{{i:play}} 3. Python ilə Render

import yaml
from pathlib import Path
from jinja2 import Environment, FileSystemLoader, StrictUndefined

env = Environment(
    loader=FileSystemLoader("templates"),
    trim_blocks=True,          # {% %} teqindən sonrakı yeni sətri sil
    lstrip_blocks=True,        # teqdən əvvəlki boşluqları sil
    undefined=StrictUndefined, # məlumatda olmayan dəyişən → xəta (boş sətir yox!)
)
tpl = env.get_template("access.j2")

Path("configs").mkdir(exist_ok=True)
for f in Path("data").glob("*.yaml"):
    data = yaml.safe_load(f.read_text())
    Path(f"configs/{data['hostname']}.cfg").write_text(tpl.render(**data))
    print("yaradıldı:", data["hostname"])

{{i:database}} 5. Source of Truth Yanaşması

  1. Məlumat mərkəzdə: NetBox və ya git-dəki YAML — cihazlar, IP-lər, VLAN-lar, portlar.

  2. Şablonlar git-də review olunur.

  3. CI render edir və nəticəni lint/test edir (batfish, yamllint).

  4. Diff: yaradılan konfiqurasiya cihazdakı ilə müqayisə olunur (NAPALM compare_config).

  5. Təsdiqdən sonra push — Netmiko, NAPALM və ya Ansible.
