{{i:binary}} Giriş: Niyə Başqa Say Sistemləri?

Kompüter üçün hər şey 0 və 1-dir. IPv4 ünvanı və maska binar (2-lik), MAC və IPv6 ünvanı isə hexadecimal (16-lıq) sistemlə daha rahat oxunur. Subnetting-i sürətli etmək üçün bu çevirmələri əzbər bilmək lazımdır.

{{i:hash}} 1. Binar Sistem

Bir oktet 8 bitdir; hər bitin öz dəyəri var. Dəyəri "1" olan bitlərin cəmi onluq ədədi verir.

Bit dəyəri1286432168421Cəm
19211000000128+64
16810101000128+32+8
770100110164+8+4+1

Onluqdan binara: çıxma üsulu

200 → 128 çıxılır? bəli → 1   qalıq 72
 72 →  64 çıxılır? bəli → 1   qalıq 8
  8 →  32? xeyr → 0,  16? xeyr → 0
  8 →   8 çıxılır? bəli → 1   qalıq 0
  0 →   4, 2, 1 → 0 0 0
200 = 11001000

{{i:hash}} 2. Hexadecimal Sistem

16 simvol: 0–9 və A–F (A=10 … F=15). Bir hex rəqəmi düz 4 bitə (nibble) bərabərdir — çevirmə buna görə çox asandır.

Hex → binar:    3C = 0011 1100 = 60
Binar → hex:    1010 1111 = AF = 175
Hex → onluq:    AF = 10×16 + 15 = 175
IPv6 hextet:    2001 = 0010 0000 0000 0001
