{{i:settings-2}} Giriş: 100 Serverə Eyni Anda

50 Linux serverdə NTP serverini dəyişmək lazımdır. Əl ilə — bütün gün və mütləq bir-ikisi unudulacaq. Ansible ilə — bir YAML faylı və bir əmr. Ansible agentless-dir: serverlərə heç nə quraşdırılmır, SSH (Windows üçün WinRM) üzərindən işləyir. Tələb yalnız hədəfdə Python-dur (şəbəkə cihazlarında o da lazım deyil).

{{i:terminal}} 2. Ad-hoc Əmrlər

pip install ansible
ansible all -i inventory.ini -m ping                      # əlaqə yoxlaması
ansible web -i inventory.ini -a "uptime"                  # istənilən əmr
ansible linux -i inventory.ini -m apt -a "name=htop state=present" --become
ansible db -i inventory.ini -m service -a "name=postgresql state=restarted" --become
ansible all -i inventory.ini -m setup -a "filter=ansible_distribution*"   # facts

--become — sudo ilə işlət. -m modul adıdır; Ansible-da minlərlə modul var: apt, dnf, copy, template, user, ufw, cisco.ios.ios_config.

{{i:file-code}} 3. Playbook

# web.yml
- name: Veb serverləri hazırla
  hosts: web
  become: true
  vars:
    site_name: portal
  tasks:
    - name: nginx quraşdır
      ansible.builtin.apt:
        name: nginx
        state: present
        update_cache: true

    - name: Sayt konfiqurasiyası
      ansible.builtin.template:
        src: templates/site.conf.j2
        dest: /etc/nginx/sites-available/{{ site_name }}.conf
      notify: nginx reload            # yalnız fayl dəyişəndə

    - name: nginx işləsin və açılışda başlasın
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

  handlers:
    - name: nginx reload
      ansible.builtin.service:
        name: nginx
        state: reloaded

# İşlətmək
ansible-playbook -i inventory.ini web.yml --check --diff   # quru sınaq: nə dəyişəcək?
ansible-playbook -i inventory.ini web.yml
ansible-playbook -i inventory.ini web.yml --limit web01

Nəticədə hər task üçün ok (dəyişiklik lazım deyildi), changed, failed görünür. İkinci işlədişdə hər şey ok olmalıdır — idempotency-nin sübutu.

{{i:package}} 5. Role-lar, Galaxy və Vault

{{i:folder-tree}}

Role: tasks, handlers, templates, defaults — təkrar istifadə olunan paket. ansible-galaxy role init nginx.

{{i:store}}

Galaxy və Collections: hazır role və modullar: ansible-galaxy collection install cisco.ios.

{{i:lock}}

Ansible Vault: parolları şifrəli saxlamaq: ansible-vault encrypt group_vars/all/vault.yml, işlədərkən --ask-vault-pass.

{{i:circle-check}}

ansible-lint və Molecule — playbook-ları CI-da yoxlamaq və test etmək.
