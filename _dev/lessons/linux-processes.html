{{i:cpu}} Giriş: Proqram və Proses

Proqram diskdəki fayldır, proses isə onun işləyən nüsxəsi: öz PID-i, yaddaşı, açıq faylları və sahibi olan. Hər proses valideyn prosesdən (fork) yaranır; ən birinci proses — PID 1 — müasir sistemlərdə systemd-dir.

{{i:hash}} PID / PPID

Prosesin və valideyninin nömrəsi.

{{i:user}} UID

Proses hansı istifadəçinin hüququ ilə işləyir.

{{i:layers}} Thread

Eyni yaddaşı paylaşan icra axınları; ps -eLf ilə görünür.

{{i:eye}} 1. Proseslərə Baxış

ps aux                              # bütün proseslər (BSD üslubu)
ps -ef --forest                     # valideyn-uşaq ağacı
ps aux --sort=-%mem | head          # ən çox RAM istifadə edənlər
ps -o pid,ppid,user,%cpu,%mem,etime,cmd -p 1234
pstree -p                           # ağac şəklində
pgrep -a nginx                      # adla axtarış
top   /   htop                      # interaktiv: P — CPU, M — RAM üzrə sırala, k — kill
pidof sshd
lsof -p 1234                        # prosesin açıq faylları və portları
ss -tlnp                            # port dinləyən proseslər

{{i:radio}} 2. Siqnallar

Siqnal№MənasıTutula bilərmi?
SIGHUP1Terminal bağlandı; çox servis üçün "konfiqurasiyanı yenidən oxu"Bəli
SIGINT2Ctrl+CBəli
SIGKILL9Dərhal öldür — təmizlik yoxdurXeyr

SIGSTOP / SIGCONT19 / 18Dondur / davam etSTOP — xeyr

kill 1234              # SIGTERM — əvvəlcə həmişə bu
kill -HUP $(pidof nginx)   # konfiqurasiyanı yenidən yüklə
kill -9 1234           # yalnız TERM kömək etməyəndə
pkill -u olduser       # istifadəçinin bütün prosesləri
killall -s TERM php-fpm

kill -9 prosesə faylları bağlamağa, müvəqqəti faylları silməyə imkan vermir — verilənlər bazasında məlumat zədələnə bilər.

{{i:layers-3}} 3. Job Control və Arxa Plan

./backup.sh &          # arxa planda başlat
jobs                   # bu shell-in işləri
fg %1                  # ön plana gətir
# Ctrl+Z               # dayandır
bg %1                  # arxa planda davam etdir

nohup ./long-task.sh > task.log 2>&1 &    # terminal bağlansa da işləsin
disown -h %1

tmux new -s maint      # SSH qopsa belə sessiya qalır; Ctrl+B D — ayrıl
tmux attach -t maint
{{i:lightbulb}}

Uzun çəkən hər əməliyyatı (yeniləmə, böyük kopyalama, migrasiya) tmux və ya screen içində başladın — VPN qopması işi yarımçıq qoymasın.

{{i:gauge}} 4. Prioritet: nice, renice, ionice

# nice: -20 (ən yüksək prioritet) ... 19 (ən aşağı); defolt 0
nice -n 15 tar czf /backup/home.tgz /home       # backup istifadəçiləri yavaşlatmasın
renice -n 10 -p 1234
ionice -c3 -p 1234                              # disk I/O — yalnız boş vaxtda (idle)

# systemd servisi üçün
systemctl set-property backup.service CPUQuota=30% IOWeight=50

Prioriteti artırmaq (mənfi nice) yalnız root edə bilər.
