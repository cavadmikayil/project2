{{i:radio-tower}} Giriş: VTP Nədir?

VLAN Trunking Protocol (VTP) Cisco-ya məxsus protokoldur və VTP domenindəki switch-lər arasında VLAN məlumatlarını (VLAN ID, ad) mərkəzləşdirilmiş şəkildə paylaşır. Bir "server" switch-də edilən dəyişiklik trunk bağlantılı "client" switch-lərə avtomatik yayılır — 50 switch-də eyni VLAN-ı əl ilə yaratmağa ehtiyac qalmır.

{{i:building}} Domen

Eyni VTP domen adı və parolu olan switch-lər qrupu. Ad böyük-kiçik hərfə həssasdır.

{{i:git-merge}} Yalnız trunk

VTP elanları yalnız trunk portlar üzərindən ötürülür.

{{i:hash}} Revision

Hər dəyişiklik revision nömrəsini 1 artırır; ən böyük nömrə "qalib" gəlir.

{{i:triangle-alert}} 2. Vacib Xəbərdarlıq: Revision Nömrəsi

{{i:triangle-alert}}

Diqqət: Hər VTP dəyişikliyi konfiqurasiya revision nömrəsini artırır. Eyni domenə daha yüksək revision nömrəli (məsələn, lab-dan gətirilmiş) server və ya client switch qoşularsa, o öz — bəlkə boş — VLAN bazasını bütün digər switch-lərə yayar və mövcud VLAN-ları silər. Nəticə: bütün access portlar VLAN-sız qalır, ofis işləmir.

  1. Yeni switch-i şəbəkəyə qoşmazdan əvvəl show vtp status ilə revision nömrəsini yoxlayın.

  2. Revision-u sıfırlamaq üçün: modu transparent edib yenidən client-ə qaytarın və ya domen adını müvəqqəti dəyişin.

  3. Bir çox şirkət riski tamamilə aradan qaldırmaq üçün bütün switch-ləri transparent rejimdə saxlayır və VLAN-ları avtomatlaşdırma ilə idarə edir.

{{i:git-branch}} 3. Versiyalar və Pruning

VTPv1 / v2

Yalnız VLAN 1–1005 (normal diapazon). v2 transparent switch-in domen adını yoxlamadan ötürməsini və Token Ring dəstəyini əlavə edir.

VTPv3

Extended VLAN-lar (1006–4094), primary server anlayışı — yalnız o dəyişiklik edə bilər, bu da təsadüfi silinmə riskini kəskin azaldır. Parol gizlədilə bilir.

VTP pruning: switch-də həmin VLAN-dan heç bir port yoxdursa, həmin VLAN-ın broadcast və naməlum unicast trafiki o switch-ə gedən trunk-dan kəsilir — lazımsız trafik azalır.

{{i:terminal}} 4. Praktiki Əmrlər

Switch(config)# vtp domain MYCOMPANY
Switch(config)# vtp version 2
Switch(config)# vtp mode server
Switch(config)# vtp password Cisco123
Switch(config)# vtp pruning

! Client switch
Switch(config)# vtp domain MYCOMPANY
Switch(config)# vtp mode client
Switch(config)# vtp password Cisco123

Domen adı, versiya və parol bütün switch-lərdə eyni olmalıdır. Pruning server-də aktivləşdirilir və domenə yayılır.

show vtp status
show vtp password
show vtp counters
show interfaces trunk

show vtp status: domen, mod, versiya, Configuration Revision və son dəyişikliyi kimin etdiyi. VLAN-lar yayılmırsa — trunk, domen adı və parolu yoxlayın.
