{{i:search-check}} Giriş: Təsadüfi Düymə Basmaq Metod Deyil

Təcrübəsiz texnik ağlına gələn hər şeyi sınayır: restart, driver, reinstall. Bəzən alınır, amma niyə alındığını bilmir və problem geri qayıdır. Təcrübəli mütəxəssis sistemli işləyir: məlumat toplayır, fərziyyə qurur, yoxlayır və sənədləşdirir. CompTIA A+ və Network+ imtahanlarında bu metodologiya ayrıca sual mövzusudur.

{{i:list-ordered}} 1. CompTIA-nın 7 Addımı

  1. Problemi müəyyən et: istifadəçini dinlə, suallar ver, xəta mesajını gör, son nə dəyişib? — ehtiyat nüsxə al.

  2. Ehtimal olunan səbəb barədə fərziyyə qur — ən sadə və ən çox rast gəlinəndən başla (kabel, qida, parol).

  3. Fərziyyəni test et. Təsdiq olunmasa — yeni fərziyyə qur və ya eskalasiya et.

  4. Fəaliyyət planı qur və mümkün təsirləri müəyyən et — kimə təsir edəcək, geri dönüş yolu varmı, təsdiq (change) lazımdırmı.

  5. Həlli tətbiq et və ya səlahiyyətin çatmırsa, eskalasiya et.

  6. Sistemin tam işlədiyini yoxla — istifadəçi ilə birlikdə; lazım olsa profilaktik tədbir gör.

  7. Sənədləşdir: nəticələr, görülən işlər və nəticə — ticket-də və knowledge base-də.

{{i:clipboard-list}} 4. Nümunə: "İnternet İşləmir"

ipconfig                    # 1. IP varmı? 169.254.x.x = DHCP-dən ünvan alınmayıb
ping 127.0.0.1              # 2. TCP/IP stack işləyirmi
ping 192.168.1.1            # 3. Default gateway-ə çatırmı (lokal şəbəkə)
ping 8.8.8.8                # 4. İnternetə IP ilə çatırmı
nslookup google.com         # 5. DNS işləyirmi
tracert 8.8.8.8             # 6. Harada kəsilir

8.8.8.8-ə ping gedir, amma saytlar açılmırsa — problem DNS-dədir. Gateway-ə ping getmirsə — kabel, Wi-Fi, VLAN və ya IP konfiqurasiyası. Bu ardıcıllıq problemi 2–3 dəqiqəyə lokallaşdırır.

{{i:ban}} 5. Tipik Səhvlər

{{i:shuffle}} Eyni anda çox dəyişiklik

Beş şeyi birdən dəyişsəniz, hansının kömək etdiyini bilməyəcəksiniz. Bir dəyişiklik — bir test.

{{i:save}} Backup-sız müdaxilə

Registry, konfiqurasiya, profil — dəyişməzdən əvvəl surət alın.

{{i:eye-off}} Fərziyyəyə aşiq olmaq

Test fərziyyəni təkzib edirsə, onu buraxın — faktlar əsasdır.

{{i:file-x}} Sənədləşdirməmək

Növbəti dəfə eyni problemə yenidən saatlar sərf olunacaq.
