{{i:terminal}} 2. Nümunə: Skript Yazdırmaq

Prompt:
"Windows Server 2022, PowerShell 5.1. AD-də 60 gündən çox daxil olmayan
aktiv istifadəçi hesablarını tap, CSV-yə yaz (Name, SamAccountName,
LastLogonDate, OU). Heç nəyi dəyişmə və ya söndürmə — yalnız hesabat.
Hər hissəyə qısa şərh əlavə et."
# Nəticə (yoxlanıldıqdan sonra):
Import-Module ActiveDirectory
$limit = (Get-Date).AddDays(-60)

Get-ADUser -Filter {Enabled -eq $true -and LastLogonDate -lt $limit} `
    -Properties LastLogonDate |
  Select-Object Name, SamAccountName, LastLogonDate,
    @{n='OU'; e={ ($_.DistinguishedName -split ',', 2)[1] }} |
  Export-Csv -Path .\inactive-users.csv -NoTypeInformation -Encoding UTF8

Prompt-da "heç nəyi dəyişmə" məhdudiyyəti qoyulub — AI-ın yazdığı skripti ilk dəfə həmişə yalnız oxuyan rejimdə və ya -WhatIf ilə işlədin. LastLogonDate replikasiya səbəbindən 9–14 gün gecikə bilər — bunu da yoxlamaq sizin işinizdir.

{{i:scroll-text}} 3. Nümunə: Log Analizi

  1. Log-u əvvəlcə filtrləyin (grep, Get-WinEvent) — 50 MB log-u yox, əlaqəli 200 sətri verin.

  2. IP, istifadəçi adı, domen kimi həssas məlumatları anonimləşdirin (məs. USER1, 10.x.x.1).

  3. Konkret sual verin: "Bu nginx error log-unda 502 xətalarının zaman qanunauyğunluğu və ehtimal olunan səbəb nədir?"

  4. Cavabdakı hər iddianı log-da tapın — model mövcud olmayan sətirdən "sitat" gətirə bilər.
