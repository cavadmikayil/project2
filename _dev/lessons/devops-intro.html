{{i:infinity}} Giriş: Divarı Sökmək

Klassik şirkətdə developer-lər kodu yazıb "divarın o tayına" — əməliyyat (Ops) komandasına atır. Developer tez dəyişiklik istəyir, Ops isə sabitlik. Nəticə: ayda bir böyük, qorxulu release və gecə yarısı qəzalar. DevOps bu iki dünyanı bir komanda, ortaq məqsəd və avtomatlaşdırılmış proses ilə birləşdirən yanaşmadır.

{{i:users}} Mədəniyyət

"Sənin kodun, mənim serverim" yox — "bizim xidmətimiz". Nasazlıqda günahkar yox, səbəb axtarılır (blameless).

{{i:workflow}} Avtomatlaşdırma

Test, build, deploy, infrastruktur — əl ilə təkrarlanan hər şey koda çevrilir.

{{i:chart-line}} Ölçmə

Nəyi ölçmürsənsə, onu yaxşılaşdıra bilməzsən: deploy tezliyi, xəta faizi, bərpa vaxtı.

{{i:wrench}} 4. Əsas Praktikalar

{{i:git-branch}} Version control hər şey üçün

Kod, konfiqurasiya, infrastruktur, sənədlər, hətta şəbəkə cihazlarının config-ləri.

{{i:repeat}} CI / CD

Hər commit avtomatik yoxlanır; yoxlamadan keçən kod avtomatik çıxa bilər.

{{i:file-code}} Infrastructure as Code

Server və şəbəkə portalda kliklə yox, kodla yaradılır — təkrarlana bilən və review olunan.

{{i:toggle-right}} Feature flags

Kod çıxır, amma funksiya söndürülüb qalır — istifadəçilərin 5%-ində yoxlanır.

{{i:file-search}} Postmortem

Hər ciddi insidentdən sonra blameless təhlil: nə oldu, niyə, nə dəyişirik.

{{i:target}} SRE

Google-un DevOps tətbiqi: SLO, error budget, toil-u avtomatlaşdırmaq.

{{i:map}} 5. DevOps Mühəndisi Yol Xəritəsi

  1. Linux və şəbəkə: terminal, bash, SSH, DNS, HTTP, TCP/IP — bu portalın Linux və CCNA dərsləri.

  2. Git və bir proqramlaşdırma dili (Python və ya Go).

  3. Konteynerlər: Docker, sonra Kubernetes.

  4. CI/CD: GitHub Actions və ya GitLab CI ilə tam pipeline.

  5. IaC: Terraform (infrastruktur) + Ansible (konfiqurasiya).

  6. Cloud: AWS və ya Azure, bir sertifikat (AZ-104, AWS SAA).

  7. Observability və təhlükəsizlik: Prometheus/Grafana, DevSecOps.
