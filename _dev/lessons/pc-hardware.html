Hardware problemini düzgün təyin etmək — kompüteri boş yerə dəyişməyin və ya lazımsız hissə almağın qarşısını alır. Helpdesk mütəxəssisi hər komponentin nə etdiyini, necə xarab olduğunu və bunu hansı simptomlarla göstərdiyini bilməlidir.

{{i:power}} 2. POST, BIOS/UEFI

Kompüter yandırılanda POST (Power-On Self-Test) hardware-i yoxlayır. Problem olarsa, ekran açılmadan səs siqnalları (beep) və ya anakart LED-ləri ilə xəbər verir — kodlar istehsalçıya görə fərqlidir, anakartın kitabçasına baxın.

{{i:settings}}

UEFI: BIOS-un müasir əvəzi — GPT diskləri, Secure Boot, qrafik interfeys. Giriş: F2, Del, F10, F12 (boot menyu).

{{i:shield-check}}

Secure Boot və TPM 2.0: Windows 11 üçün tələbdir; BitLocker açarını TPM saxlayır.

{{i:list-ordered}}

Boot order: "No bootable device" xətasında ilk baxılan yer.

{{i:refresh-cw}}

Firmware yeniləməsi: yalnız istehsalçının rəsmi alətilə və qidası kəsilməyən mühitdə.

{{i:shield-alert}} 5. Təhlükəsizlik və ESD

{{i:zap}} ESD

Statik elektrik komponentləri görünməz şəkildə zədələyə bilər. Antistatik bilərzik, antistatik xalça; hissələri kənarlarından tutun.

{{i:plug}} Qidanı ayırın

Açmazdan əvvəl kabeli çıxarın, noutbukda batareyanı ayırın; güc düyməsini basıb qalıq enerjini boşaldın.

{{i:ban}} PSU-nu açmayın

İçindəki kondensatorlar söndürüldükdən sonra da təhlükəli gərginlik saxlayır — PSU bütöv dəyişdirilir.

{{i:lightbulb}}

Hissəni dəyişməzdən əvvəl zəmanəti yoxlayın (seriya nömrəsi ilə istehsalçı saytında) — korporativ cihazlarda çox vaxt istehsalçı növbəti iş günü pulsuz dəyişir.
