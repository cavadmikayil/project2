{{i:message-square-text}} Giriş: "Növbəti Sözü Təxmin Et"

ChatGPT, Claude, Gemini kimi Large Language Model-lərin (LLM) əsasında sadə görünən tapşırıq durur: verilmiş mətndən sonra növbəti token-i təxmin etmək. Bunu internet həcmində mətn üzərində milyardlarla parametrlə öyrənəndə model qrammatika, faktlar, kod yazmaq və mühakimə kimi qabiliyyətlər qazanır. Amma mahiyyətcə o, ehtimallar üzərində işləyən modeldir — verilənlər bazası deyil.

{{i:scissors}} 1. Token-lər

Model mətni söz-söz yox, token-lərlə görür — söz hissələri, simvollar, boşluqlar.

"Switch portu err-disabled oldu"
→ ["Switch", " port", "u", " err", "-", "disabled", " oldu"]   (təxmini bölgü)
{{i:languages}}

Dil fərqi: ingilis dilində bir söz çox vaxt 1 token-dir, Azərbaycan dilində isə söz daha çox token-ə bölünə bilər — eyni mətn daha "baha" və kontekstdə daha çox yer tutur.

{{i:banknote}}

Qiymət və limit token ilə ölçülür: giriş (input) və çıxış (output) token-ləri ayrıca hesablanır.

{{i:calculator}}

Hesablama: model rəqəmləri də token kimi görür — buna görə uzun hesablamalarda səhv edə bilər; dəqiq hesab üçün kod/alət istifadə etmək daha etibarlıdır.

{{i:git-merge}} 2. Transformer və Attention

Attention mexanizmi hər token-in digər bütün token-lərə nə qədər "diqqət" etməli olduğunu hesablayır. "Server çökdü, çünki o yaddaşsız qaldı" cümləsində "o" sözünü emal edərkən model "server"ə yüksək diqqət verir.

  1. Token-lər embedding vektorlarına (ədəd siyahısına) çevrilir, mövqe məlumatı əlavə olunur.

  2. Onlarla transformer bloku: attention + neural network qatları — məna tədricən zənginləşir.

  3. Sonda softmax bütün lüğət üzrə növbəti token-in ehtimallarını verir.

  4. Bir token seçilir, mətnə əlavə olunur və proses təkrarlanır — cavab token-token yaranır (streaming).

{{i:panel-left-open}} 5. Kontekst Pəncərəsi

Context window — modelin bir anda "gördüyü" token sayı: system prompt + söhbət tarixçəsi + əlavə etdiyiniz sənədlər + cavab.

{{i:brain}}

Yaddaş deyil: model söhbətləri "xatırlamır" — hər sorğuda bütün tarixçə yenidən göndərilir.

{{i:scissors}}

Limit dolanda köhnə mesajlar kəsilir və ya xülasələnir — erkən verilən təlimatlar "unudula" bilər.

{{i:file-text}}

Uzun sənədlər: ən vacib məlumatı aydın başlıqlarla verin; lazımsız log-ları əvvəlcə filtrləyin.

{{i:triangle-alert}} 6. Güclü və Zəif Tərəflər

{{i:circle-check}} Güclüdür

Mətn yazmaq və xülasə, tərcümə, kod və skript qaralaması, xəta mesajını izah etmək, konfiqurasiya nümunələri, beyin fırtınası.

{{i:circle-x}} Ehtiyatlı olun

Dəqiq faktlar, rəqəmlər, versiyaya xas əmrlər, hüquqi/tibbi məsələlər, son xəbərlər. Model əmin görünür, amma səhv ola bilər (hallucination) — həmişə mənbə ilə yoxlayın.
