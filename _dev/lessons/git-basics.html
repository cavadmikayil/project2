{{i:git-branch}} Giriş: Faylların "Zaman Maşını"

config_final.txt, config_final2.txt, config_son_versiya_DUZGUN.txt — tanış gəlir? Git faylların hər vəziyyətini (commit) yadda saxlayan paylanmış versiya nəzarəti sistemidir: kim, nə vaxt, nəyi, niyə dəyişdi — hamısı tarixçədədir və istənilən ana qayıtmaq olar.

{{i:git-commit-horizontal}} Commit

Layihənin müəyyən andakı "şəkli" + müəllif + mesaj. Unikal SHA hash ilə tanınır.

{{i:folder-git-2}} Repository

Layihə + onun bütün tarixçəsi (.git qovluğu).

{{i:cloud-upload}} Remote

GitHub, GitLab, Azure Repos — repo-nun serverdəki nüsxəsi. Git özü isə internetsiz də işləyir.

{{i:lightbulb}}

Staging sayəsində 5 dəyişdirilmiş fayldan yalnız 2-sini bir commit-ə qoymaq olar: hər commit bir məntiqi dəyişiklik olsun — "VLAN 30 əlavə edildi", "NTP server dəyişdi".

{{i:terminal}} 2. İlk Repository

# Bir dəfəlik ayar
git config --global user.name "Cavad Mikayil"
git config --global user.email "info@cavadmikayil.com"
git config --global init.defaultBranch main

mkdir network-configs && cd network-configs
git init
echo "hostname R1" > R1.cfg
git status                      # qırmızı: untracked
git add R1.cfg                  # və ya: git add .
git status                      # yaşıl: staged
git commit -m "R1 ilkin konfiqurasiya"

# GitHub-da boş repo yaradıb qoşmaq
git remote add origin git@github.com:cavadmikayil/network-configs.git
git push -u origin main

# Mövcud repo-nu yükləmək
git clone https://github.com/cavadmikayil/project2.git

.gitignore faylına git-ə düşməməli olanları yazın: *.log, .env, __pycache__/, parollu fayllar.

{{i:history}} 3. Tarixçəyə Baxmaq

git log --oneline --graph --all     # qısa, branch-larla qrafik
git log -p R1.cfg                   # faylın hər dəyişikliyi ilə
git log --author="Cavad" --since="2 weeks ago"

git diff                            # staged olmayan dəyişikliklər
git diff --staged                   # commit-ə gedəcək dəyişikliklər
git diff main..feature/vlan30       # iki branch arasında

git show a1b2c3d                    # bir commit-in tam məzmunu
git blame R1.cfg                    # hər sətri kim və hansı commit-də yazıb
{{i:pencil}}

Yaxşı commit mesajı əmr formasında və qısa olur: "Add VLAN 30 for guests", "Fix OSPF area on R2". "update", "fix", "asdf" kimi mesajlar 6 ay sonra heç nə demir.

{{i:git-fork}} 4. Branch-lar

Branch — commit-ə göstərici (pointer). Yeni ideya üzərində main-i pozmadan ayrıca xətdə işləmək imkanı verir.

git switch -c feature/vlan30        # yeni branch yarat və keç
# ... dəyişikliklər, commit-lər ...
git switch main
git merge feature/vlan30            # dəyişiklikləri main-ə birləşdir
git branch -d feature/vlan30        # birləşmiş branch-ı sil
git branch -a                       # bütün branch-lar (remote da daxil)

{{i:fast-forward}} Fast-forward

main-də yeni commit yoxdursa, göstərici sadəcə irəli sürüşür — əlavə commit yaranmır.

{{i:git-merge}} Merge commit

Hər iki tərəfdə yeni commit varsa, iki valideynli birləşmə commit-i yaranır.
