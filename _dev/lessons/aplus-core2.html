{{i:trash-2}}

{{i:smartphone}}

Mobil: ekran kilidi, biometrika, remote wipe, locator tətbiqləri, OS yeniləmələri.

{{i:bug}} 4. Malware Silmənin 7 Addımı (ardıcıllıq soruşulur!)

  1. Investigate and verify — malware əlamətlərini araşdır və təsdiqlə.

  2. Quarantine — yoluxmuş sistemi şəbəkədən təcrid et.

  3. Disable System Restore (Windows) — köhnə restore point-lərdə malware qalmasın.

  4. Remediate — anti-malware-i yenilə, skan et və sil (safe mode, pre-installation environment).

  5. Schedule scans and run updates.

  6. Enable System Restore və yeni təmiz restore point yarat.

  7. Educate the end user — istifadəçini maarifləndir.

{{i:lightbulb}}

Əlamətlər: brauzer yönləndirmələri, saxta antivirus pəncərələri, yavaşlıq, naməlum proseslər, deaktiv edilmiş antivirus, fayl uzantılarının dəyişməsi (ransomware), dostlara göndərilmiş spam.
