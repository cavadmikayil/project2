{{i:triangle-alert}} 2. 169.254.x.x — APIPA

Windows DHCP serverindən cavab ala bilmədikdə özünə 169.254.0.0/16 aralığından ünvan verir (APIPA). Bu ünvanla heç bir yerə çıxmaq olmur. Deməli, problem kompüter ilə DHCP server arasındadır.

  1. Kabel / Wi-Fi qoşuludurmu? Port LED-i yanırmı?

  2. ipconfig /release və ipconfig /renew — yenidən sorğu.

  3. Eyni otaqda başqalarında da belədirsə — switch portu, VLAN və ya DHCP server/scope dolub (şəbəkə komandasına eskalasiya).

  4. Yalnız bir kompüterdədirsə — port security, 802.1X, NIC driver-i və ya port err-disabled ola bilər.

ipconfig /flushdns          # DNS keşi
ipconfig /release
ipconfig /renew
arp -d *                    # ARP keşi (admin)
netsh winsock reset         # Winsock kataloqu (admin, restart tələb edir)
netsh int ip reset          # TCP/IP parametrləri (admin, restart tələb edir)

Test-NetConnection intranet.corp.example.az -Port 443   # konkret porta qoşulma testi

winsock reset və int ip reset "son çarə"dir: statik IP parametrlərini və bəzi VPN/proxy parametrlərini silə bilər. Əvvəl ipconfig/ping ilə problemin yerini tapın.
