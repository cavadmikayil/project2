{{i:clipboard-list}} 2. Facts və Show Əmrləri

# inventory_report.yml
- name: Cihaz inventarı
  hosts: all
  gather_facts: false
  tasks:
    - name: Facts topla
      cisco.ios.ios_facts:
        gather_subset: min

    - name: Versiya çap et
      ansible.builtin.debug:
        msg: "{{ inventory_hostname }}: {{ ansible_net_model }} / {{ ansible_net_version }} / {{ ansible_net_serialnum }}"

    - name: OSPF qonşuları
      cisco.ios.ios_command:
        commands: show ip ospf neighbor
      register: ospf

    - ansible.builtin.debug:
        var: ospf.stdout_lines[0]

{{i:file-cog}} 3. Konfiqurasiya: ios_config və Resource Modullar

- name: Standart xidmətlər
  hosts: all
  gather_facts: false
  tasks:
    - name: NTP və logging
      cisco.ios.ios_config:
        lines:
          - ntp server 10.0.0.10
          - logging host 10.0.0.50
        save_when: modified          # yalnız dəyişiklik olanda write memory

    - name: ACL — ardıcıllıq vacibdir
      cisco.ios.ios_config:
        parents: ip access-list standard MGMT
        lines:
          - permit 10.0.0.0 0.0.0.255
          - deny any log
        before: no ip access-list standard MGMT
        match: exact
- name: VLAN-lar — istənilən vəziyyət
  hosts: switches
  gather_facts: false
  tasks:
    - cisco.ios.ios_vlans:
        config:
          - { vlan_id: 10, name: MUHASIBAT }
          - { vlan_id: 20, name: IT }
          - { vlan_id: 30, name: GUEST }
        state: merged            # merged | replaced | overridden | deleted

    - cisco.ios.ios_l2_interfaces:
        config:
          - name: GigabitEthernet1/0/1
            mode: access
            access: { vlan: 10 }
        state: merged

Resource modullar strukturlaşdırılmış məlumatla işləyir və idempotentdir. overridden — siyahıda olmayan VLAN-ları silir (ehtiyatla!).

{{i:hard-drive-download}} 4. Konfiqurasiya Backup-ı

- name: Gecəlik backup
  hosts: all
  gather_facts: false
  tasks:
    - cisco.ios.ios_config:
        backup: true
        backup_options:
          dir_path: ./backups
          filename: "{{ inventory_hostname }}.cfg"

# cron / CI: hər gecə
ansible-playbook -i inventory.yml backup.yml --vault-password-file ~/.vault_pass
cd backups && git add -A && git commit -m "backup $(date +%F)" || true

{{i:clipboard-check}} 5. Uyğunluq Yoxlaması

- name: Təhlükəsizlik standartı
  hosts: all
  gather_facts: false
  tasks:
    - cisco.ios.ios_command:
        commands: show running-config
      register: run

    - name: Telnet bağlı olmalıdır
      ansible.builtin.assert:
        that: "'transport input ssh' in run.stdout[0]"
        fail_msg: "{{ inventory_hostname }}: VTY-də yalnız SSH olmalıdır"
      ignore_errors: true

    - name: Parollar şifrələnməlidir
      ansible.builtin.assert:
        that: "'service password-encryption' in run.stdout[0]"
      ignore_errors: true
{{i:lightbulb}}

Bu yoxlamaları --check rejimli konfiqurasiya playbook-u ilə birləşdirsəniz, hansı cihazın standartdan kənara çıxdığını (drift) hər gün avtomatik görərsiniz.
