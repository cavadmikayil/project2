{{i:network}} Giriş: STP Nədir?

Spanning Tree Protocol (STP, IEEE 802.1D) Layer 2 şəbəkədə switch-lər arasındakı fiziki dövrələri (loop) aşkarlayıb topologiyanı məntiqi ağaca (tree) çevirir. Loop olduqda Ethernet frame-ləri sonsuz dövr edir (broadcast storm), MAC cədvəli qeyri-sabit olur və şəbəkə saniyələr içində dayanır. STP artıq yolları bloklayır, amma itirmir — əsas yol kəsiləndə ehtiyat yol avtomatik aktivləşir.

{{i:repeat}} Broadcast storm

L2 frame-də TTL yoxdur — loop-dakı broadcast heç vaxt ölmür.

{{i:copy}} Duplicate frame

Eyni frame hədəfə bir neçə yoldan çatır.

{{i:shuffle}} MAC flapping

Switch eyni MAC-ı növbə ilə fərqli portlarda görür.

{{i:crown}} 1. Root Bridge Seçkisi və Cost

  1. Bridge ID = priority (defolt 32768, 4096-lıq addımlarla) + VLAN ID (extended system ID) + MAC. Ən kiçik BID Root Bridge olur.

  2. Hər qeyri-root switch Root-a ən kiçik ümumi cost-lu portu Root Port seçir.

  3. Hər seqmentdə Root-a ən yaxın switch-in portu Designated Port olur.

  4. Qalan portlar bloklanır (Alternate/Blocking).

{{i:users}} 2. Port Rolları

{{i:crown}}

Root Bridge: ən kiçik Bridge ID-li switch; bütün portları designated-dir.

{{i:door-open}}

Root Port: qeyri-root switch-də Root Bridge-ə ən az cost-lu port (hər switch-də bir).

{{i:circle-check}}

Designated Port: hər seqmentdə trafiki ötürən seçilmiş port (forwarding).

{{i:ban}}

Alternate / Blocking: loop yaratmamaq üçün trafik ötürməyən ehtiyat port. RSTP-də həmçinin Backup rolu var.

{{i:timer}} 3. Port Vəziyyətləri

Klassik STP portu forwarding-ə keçirməzdən əvvəl bir neçə mərhələdən keçirir — bu 30–50 saniyə çəkir (forward delay 15 s × 2, max age 20 s). RSTP bu prosesi saniyələrə endirir.

{{i:layers}} 4. STP Növləri

PVST+

Cisco-ya məxsus, hər VLAN üçün ayrıca 802.1D instansı. Köhnə Cisco IOS-larda defolt.

Rapid-PVST+

RSTP-nin VLAN-başına versiyası: saniyələr içində konvergensiya. Müasir tövsiyə olunan rejim.

MSTP (802.1s)

VLAN-ları bir neçə instansda qruplaşdırır — böyük şəbəkələrdə CPU yükünü azaldır, multi-vendor.

{{i:terminal}} 5. Praktiki Əmrlər

Switch(config)# spanning-tree mode rapid-pvst
Switch(config)# spanning-tree vlan 10 priority 4096
Switch(config)# spanning-tree vlan 20 root primary        ! və ya root secondary
Switch(config)# interface FastEthernet0/1
Switch(config-if)# spanning-tree portfast
Switch(config-if)# spanning-tree bpduguard enable
Switch(config-if)# spanning-tree cost 10                  ! yol seçiminə təsir

Rapid-PVST+ rejimini aktivləşdirir, VLAN 10 üçün bu switch-i Root Bridge edir, son istifadəçi portunda PortFast və BPDU Guard qoşur. Root Bridge-i həmişə özünüz seçin — təsadüfi köhnə switch-in root olması trafiki pis yola yönəldir.

show spanning-tree
show spanning-tree vlan 10
show spanning-tree interface FastEthernet0/1
show spanning-tree summary
show spanning-tree root

"This bridge is the root" — bu switch Root Bridge-dir. Port rolları: Root, Desg, Altn; vəziyyətlər: FWD, BLK/LRN.

PortFast, BPDU Guard, Root Guard və Loop Guard kimi qoruma mexanizmləri Rapid PVST+ və STP Qoruma dərsində ətraflı izah olunur.
