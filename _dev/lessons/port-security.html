{{i:lock-keyhole}} Giriş: Port Security Nədir?

Port Security switch portuna qoşula bilən cihazların sayını və/və ya MAC ünvanlarını məhdudlaşdıran Layer 2 təhlükəsizlik funksiyasıdır. O, MAC flooding hücumlarının və icazəsiz cihazların (şəxsi router, noutbuk) şəbəkəyə qoşulmasının qarşısını alır. İcazə verilən MAC sayı aşıldıqda və ya naməlum MAC görünəndə konfiqurasiya edilmiş violation rejiminə uyğun tədbir görülür.

{{i:skull}} MAC flooding

Hücumçu minlərlə saxta MAC göndərir, CAM cədvəli dolur və switch hub kimi hər şeyi yaymağa başlayır.

{{i:router}} Rogue cihaz

İstifadəçi rozetkaya öz Wi-Fi router-ini qoşur — IT-nin xəbəri olmadan açıq şəbəkə.

{{i:plug}} Yalnız access port

Port security access (və ya statik trunk) portda konfiqurasiya olunur, dinamik DTP portunda yox.

{{i:book-open}} 1. MAC Ünvanlarının Öyrənilməsi

{{i:keyboard}}

Static: switchport port-security mac-address aaaa.bbbb.cccc — əl ilə yazılır, config-də saxlanır.

{{i:refresh-cw}}

Dynamic: defolt — portdan öyrənilir, amma switch yenidən başlayanda itir.

{{i:pin}}

Sticky: dinamik öyrənilən MAC-lar avtomatik running-config-ə yazılır; write memory ilə daimi olur.

{{i:hash}}

Maximum: defolt 1. IP telefon + kompüter üçün adətən 2 (voice VLAN-da telefon ayrıca sayılır).

{{i:terminal}} 3. Praktiki Əmrlər

Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum 2
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security violation restrict
Switch(config-if)# switchport port-security aging time 60

Portda maksimum 2 MAC, öyrənilənlər sticky olaraq saxlanır, pozuntu zamanı "restrict". switchport port-security əmri olmadan digər ayarlar işləmir — ən çox unudulan addım.

show port-security
show port-security interface FastEthernet0/1
show port-security address
show interfaces status err-disabled
show errdisable recovery

interface çıxışında: Port Status (Secure-up / Secure-shutdown), Violation Mode, Maximum MAC, Last Source Address və Security Violation Count.

{{i:life-buoy}} 4. err-disabled Portun Bərpası

! Əl ilə: əvvəlcə səbəbi aradan qaldırın (icazəsiz cihazı ayırın)
Switch(config)# interface FastEthernet0/1
Switch(config-if)# shutdown
Switch(config-if)# no shutdown

! Avtomatik: 5 dəqiqədən sonra portu yenidən aç
Switch(config)# errdisable recovery cause psecure-violation
Switch(config)# errdisable recovery interval 300
{{i:lightbulb}}

Port security MAC-ı saxtalaşdırmağa (spoofing) qarşı tam qoruma deyil. Güclü həll — 802.1X (hər cihazın autentifikasiyası). Port security isə sadə və hər switch-də mövcud olan ilk müdafiə xəttidir.
