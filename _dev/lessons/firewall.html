{{i:brick-wall}} Giriş: ACL Kifayət Etmirsə

ACL hər paketə ayrıca baxır və bağlantının vəziyyətini "yadda saxlamır". Daxildən internetə gedən veb sorğusunun cavabını buraxmaq üçün ACL-də geniş portları açmaq lazım gəlir. Firewall isə bağlantıları izləyir: daxildən başlanan sessiyanın cavabını avtomatik buraxır, xaricdən başlanan icazəsiz bağlantını isə bloklayır.

{{i:scale}} 1. Stateless və Stateful Filtrləmə

Stateless (ACL)Stateful (firewall)
Qərar əsasıHər paketin başlığı ayrıcaPaket + bağlantı cədvəli (state table)
Cavab trafikiƏl ilə açılmalıdırAvtomatik buraxılır
Saxta "cavab" paketləriKeçə bilərCədvəldə sessiya yoxdursa atılır
ResursAzÇox (hər sessiya yaddaşda)

  1. PC 10.1.1.10:51000 → 93.184.216.34:443 SYN göndərir. Firewall siyasətə baxır, icazə var — sessiyanı cədvələ yazır.

  2. Server 93.184.216.34:443 → 10.1.1.10:51000 SYN-ACK qaytarır. Firewall cədvəldə uyğun sessiyanı tapır və buraxır.

  3. Xaricdən kimsə 10.1.1.10-a yeni bağlantı açmağa çalışır. Cədvəldə sessiya yoxdur, xaricdən daxilə siyasət də icazə vermir — paket atılır.

{{i:shield-check}} 3. Next-Generation Firewall (NGFW)

Klassik firewall IP və portlara baxır. NGFW (Cisco Secure Firewall, Palo Alto, Fortinet) paketin içinə də baxır:

{{i:app-window}}

Tətbiq tanıma (AVC): TCP 443 üzərindən gedən YouTube, Teams və ya torrent-i fərqləndirir.

{{i:user-check}}

İstifadəçi əsaslı siyasət: IP əvəzinə Active Directory qrupuna görə qayda.

{{i:link}}

URL filtrləmə: kateqoriyaya görə saytları bloklamaq (qumar, zərərli saytlar).

{{i:bug}}

Malware müdafiəsi (AMP): fayl reputasiyası və sandbox analizi.

{{i:shield-alert}}

İnteqrasiya olunmuş IPS: məlum hücum imzalarını real vaxtda bloklayır.

{{i:fingerprint}} İmza əsaslı

Məlum hücumların nümunələri ilə müqayisə — dəqiqdir, amma yeni (zero-day) hücumları görmür. İmzalar mütəmadi yenilənməlidir.

{{i:activity}} Anomaliya əsaslı

Normal trafik profilindən kənarlaşmanı axtarır — yeni hücumları tuta bilər, amma yanlış həyəcan (false positive) daha çoxdur.

{{i:terminal}} 5. Laboratoriya: Zone-Based Firewall (IOS)

Cisco router-in özü də stateful firewall ola bilər. ZBF-də interfeyslər zonalara bölünür və zonalar arası trafik siyasət ilə idarə olunur.

R1(config)# zone security INSIDE
R1(config)# zone security OUTSIDE

R1(config)# class-map type inspect match-any IN-TO-OUT
R1(config-cmap)# match protocol http
R1(config-cmap)# match protocol https
R1(config-cmap)# match protocol dns
R1(config-cmap)# match protocol icmp

R1(config)# policy-map type inspect PM-IN-TO-OUT
R1(config-pmap)# class type inspect IN-TO-OUT
R1(config-pmap-c)# inspect
R1(config-pmap)# class class-default
R1(config-pmap-c)# drop log

R1(config)# zone-pair security ZP-IN-OUT source INSIDE destination OUTSIDE
R1(config-sec-zone-pair)# service-policy type inspect PM-IN-TO-OUT

R1(config)# interface GigabitEthernet0/0
R1(config-if)# zone-member security INSIDE
R1(config)# interface GigabitEthernet0/1
R1(config-if)# zone-member security OUTSIDE

R1# show policy-map type inspect zone-pair sessions

inspect sessiyanı izləyir və cavabı avtomatik buraxır. OUTSIDE → INSIDE üçün zone-pair olmadığından xaricdən başlanan bütün trafik atılır. Eyni zonadakı interfeyslər arasında trafik sərbəst keçir, zonası olmayan interfeyslə zonalı interfeys arasında isə keçmir.
