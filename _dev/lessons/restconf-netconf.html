{{i:list-tree}} 1. YANG: Məlumat Modeli

module example-vlan {
  namespace "urn:example:vlan";
  prefix ev;

  container vlans {
    list vlan {
      key "id";
      leaf id   { type uint16 { range "1..4094"; } }
      leaf name { type string { length "1..32"; } }
      leaf enabled { type boolean; default true; }
    }
  }
}

YANG məlumatın strukturunu və qaydalarını müəyyən edir: VLAN ID-si 1–4094 aralığında olmalıdır — 5000 göndərsəniz, cihaz konfiqurasiyanı tətbiq etmədən rədd edir.

{{i:box}} container

Qovluq kimi qruplaşdırma.

{{i:list}} list + key

Təkrarlanan elementlər (interfeyslər, VLAN-lar), açarla tanınır.

{{i:leaf}} leaf

Tək dəyər: ad, IP, MTU.

{{i:library}} Model mənbələri

IETF və OpenConfig (vendor-neytral), native (Cisco-IOS-XE-native — bütün CLI imkanları).

{{i:terminal}} 2. NETCONF

! IOS XE-də aktivləşdirmək
netconf-yang
restconf
ip http secure-server
username netadmin privilege 15 secret S3cret!

  1. Klient SSH ilə 830 portuna qoşulur (netconf subsystem).

  2. Hər iki tərəf <hello> mesajı ilə capabilities-ləri (dəstəklənən modellər və imkanlar) mübadilə edir.

  3. Klient <rpc> göndərir, cihaz <rpc-reply> ilə cavab verir.

  4. Datastore-lar: running, startup, candidate (dəyişiklik əvvəlcə burada yığılır, sonra commit).

{{i:globe}} 3. RESTCONF

# Interfeysləri oxumaq (IETF modeli)
curl -sk -u netadmin:S3cret! \
  -H "Accept: application/yang-data+json" \
  https://10.10.0.254/restconf/data/ietf-interfaces:interfaces

# Loopback yaratmaq (PUT idempotentdir)
curl -sk -u netadmin:S3cret! -X PUT \
  -H "Content-Type: application/yang-data+json" \
  https://10.10.0.254/restconf/data/ietf-interfaces:interfaces/interface=Loopback100 \
  -d '{"ietf-interfaces:interface": {
        "name": "Loopback100",
        "type": "iana-if-type:softwareLoopback",
        "enabled": true,
        "ietf-ip:ipv4": {"address": [{"ip": "100.100.100.1", "netmask": "255.255.255.255"}]}
      }}'

URL strukturu: /restconf/data/<modul>:<container>/<list>=<açar>. Media tipi application/yang-data+json-dır, adi application/json yox.

{{i:code}} 4. Python: ncclient

from ncclient import manager      # pip install ncclient

FILTER = """
<filter>
  <interfaces xmlns="urn:ietf:params:xml:ns:yang:ietf-interfaces">
    <interface><name/><enabled/></interface>
  </interfaces>
</filter>"""

CONFIG = """
<config>
  <native xmlns="http://cisco.com/ns/yang/Cisco-IOS-XE-native">
    <hostname>EDGE-R1</hostname>
  </native>
</config>"""

with manager.connect(host="10.10.0.254", port=830, username="netadmin",
                     password="S3cret!", hostkey_verify=False) as m:
    print([c for c in m.server_capabilities if "ietf-interfaces" in c][:1])
    reply = m.get_config(source="running", filter=FILTER)
    print(reply.xml[:500])
    m.edit_config(target="running", config=CONFIG)    # candidate varsa: target="candidate" + m.commit()

Lab üçün hostkey_verify=False rahatdır; production-da cihazın SSH açarını known_hosts-a əlavə edin.

 encoding encode-kvgpb
 filter xpath /process-cpu-ios-xe-oper:cpu-usage/cpu-utilization/five-seconds
 stream yang-push
 update-policy periodic 1000          ! santisaniyə = 10 saniyə
