{{i:screen-share}} Giriş: Yerindən Tərpənmədən Kömək

Müasir helpdesk müraciətlərin çoxunu uzaqdan həll edir: istifadəçinin ekranını görmək, idarə etmək, əmr icra etmək. Bu sürətlidir, amma eyni zamanda böyük təhlükəsizlik riskidir — saxtakarlar da "Microsoft dəstəyi" adı ilə uzaqdan giriş istəyirlər.

{{i:wrench}} 1. Alətlərin Müqayisəsi

AlətNövHarada uyğundur
Quick AssistWindows-a daxildir, istifadəçi kodu təsdiqləyirTez, quraşdırmasız kömək (Microsoft hesabı ilə)
Remote Desktop (RDP)Ayrıca sessiya — istifadəçi ekranı bağlanırServerlər, admin işləri
Intune Remote HelpEntra ID ilə inteqrasiya, rol əsaslıMicrosoft 365 mühitində korporativ dəstək
TeamViewer / AnyDeskKommersiya, NAT arxasından işləyirŞirkət şəbəkəsindən kənar istifadəçilər
RMM (NinjaOne, Datto və s.)Agent əsaslı, yüzlərlə cihazMSP-lər, geniş park idarəetməsi

{{i:monitor}} 2. RDP ilə İşləmək

mstsc /v:srv-app01.corp.example.az          # qoşulmaq
mstsc /v:srv-app01 /admin                     # admin sessiyası
query user /server:srv-app01                  # serverdəki sessiyalar
logoff 3 /server:srv-app01                    # asılı qalmış sessiyanı bağlamaq

Test-NetConnection srv-app01 -Port 3389       # port açıqdırmı
XətaSəbəb
"Remote Desktop can't connect"RDP söndürülüb, firewall, port 3389 bağlıdır, kompüter yuxu rejimindədir
"The connection was denied because the user account is not authorized"İstifadəçi Remote Desktop Users qrupunda deyil
CredSSP / NLA xətasıKlient və ya serverdə yeniləmələr uyğunsuzdur — hər ikisini yeniləyin

{{i:shield-alert}} 3. Təhlükəsizlik Qaydaları

{{i:ban}}

RDP-ni internetə açmayın. 3389 portu daima brute-force və ransomware hücumlarına məruz qalır — VPN, RD Gateway və ya ZTNA arxasında saxlayın.

{{i:list-checks}}

Təsdiqlənmiş alətlər siyahısı: şirkət yalnız bir-iki aləti icazəli edir; digərləri bloklanır.

{{i:user-check}}

İstifadəçi razılığı: sessiya yalnız istifadəçinin təsdiqi ilə açılır.

{{i:scroll-text}}

Audit: kim, nə vaxt, hansı kompüterə qoşuldu — log saxlanılır, mümkünsə sessiya yazılır.

{{i:triangle-alert}}

İstifadəçilərə öyrədin: real IT heç vaxt gözlənilmədən zəng edib AnyDesk quraşdırmağı istəmir. "Bankdan", "Microsoft-dan" zəng edib uzaqdan giriş istəyənlər — tech support scam-dır.

{{i:handshake}} 4. Uzaqdan Sessiyanın Etikası

  1. Qoşulmazdan əvvəl icazə alın və açıq şəxsi sənədləri/çatları bağlamağı xahiş edin.

  2. Nə etdiyinizi səsli izah edin — istifadəçi həm öyrənir, həm də rahat olur.

  3. Yalnız problemlə bağlı fayl və proqramlara toxunun.

  4. Bitəndə istifadəçi ilə birlikdə yoxlayın, sessiyanı bağlayın və ticket-ə qeyd edin.

{{i:terminal}} 5. Ekran Paylaşmadan Uzaqdan Əmrlər

Bir çox iş üçün istifadəçinin ekranına ehtiyac yoxdur — PowerShell Remoting ilə diaqnostika onun işinə mane olmur.

Enter-PSSession -ComputerName PC-MUH-014        # interaktiv sessiya

Invoke-Command -ComputerName PC-MUH-014 -ScriptBlock {
    Get-CimInstance Win32_OperatingSystem | Select Caption, LastBootUpTime
    Get-PSDrive C | Select Used, Free
    Get-Service Spooler | Restart-Service -PassThru
}

Get-CimInstance -ComputerName PC-MUH-014 Win32_ComputerSystem | Select UserName, Model

WinRM domen kompüterlərində GPO ilə aktivləşdirilir. Əmrlər sizin admin hesabınızla icra olunur — hər hərəkət audit log-da görünür.
