{{i:signpost}} Giriş: Nə vaxt statik marşrut?

Statik marşrut administratorun əl ilə yazdığı marşrutdur. Router onu dəyişmir və qonşulara elan etmir. Kiçik şəbəkələrdə, tək çıxışlı (stub) filiallarda və internetə defolt çıxış üçün idealdır. İnzibati məsafəsi (AD) 1-dir, yəni dinamik protokollardan daha etibarlı sayılır.

{{i:circle-check}} Üstünlüklər

CPU/bant genişliyi sərf etmir, proqnozlaşdırıla biləndir, təhlükəsizdir (heç nə elan olunmur).

{{i:circle-x}} Çatışmazlıqlar

Topologiya dəyişəndə avtomatik uyğunlaşmır; böyük şəbəkələrdə idarə etmək çətindir.

Next-hop, çıxış interfeysi, yoxsa hər ikisi?

{{i:arrow-right}}

Next-hop IP: router next-hop-u tapmaq üçün cədvəldə ikinci axtarış edir (recursive lookup).

{{i:cable}}

Çıxış interfeysi: point-to-point (serial) linklər üçün uyğundur; Ethernet-də tövsiyə olunmur (ARP yükü).

{{i:circle-check}}

Fully specified: interfeys + next-hop — Ethernet üçün ən etibarlı variant.

{{i:target}}

Longest prefix match: 192.168.2.50-yə gedən paket üçün həm 0.0.0.0/0, həm də 192.168.2.0/24 uyğundur — router həmişə ən uzun prefiksli (/24) marşrutu seçir. AD yalnız eyni prefiks müxtəlif mənbələrdən öyrənildikdə müqayisə olunur.

{{i:terminal}} 3. Praktiki Əmrlər

R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
R1(config)# ip route 192.168.3.0 255.255.255.0 GigabitEthernet0/1 10.0.0.2
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

Next-hop ilə standart marşrut, fully specified marşrut və internetə defolt marşrut.

R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
R1(config)# ip route 0.0.0.0 0.0.0.0 198.51.100.1 5

Əsas ISP (AD 1) işləyərkən ikinci marşrut cədvələ düşmür. Əsas link qopduqda AD 5 olan ehtiyat marşrut avtomatik aktivləşir.

R1(config)# ipv6 unicast-routing
R1(config)# ipv6 route 2001:db8:2::/64 2001:db8:ffff::2
R1(config)# ipv6 route ::/0 GigabitEthernet0/1 fe80::2

IPv6 statik marşrut və link-local next-hop ilə defolt marşrut (link-local istifadə olunduqda çıxış interfeysi mütləqdir).

show ip route static
show ip route 192.168.2.0
show ipv6 route static
ping 192.168.2.1
traceroute 192.168.2.1

Yalnız statik marşrutlar, konkret şəbəkə üçün seçilmiş marşrut, IPv6 statik marşrutlar və yolun yoxlanması.
