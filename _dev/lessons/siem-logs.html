{{i:scroll-text}} Giriş: Log Olmayan Yerdə Sübut Yoxdur

Firewall, server, AD, EDR, bulud — hər biri gündə milyonlarla qeyd yaradır. SIEM (Security Information and Event Management) onları bir yerə toplayır, normallaşdırır, əlaqələndirir (correlation) və şübhəli ardıcıllıqlarda xəbərdarlıq yaradır. Nümunələr: Microsoft Sentinel, Splunk, Elastic Security, Wazuh (açıq mənbə).

{{i:database}} 2. Hansı Log-lar Toplanmalıdır?

{{i:building}}

Identity: Domain Controller Security log, Entra ID sign-in log-ları.

{{i:laptop}}

Endpoint: EDR telemetriyası, Sysmon, PowerShell Script Block logging.

{{i:brick-wall}}

Şəbəkə: firewall, VPN, proxy/DNS log-ları.

{{i:mail}}

Email: phishing aşkarlamaları, klik hadisələri.

{{i:cloud}}

Cloud: Azure Activity, AWS CloudTrail — kim nə resursu dəyişdi.

{{i:app-window}}

Tətbiqlər: veb server, WAF, kritik biznes tətbiqləri.

{{i:clock}}

Bütün mənbələrdə vaxt sinxron olmalıdır (NTP) — əks halda hadisələrin ardıcıllığını qurmaq mümkün olmur. Log-ların saxlanma müddəti (retention) qanun və siyasətə uyğun olmalıdır (tez-tez 90 gün "isti", 1 il arxiv).

{{i:target}} 4. Aşkarlama Məntiqi və MITRE ATT&CK

Tək hadisə çox vaxt heç nə demir; ardıcıllıq danışır. MITRE ATT&CK hücumçuların taktika və texnikalarını kataloqlaşdırır — aşkarlama qaydaları çox vaxt ona bağlanır.

SsenariKorrelyasiya qaydası
Password sprayingBir IP-dən 15 dəqiqədə 20+ fərqli hesaba 4625
Uğurlu brute forceEyni hesaba çoxlu 4625, ardınca 4624
Impossible travelBir hesab 30 dəqiqə fərqlə Bakı və başqa qitədən daxil olur
Privilege escalationİş saatından kənar Domain Admins-ə üzv əlavəsi
Şübhəli PowerShellOffice prosesindən yaranan powershell.exe -enc ...

{{i:terminal}} 5. Sorğu Nümunələri

SecurityEvent
| where EventID == 4625 and TimeGenerated > ago(1h)
| summarize Failures = count(), Accounts = dcount(TargetAccount) by IpAddress
| where Accounts > 20
| order by Failures desc
index=wineventlog EventCode=4625 earliest=-1h
| stats count AS failures dc(TargetUserName) AS accounts BY IpAddress
| where accounts > 20
| sort - failures
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625; StartTime=(Get-Date).AddHours(-1)} |
  ForEach-Object { $_.Properties[19].Value } |
  Group-Object | Sort-Object Count -Descending | Select -First 10 Count, Name

4625 hadisəsinin 19-cu xassəsi mənbə IP ünvanıdır. SIEM-siz kiçik mühitdə ilkin baxış üçün faydalıdır.

{{i:list-checks}} 6. Alert Triage Addımları

  1. Kontekst: hansı istifadəçi, cihaz, IP? Bu istifadəçi üçün normal davranış nədir?

  2. Zənginləşdirmə: IP reputasiyası, geolokasiya, hash-ın VirusTotal nəticəsi.

  3. Əhatə: eyni göstərici (IOC) başqa cihazlarda da varmı?

  4. Qərar: true positive → incident response; false positive → qaydanı tənzimlə və səbəbini qeyd et.
