{{i:webhook}} Giriş: Proqramların Bir-biri ilə Danışığı

API (Application Programming Interface) — bir proqramın digərinə xidmət təklif etdiyi razılaşdırılmış interfeysdir. REST isə HTTP üzərində qurulan ən geniş yayılmış API üslubudur: hər şey resursdur (/devices, /devices/42/interfaces), resurslar URL ilə tanınır və HTTP metodları ilə idarə olunur. Cisco Catalyst Center, Meraki, FortiGate, NetBox, AWS — hamısının REST API-si var.

{{i:unplug}} Stateless

Hər sorğu özündə bütün lazımi məlumatı (token daxil) daşıyır; server əvvəlki sorğunu yadda saxlamır.

{{i:link}} URI

https://api.example.com/v1/devices?site=baku&limit=50 — base URL, versiya, resurs, query parametrləri.

{{i:braces}} JSON

Məlumat adətən JSON formatında göndərilir və qaytarılır.

{{i:key-round}} 3. Autentifikasiya Üsulları

{{i:user}}

Basic auth: Authorization: Basic base64(user:pass) — yalnız HTTPS üzərində; base64 şifrələmə deyil.

{{i:key}}

API key: X-Cisco-Meraki-API-Key: ... və ya Authorization: Bearer ... — uzunmüddətli, ehtiyatla saxlanmalı.

{{i:ticket}}

Token: əvvəlcə login endpoint-dən token alınır (Catalyst Center: X-Auth-Token), sonra hər sorğuda göndərilir; müddəti bitir.

{{i:shield-check}}

OAuth 2.0: client credentials ilə qısamüddətli access token — Microsoft Graph, Webex, müasir SaaS API-lər.

# Header və token ilə
curl -s -H "Authorization: Token $NETBOX_TOKEN" -H "Accept: application/json" \
  "https://netbox.local/api/dcim/devices/?site=baku&limit=5" | jq '.results[].name'

# POST — JSON body ilə

curl -i ...        # cavab header-lərini və status kodunu da göstər

{{i:code}} 5. Python requests

import os, requests

BASE = "https://netbox.local/api"
s = requests.Session()
s.headers.update({
    "Authorization": f"Token {os.environ['NETBOX_TOKEN']}",
    "Accept": "application/json",
})

# GET + səhifələmə (pagination)
url = f"{BASE}/dcim/devices/?site=baku&limit=100"
devices = []
while url:
    r = s.get(url, timeout=10)
    r.raise_for_status()                  # 4xx/5xx → istisna
    data = r.json()
    devices += data["results"]
    url = data["next"]                    # növbəti səhifə və ya None
print(len(devices), "cihaz")

# POST
r = s.post(f"{BASE}/ipam/vlans/", json={"vid": 30, "name": "GUEST", "status": "active"}, timeout=10)
if r.status_code == 201:
    print("yaradıldı, id =", r.json()["id"])
else:
    print(r.status_code, r.text)

json= parametri body-ni JSON-a çevirir və Content-Type-ı özü qoyur. Daxili şəbəkədə öz sertifikatı olan cihazlar üçün verify=False əvəzinə CA faylını göstərin: verify="/etc/ssl/company-ca.pem".
