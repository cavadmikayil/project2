{{i:wifi}} Giriş: Simsiz Şəbəkələr

Wireless LAN (WLAN) IEEE 802.11 standartlarına əsaslanır və məlumatı radio dalğaları ilə ötürür. Simsiz mühit paylaşılan və half-duplexdir: eyni kanalda eyni anda yalnız bir cihaz ötürə bilər, toqquşmaların qarşısı CSMA/CA ilə alınır.

{{i:tag}} SSID

Şəbəkənin adı (məs. "Kollec-WiFi"). Bir AP bir neçə SSID yayımlaya bilər.

{{i:hash}} BSSID

AP-nin radio interfeysinin MAC ünvanı — hər BSS-in unikal identifikatoru.

{{i:radio-tower}} BSS / ESS

BSS — bir AP və onun müştəriləri. ESS — eyni SSID-li bir neçə AP; müştəri AP-lər arasında roaming edir.

{{i:radio}} 2. Tezliklər və Kanallar

{{i:signal}} 2.4 GHz

Daha uzağa çatır və divarlardan yaxşı keçir, amma yalnız 3 üst-üstə düşməyən kanal var: 1, 6, 11. Qonşu AP-lər bu kanallara paylanmalıdır.

{{i:gauge}} 5 GHz

Daha çox üst-üstə düşməyən kanal və daha yüksək sürət, amma daha qısa əhatə dairəsi.

{{i:zap}} 6 GHz (Wi-Fi 6E)

Yeni, sıxlığı az diapazon; yalnız 6E dəstəkləyən cihazlar istifadə edə bilər. WPA3 tələb olunur.

{{i:key-round}} Personal (PSK / SAE)

Hamı üçün ortaq parol. WPA3-Personal SAE istifadə edir və parolu offline lüğət hücumlarına qarşı qoruyur.

{{i:user-check}} Enterprise (802.1X)

Hər istifadəçi öz hesabı ilə RADIUS server vasitəsilə autentifikasiya olunur. Müəssisələr üçün doğru seçimdir.

{{i:terminal}} 5. Konfiqurasiya

  1. WLANs → Create New: profil adı və SSID daxil edin (məs. "Kollec-WiFi"), WLAN ID seçin.

  2. General: Status = Enabled; Interface = müştəri VLAN-ına bağlı dinamik interfeys.

  3. Security → Layer 2: WPA2/WPA3 seçin; Personal üçün PSK/SAE parolu, Enterprise üçün 802.1X.

  4. Security → AAA Servers: Enterprise rejimində RADIUS serveri seçin.

  5. Apply düyməsini basın və müştəri qoşulmasını yoxlayın.

Switch(config)# interface GigabitEthernet0/5
Switch(config-if)# description Lightweight-AP-01
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 99
Switch(config-if)# spanning-tree portfast
Switch(config-if)# power inline auto

Local rejimli lightweight AP idarəetmə VLAN-ında access porta qoşulur; müştəri trafiki CAPWAP tunelində WLC-yə gedir. PoE ilə AP-yə enerji verilir.

show wlan summary
show ap summary
show client summary
show interface summary

WLAN-ların siyahısı və statusu, WLC-yə qoşulmuş AP-lər, qoşulmuş müştərilər və WLC interfeysləri.
