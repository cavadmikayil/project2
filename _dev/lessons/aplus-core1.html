{{i:smartphone}} 1. Mobil Cihazlar

{{i:laptop}}

Noutbukda dəyişdirilə bilənlər: RAM (SO-DIMM), SSD (M.2 / 2.5"), batareya, klaviatura, Wi-Fi kartı. Dəyişməzdən əvvəl batareyanı ayırın.

{{i:monitor}}

Ekran: LCD (IPS — geniş bucaq, TN — sürətli, VA), OLED (piksel özü işıq verir). Wi-Fi antenaları adətən ekran çərçivəsindədir.

{{i:bluetooth}}

Qoşulma: Bluetooth (pairing, PIN), NFC (ödəniş, qısa məsafə), hotspot/tethering.

{{i:shield-check}}

MDM: şirkət telefonlarını mərkəzdən idarə etmək — parol siyasəti, uzaqdan silmə (remote wipe), tətbiq nəzarəti.

{{i:memory-stick}}

RAM: DDR4/DDR5 fərqli çəngəl yerləri — qarışdırmaq olmaz. Dual-channel üçün eyni cüt slotlar. Server — ECC RAM.

{{i:hard-drive}}

Storage: HDD (5400/7200 rpm), SATA SSD (~550 MB/s), NVMe M.2 (PCIe, GB/s-lərlə). M.2 SATA və NVMe fərqli ola bilər — açarı yoxlayın.

{{i:shield}}

Firmware: UEFI + Secure Boot, TPM 2.0 (BitLocker və Windows 11 üçün), BIOS parolu.

{{i:plug}}

PSU: 24-pin ATX, 8-pin EPS (CPU), 6/8-pin və 12V-2x6 (GPU). Gücü komponentlərin cəmindən ~20–30% artıq seçin.

{{i:printer}}

Printer: lazer prosesi 7 addım — processing, charging, exposing, developing, transferring, fusing, cleaning. Fuser isti olur!

{{i:layers}} 5. Virtualizasiya və Cloud

{{i:server}}

Type 1 hypervisor (bare metal): ESXi, Hyper-V Server. Type 2 (OS üzərində): VirtualBox, VMware Workstation.

{{i:cpu}}

Tələb: CPU-da virtualizasiya dəstəyi (Intel VT-x / AMD-V) BIOS/UEFI-də aktiv olmalıdır.

{{i:cloud}}

Cloud: IaaS/PaaS/SaaS, public/private/hybrid/community, rapid elasticity, metered utilization, shared resources.

{{i:monitor-smartphone}}

VDI: masaüstü mərkəzi serverdə, istifadəçi nazik klient və ya brauzerdən qoşulur.
