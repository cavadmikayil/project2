{{i:siren}} Giriş: Təhlükəsizliyin Məqsədi — CIA

{{i:lock}} Confidentiality (Məxfilik)

Məlumatı yalnız icazəli şəxslər görə bilsin — şifrələmə, giriş nəzarəti.

{{i:fingerprint}} Integrity (Bütövlük)

Məlumat icazəsiz dəyişdirilməsin — hash, rəqəmsal imza.

{{i:activity}} Availability (Əlçatanlıq)

Xidmət lazım olanda işləsin — ehtiyat sistemlər, DoS müdafiəsi.

{{i:shield-alert}} 2. Tipik Hücumlar

HücumNecə işləyir

DoS / DDoSXidməti sorğularla boğmaq; məs. TCP SYN flood — yarımçıq bağlantılar serverin resursunu tükədir. DDoS-da minlərlə yoluxmuş cihaz (botnet) iştirak edir

{{i:key-round}} 3. Parol Hücumları və Autentifikasiya

{{i:book-open}}

Dictionary: məşhur parolların siyahısı ilə yoxlama.

{{i:refresh-cw}}

Brute force: bütün kombinasiyaların sınanması — uzun parol bunu praktiki olaraq mümkünsüz edir.

{{i:user-check}}

MFA (çoxfaktorlu): bildiyin (parol) + sahib olduğun (telefon, token) + olduğun şey (barmaq izi) — iki və ya daha çox faktor.

{{i:file-lock}}

Sertifikatlar (PKI): cihaz və serverlərin kimliyini etibarlı mərkəzin (CA) imzası ilə təsdiqləmək.

{{i:lightbulb}}

Yaxşı parol siyasəti: uzunluq (ən azı 12–15 simvol, parol ifadəsi), təkrar istifadə etməmək, standart parolları dəyişmək, uğursuz cəhdlərdən sonra bloklama və mümkün olan hər yerdə MFA.

{{i:shield-check}} 4. Müdafiə Tədbirləri

{{i:users}} İstifadəçi maarifləndirməsi

Mütəmadi təlim və saxta phishing kampaniyaları — ən ucuz və ən effektiv müdafiələrdən biri.

{{i:lock-keyhole}} Fiziki giriş nəzarəti

Server otağına kart/biometrik giriş, kilidli rack-lər, istifadə olunmayan portların söndürülməsi.

{{i:layers}} Defense in depth

Çoxqatlı müdafiə: firewall, IPS, ACL, port security, DHCP snooping, DAI, 802.1X, şifrələmə.

{{i:refresh-cw}} Yeniləmə və monitorinq

IOS və OS yeniləmələri, Syslog/SNMP ilə izləmə, konfiqurasiya ehtiyat nüsxələri.

Bu tədbirlərin konfiqurasiyasını portalın digər dərslərində tapa bilərsiniz: SSH, Port Security, DHCP Snooping, DAI/802.1X, ACL, AAA, Firewall və VPN.
