{{i:cloud}} 1. Cloud Konsepsiyaları (25–30%)

{{i:layers}}

IaaS / PaaS / SaaS fərqi və shared responsibility — hər sual növündə çıxır.

{{i:git-merge}}

Public, private, hybrid; Azure Arc — on-prem və digər cloud-ları Azure-dan idarə etmək.

{{i:receipt}}

CapEx vs OpEx, consumption-based model, serverless.

{{i:activity}}

High availability, scalability, reliability, predictability, security, governance, manageability anlayışları.

{{i:blocks}} 2. Arxitektura və Xidmətlər (35–40%)

MövzuBilmək lazımdır
FizikiRegion, region pair, sovereign region (Azure Government, Çin), availability zone
MəntiqiManagement group → subscription → resource group → resource
ComputeVM, VM Scale Sets, availability set, App Service, Functions, ACI, AKS, Azure Virtual Desktop
ŞəbəkəVNet, subnet, peering, VPN Gateway, ExpressRoute, Azure DNS, public/private endpoint
StorageBlob, Files, Queue, Table; Hot/Cool/Cold/Archive; LRS/ZRS/GRS/GZRS; AzCopy, Storage Explorer, Azure Migrate, Data Box
IdentityEntra ID, SSO, MFA, passwordless, Conditional Access, B2B/B2C, Zero Trust, defense in depth, Microsoft Defender for Cloud
{{i:lightbulb}}

Tələ sualı: availability set VM-ləri bir data mərkəzi daxilində fault/update domain-lərə yayır, availability zone isə ayrı data mərkəzlərinə. Zone daha yüksək SLA verir.

{{i:landmark}} 3. İdarəetmə və Governance (30–35%)

{{i:file-check}} Azure Policy

Qaydaları məcburi edir: "yalnız West Europe regionu", "hər resursda owner tag-ı olsun".

{{i:lock}} Resource Lock

CanNotDelete və ReadOnly — hətta Owner da əvvəlcə lock-u silməlidir.

{{i:search}} Microsoft Purview

Məlumatın kataloqu, təsnifatı və uyğunluq idarəetməsi.

{{i:lightbulb}} Azure Advisor

Xərc, təhlükəsizlik, etibarlılıq və performans üzrə tövsiyələr.

{{i:heart-pulse}} Service Health

Azure tərəfində kəsinti və planlı işlər haqqında sizin resurslara aid bildirişlər.

{{i:chart-line}} Azure Monitor

Metrika, Log Analytics (KQL), alert-lər, Application Insights.

İdarəetmə alətləri: Portal, Cloud Shell, CLI, PowerShell; IaC üçün ARM template və Bicep.

{{i:wallet}} 4. Xərc və SLA

{{i:calculator}}

Pricing Calculator — yeni həllin aylıq qiymətini hesablamaq. TCO Calculator — on-prem ilə Azure-u müqayisə.

{{i:chart-pie}}

Cost Management + Billing: faktiki xərc analizi, budget və alert-lər.

{{i:tags}}

Tag-lar xərci şöbə və layihələr üzrə bölmək üçün.

{{i:percent}}

Qiymətə təsir edənlər: resurs tipi, region, çıxan trafik (egress), reservation, Azure Hybrid Benefit (mövcud Windows/SQL lisenziyaları).
