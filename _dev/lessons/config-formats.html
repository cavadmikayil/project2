{{i:braces}} Giriş: Maşınların və İnsanların Ortaq Dili

Ansible playbook, Kubernetes manifest, GitHub Actions workflow, Docker Compose — hamısı YAML-dır. REST API cavabları, Terraform state, AWS policy — JSON. DevOps və network automation-da ilk öyrənilməli "dil" proqramlaşdırma dili yox, bu iki məlumat formatıdır.

{{i:text}} Scalar

Tək dəyər: sətir, rəqəm, boolean, null.

{{i:list}} List / array

Sıralı dəyərlər: VLAN-ların siyahısı.

{{i:book-key}} Dictionary / object

Açar-dəyər cütləri: hostname: R1.

{{i:file-json}} 1. JSON

{
  "hostname": "SW1",
  "mgmt_ip": "192.168.1.2",
  "stp_enabled": true,
  "uplink": null,
  "vlans": [
    { "id": 10, "name": "MUHASIBAT" },
    { "id": 20, "name": "IT" }
  ]
}
{{i:quote}}

Açarlar və sətirlər yalnız qoşa dırnaqda: "name".

{{i:ban}}

Şərh (comment) yoxdur, sonuncu elementdən sonra vergül olmaz.

{{i:binary}}

Tiplər: string, number, true/false, null, array [], object {}.

{{i:wrench}} 4. Alətlər

# jq — JSON üçün grep/sed
curl -s https://api.github.com/repos/cavadmikayil/project2 | jq '.stargazers_count'
jq '.vlans[] | select(.id > 10) | .name' sw1.json
jq -r '.vlans[].id' sw1.json

# yq — YAML üçün eyni sintaksis
yq '.vlans[0].name' sw1.yaml
yq -o=json sw1.yaml > sw1.json          # YAML → JSON

yamllint playbook.yml                     # sintaksis və stil yoxlaması
python3 -m json.tool sw1.json             # JSON-u yoxla və gözəl formatla
import json, yaml    # pip install pyyaml

with open("sw1.yaml") as f:
    data = yaml.safe_load(f)          # safe_load — heç vaxt yaml.load yox

for vlan in data["vlans"]:
    print(f"vlan {vlan['id']}\n name {vlan['name']}")

with open("sw1.json", "w") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
