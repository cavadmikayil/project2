{{i:cloud-sun}} Giriş: Microsoft Azure

Azure Microsoft-un public cloud platformasıdır. Onun güclü tərəfi Microsoft ekosistemi ilə inteqrasiyadır: Active Directory, Windows Server, SQL Server, Microsoft 365 artıq istifadə edən şirkət üçün Azure təbii növbəti addımdır. AZ-900 sertifikatı da məhz bu platformanın əsaslarını yoxlayır.

{{i:globe}} Region və pair

Hər region başqa bir region ilə cütləşir (region pair) — platforma yeniləmələri növbə ilə edilir, fəlakətdə bərpa prioritetlidir.

{{i:building}} Availability Zone

Region daxilində fiziki olaraq ayrılmış data mərkəzləri; zone-redundant xidmətlər avtomatik yayılır.

{{i:mouse-pointer-2}} İdarəetmə

Azure Portal, Azure CLI, Azure PowerShell, Cloud Shell (brauzerdə), ARM/Bicep şablonları.

{{i:folder-tree}} 1. Resurs İyerarxiyası

  1. Management group: bir neçə subscription-u qruplaşdırır; Azure Policy və RBAC burada təyin olunanda aşağıya miras keçir.

  2. Subscription: hesablaşma və limit sərhədi. Tipik bölgü: Production, Dev-Test, Shared-Services.

  3. Resource group: eyni həyat dövrünə malik resursların məntiqi konteyneri. Resource group silinəndə içindəki hər şey silinir.

  4. Resource: VM, storage account, VNet, SQL database və s. Hər resurs yalnız bir resource group-da olur.

{{i:lightbulb}}

Adlandırma standartı qəbul edin: rg-portal-prod-weu, vm-web01-prod, st+kiçik hərflər (storage account adı yalnız kiçik hərf və rəqəm, qlobal unikal).

{{i:id-card}} 4. Microsoft Entra ID və RBAC

Microsoft Entra ID (əvvəlki adı Azure AD) — cloud identity xidmətidir: Microsoft 365, Azure portal və minlərlə SaaS tətbiqinə single sign-on.

{{i:refresh-cw}}

Entra Connect: on-prem AD istifadəçilərini Entra ID ilə sinxronlaşdırır (hybrid identity).

{{i:shield-check}}

Conditional Access: "Ölkə xaricindən və ya idarə olunmayan cihazdan girişdə MFA tələb et" kimi qaydalar.

{{i:key-round}}

RBAC rolları: Owner (hər şey + icazə vermək), Contributor (hər şey, icazəsiz), Reader (yalnız baxmaq).

{{i:bot}}

Managed Identity: VM və ya App Service parolsuz olaraq Key Vault və Storage-a çatır.

{{i:terminal}} 5. Azure CLI ilə İlk Resurslar

az login
az account set --subscription "Dev-Test"

az group create --name rg-lab-weu --location westeurope

# Ubuntu VM, SSH açarı ilə
az vm create -g rg-lab-weu -n vm-web01 --image Ubuntu2404 \
  --size Standard_B2s --admin-username azureuser --generate-ssh-keys
az vm open-port -g rg-lab-weu -n vm-web01 --port 80

# Storage account və container
az storage account create -g rg-lab-weu -n stlabcavad2027 --sku Standard_LRS
az storage container create --account-name stlabcavad2027 -n backups --auth-mode login

az resource list -g rg-lab-weu -o table
az group delete --name rg-lab-weu --yes --no-wait   # lab bitdi — hamısını sil

Lab üçün hər şeyi bir resource group-da yaradın: təmizləmək bir əmrdir. Eyni əmrlər Azure Portal-dakı Cloud Shell-də quraşdırmadan işləyir.
