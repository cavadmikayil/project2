{{i:cloud}} 4. Cloud və Data Mərkəzi

{{i:network}} Spine-leaf

Müasir DC topologiyası: hər leaf hər spine-a qoşulur — istənilən iki server arasında bərabər hop sayı.

{{i:arrow-left-right}} North-south / East-west

DC-yə girib-çıxan trafik və DC daxilində serverlər arası trafik.

{{i:layers-3}} Three-tier

Klassik core – distribution – access; collapsed core kiçik şəbəkələr üçün.

{{i:cloud-cog}} NFV və VPC

Router və firewall-un virtual maşın kimi işləməsi; cloud-da security group, NACL, IGW, NAT gateway.

{{i:hard-drive}} Storage şəbəkələri

Fibre Channel, FCoE, iSCSI (TCP 3260), NAS (SMB/NFS).
