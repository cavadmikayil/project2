{{i:brain-circuit}} Giriş: Beyindən İlhamlanmış Riyaziyyat

Neural network — bir-birinə bağlı sadə hesablama vahidlərindən (neyronlardan) ibarət modeldir. Tək neyron çox sadə iş görür, amma milyonlarla və milyardlarla neyron birlikdə şəkil tanımaq, səsi mətnə çevirmək və dil yaratmaq kimi mürəkkəb qanunauyğunluqları öyrənə bilir.

{{i:circle-dot}} 1. Bir Neyron Necə İşləyir?

girişlər   çəkilər (weights)
  x1 ──── w1 ──┐
  x2 ──── w2 ──┼──►  Σ (x·w) + b  ──►  aktivasiya f(z)  ──►  çıxış
  x3 ──── w3 ──┘         (bias)

  z = x1·w1 + x2·w2 + x3·w3 + b
Aktivasiya funksiyasıÇıxışHarada
ReLUmax(0, z)Gizli qatlarda ən çox istifadə olunan
Sigmoid0 … 1İkili təsnifatda ehtimal
SoftmaxEhtimallar cəmi = 1Çox sinifli təsnifat, LLM-də növbəti token seçimi

Aktivasiya funksiyası olmasa, nə qədər qat əlavə etsək də şəbəkə sadə xətti funksiya olaraq qalardı — qeyri-xəttilik mürəkkəb əlaqələri öyrənməyə imkan verir.

Deep learning — çoxlu gizli qat deməkdir. İlk qatlar sadə xüsusiyyətləri (xətt, künc), dərin qatlar mürəkkəb anlayışları (göz, üz, mətndə məna) öyrənir. Modelin "parametr sayı" — bütün çəki və bias-ların cəmidir; böyük dil modellərində milyardlarladır.

{{i:refresh-cw}} 3. Şəbəkə Necə Öyrədilir?

  1. Forward pass: nümunə şəbəkədən keçir və proqnoz alınır.

  2. Loss: proqnozun düzgün cavabdan nə qədər uzaq olduğu hesablanır.

  3. Backpropagation: hər çəkinin xətaya nə qədər töhfə verdiyi (gradient) geriyə doğru hesablanır.

  4. Gradient descent: çəkilər xətanı azaldan istiqamətdə kiçik addımla (learning rate) dəyişdirilir.

  5. Bu, bütün məlumat üzərində dəfələrlə təkrarlanır (epoch), məlumat kiçik paketlərlə (batch) verilir.

{{i:mountain}}

Analogiya: dumanlı dağdan aşağı enmək — ətrafı görmürsünüz, amma ayağınızın altındakı mailliyi hiss edib ən dik aşağı istiqamətdə addım atırsınız. Addım çox böyükdürsə (yüksək learning rate) çuxurun üstündən tullanırsınız, çox kiçikdirsə — enmək günlərlə çəkir.

{{i:cpu}} 5. Niyə GPU? Training və Inference

{{i:grid-3x3}} GPU

Neural network əsasən matris vurmasıdır — GPU minlərlə kiçik nüvə ilə bunu paralel edir. Əsas məhdudiyyət çox vaxt VRAM həcmidir.

{{i:dumbbell}} Training

Modeli öyrətmək — böyük modellər üçün minlərlə GPU, həftələr və böyük xərc.

{{i:zap}} Inference

Hazır modeldən istifadə — daha ucuzdur; kiçik modellər adi noutbukda da işləyir.

Fine-tuning — hazır, böyük modeli öz kiçik məlumat dəstinizlə əlavə öyrətmək; sıfırdan öyrətməkdən çox ucuzdur. Quantization — çəkiləri daha az bitlə (məs. 4-bit) saxlayıb modeli kiçiltmək; bir az keyfiyyət itkisi ilə daha az yaddaş.
