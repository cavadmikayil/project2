{{i:shield}} Giriş: DHCP Snooping Nədir?

DHCP Snooping Layer 2 switch-lərdə DHCP hücumlarının qarşısını alan təhlükəsizlik mexanizmidir. DHCP spoofing hücumunda hücumçu saxta DHCP server kimi çıxış edir və istifadəçilərə saxta gateway və DNS verir — bütün trafik onun kompüterindən keçir (man-in-the-middle). Hətta ehtiyatsızlıqla qoşulmuş ev router-i də eyni problemi yaradır. DHCP Snooping belə cavabları bloklayır.

{{i:user-x}} Rogue DHCP

Saxta server daha tez cavab verir və klientlər onun parametrlərini qəbul edir.

{{i:battery-low}} DHCP starvation

Hücumçu minlərlə saxta MAC ilə bütün ünvanları "yeyir" — rate limit bunu dayandırır.

{{i:database}} Binding table

DAI və IP Source Guard üçün etibarlı IP–MAC–port məlumat bazası.

{{i:workflow}} 1. DHCP Snooping Necə İşləyir?

Switch portları trusted (etibarlı) və untrusted (etibarsız) kimi təsnif olunur. Snooping aktiv olanda bütün portlar defolt olaraq untrusted-dir.

{{i:shield-check}} Trusted portlar

Qanuni DHCP serverə və ya digər switch-lərə (uplink) gedən portlar. Bu portlardan gələn bütün DHCP mesajları yoxlanılmadan ötürülür.

{{i:shield-alert}} Untrusted portlar

Son istifadəçi portları. Bu portlardan gələn server mesajları (OFFER, ACK, NAK) atılır; yalnız klient mesajlarına (DISCOVER, REQUEST) icazə verilir.

DHCP Snooping Binding Table

Switch untrusted portlara gedən qanuni DHCP ACK mesajlarını izləyərək binding table yaradır: IP ünvanı, MAC ünvanı, VLAN, port və icarə müddəti. Bu cədvəl Dynamic ARP Inspection və IP Source Guard üçün əsasdır.

{{i:clipboard-list}}

Cədvəl məzmunu: IP, MAC, VLAN ID, port, icarə müddəti.

{{i:shield}}

Təhlükəsizlik: yalnız qanuni IP–MAC bağlamalarına etibar edilir.

{{i:settings}} 2. Konfiqurasiya

Əvvəlcə DHCP Snooping qlobal, sonra VLAN-lar üçün aktivləşdirilir; ən sonda trusted portlar təyin olunur. Sıra vacibdir: uplink-i trust etmədən VLAN-da aktivləşdirsəniz, bütün klientlər ünvan ala bilməz.

Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 10,20,30
Switch(config)# ip dhcp snooping database flash:dhcp-snooping.db   ! reboot-dan sonra cədvəl qalsın

DHCP Snooping qlobal və seçilmiş VLAN-lar üçün aktivləşir. Binding cədvəlini fayla yazmaq DAI istifadə edəndə vacibdir.

! DHCP server və ya uplink portu
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip dhcp snooping trust
Switch(config-if)# exit

! İstifadəçi portları (defolt untrusted)
Switch(config)# interface range FastEthernet0/2 - 24
Switch(config-if-range)# ip dhcp snooping limit rate 15

İstifadəçi portlarında DHCP paketlərinin sürəti saniyədə 15-lə məhdudlaşır — starvation hücumu port err-disabled olmaqla dayandırılır.

Option 82 (DHCP relay agent information) DHCP mesajına circuit ID və remote ID əlavə edir — server sorğunun hansı switch və portdan gəldiyini bilir.

Switch(config)# ip dhcp snooping information option
Switch(config)# ip dhcp snooping information option allow-untrusted
! və ya Option 82-ni tamamilə söndürmək:
Switch(config)# no ip dhcp snooping information option

Tipik problem: Cisco switch defolt olaraq Option 82 əlavə edir, Windows DHCP server və ya IOS DHCP isə "giaddr = 0" olan belə paketləri rədd edir. Klientlər ünvan ala bilmirsə — bu ayarı yoxlayın.

{{i:circle-slash}} 3. Errdisable və Bərpa

err-disabled — switch-in təhlükəsizlik qaydası pozulduqda portu avtomatik söndürdüyü vəziyyətdir. Port fiziki olaraq qoşulu görünür, amma heç bir trafik ötürmür.

{{i:gauge}}

DHCP snooping rate limit (%DHCP_SNOOPING-5-DHCP_SNOOPING_RATE_LIMIT_EXCEEDED)

{{i:ban}}

BPDU Guard pozuntusu

{{i:lock-keyhole}}

Port Security pozuntusu

{{i:repeat}}

Loopback aşkarlanması, link-flap

Switch(config)# errdisable recovery cause dhcp-rate-limit
Switch(config)# errdisable recovery interval 30
Switch(config)# errdisable recovery cause ?        ! bütün səbəblər

DHCP rate limit səbəbindən err-disabled olan portlar 30 saniyə sonra avtomatik yenidən aktivləşir. Əl ilə: shutdown → no shutdown.

{{i:circle-check}} 4. Doğrulama

show ip dhcp snooping
show ip dhcp snooping binding
show ip dhcp snooping statistics
show ip dhcp snooping database
show ip dhcp snooping interface FastEthernet0/1
show interfaces status err-disabled
show errdisable recovery

Qlobal status, trusted portlar və rate limit-lər, binding cədvəli, statistika (atılan paketlər), err-disabled portlar və avtomatik bərpa ayarları.

{{i:clipboard-list}} 5. Tam Ssenari

  1. DHCP snooping qlobal və istifadəçi VLAN-ları üçün aktivləşdirilir.

  2. DHCP serverə gedən və uplink portlar ip dhcp snooping trust ilə etibarlı edilir.

  3. İstifadəçi portlarına ip dhcp snooping limit rate tətbiq olunur.

  4. Rate limit pozulan port err-disabled olur və errdisable recovery ilə müəyyən müddətdən sonra bərpa edilir.

  5. Binding table əsasında Dynamic ARP Inspection (ip arp inspection vlan 10) aktivləşdirilir — ARP spoofing də bloklanır.
