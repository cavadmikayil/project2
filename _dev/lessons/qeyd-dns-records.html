{{i:globe}} DNS Record Nədir?

{{i:pen-line}} Müəllimin qeydi · Cavad Mikayil

İnternetdə hər şey adlarla işləyir: google.com, youtube.com və s.
Amma kompüterlər ad yox, IP address anlayır.
Burada köməyə DNS (Domain Name System) gəlir.

DNS-i telefon kitabçası kimi düşün:

  • ad → nömrə
  • domain name → IP address

İndi isə ən çox istifadə olunan 8 DNS Record Type-a baxaq.

{{i:map-pin}} A, CNAME və AAAA Record

1 A (Address) Record

A Record domain adını IPv4 address-ə çevirir.

Yəni: Browser deyir ki, “bu sayt hardadır?” – A record cavab verir.

pitstech.az → 192.168.1.1

Bu record ən əsas DNS record-dur.
Əgər A record yoxdursa, sayt açılmaz.

2 CNAME (Canonical Name) Record

CNAME Record bir domain-i başqa domain-ə yönləndirir.

Məsələn: www.pitstech.az → pitstech.az

Adətən subdomain-lər üçün istifadə olunur:

  • Bir neçə adı eyni sayta bağlamaq üçün
  • Managementi asanlaşdırmaq üçün əladır.

3 AAAA Record

AAAA Record, A record kimidir, amma fərqi var.
Bu record IPv6 address üçün istifadə olunur.

pitstech.az → 2001:db8::1

Qeyd: Əgər saytımız IPv6 dəstəkləyirsə, AAAA record olur.

{{i:mail}} PTR, MX və NS Record

4 PTR Record

PTR Record əksinə işləyir. Burada:

IP address → domain name

Bu prosesə reverse DNS lookup deyilir.

Harada lazımdır?

  • Mail server-lərdə
  • Server-in real olub-olmadığını yoxlamaq üçün

Çox vaxt email problemlərində PTR record yoxlanılır.

5 MX (Mail Exchange) Record

MX Record email-lərin hara gedəcəyini göstərir.

Məsələn: example.com → mail.example.com

Kimsə sənə email göndərəndə DNS deyir:
“Bu domain-in mail server-i budur”.

MX record olmadan email işləməz.

6 NS (Name Server) Record

NS Record deyir ki: “Bu domain-in DNS cavablarını kim verir?”

Yəni hansı DNS Server cavabdehdir. Məsələn:

ns1.example.com
ns2.example.com

Domain alanda ilk işlədilən record-lardan biridir.
Bunu Cloudflare və ya EasyDNS-ə qeydiyyat edə bilərsiz.

{{i:file-text}} SRV və TXT Record

7 SRV (Service) Record

SRV Record xüsusi servislər üçün istifadə olunur. Bu record aşağıdakı məlumatları saxlayır:

  • service
  • protocol
  • host
  • port

Harada istifadə olunur?

  • VoIP
  • XMPP
  • Microsoft services

Adətən A Record ilə birlikdə işləyir.

8 TXT (Text) Record

TXT Record DNS-ə mətn əlavə etməyə imkan verir. Ən çox istifadə olunan sahələr:

  • SPF
  • DKIM
  • Domain verification

Məsələn: v=spf1 include:_spf.google.com ~all

Email security üçün çox vacibdir.

{{i:list-checks}} Nəticə: Yadımızda Saxlayaq

  • A / AAAA → saytın IP address-i
  • CNAME → yönləndirmə
  • MX → email
  • NS → DNS server-lər
  • PTR → reverse lookup
  • SRV → xüsusi servislər
  • TXT → təsdiqləmə və security

DNS-i yaxşı başa düşsən: sayt problemlərini, email xətalarını, server problemlərini daha rahat həll edərsən.
