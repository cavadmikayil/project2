{{i:laptop-minimal-check}} Giriş: Hər Noutbuk Bir Qapıdır

Endpoint — noutbuk, iş stansiyası, server, telefon. İstifadəçi burada email açır, fayl yükləyir və internetə çıxır. Endpoint ələ keçirilərsə, hücumçu oradan bütün şəbəkəyə yayılmağa çalışır. Buna görə hər cihaz bir neçə qatla qorunur.

{{i:layers}} 1. Müdafiə Qatları

{{i:refresh-cw}}

Yeniləmələr — OS, brauzer, Office, PDF oxuyucu, driver-lər.

{{i:radar}}

Antivirus / EDR — zərərli proqramları aşkarlamaq və bloklamaq.

{{i:user-minus}}

Admin hüququ yoxdur — istifadəçi gündəlik işdə lokal admin deyil.

{{i:brick-wall}}

Host firewall — lazımsız gələn bağlantılar bağlıdır.

{{i:hard-drive}}

Disk şifrələməsi — itirilmiş noutbukdan məlumat oxunmur.

{{i:list-checks}}

Application control — yalnız icazəli proqramlar işləyir.

{{i:refresh-cw}} 3. Patch Management

  1. İnventar: hansı cihazlarda hansı OS və proqram versiyaları var?

  2. Prioritet: aktiv istismar olunan (CISA KEV siyahısında) və internetə açıq sistemlər birinci.

  3. Test qrupu (pilot ring): IT və könüllülər — sonra hamı.

  4. Yerləşdirmə: Windows Update for Business / Intune / WSUS; Linux-da unattended-upgrades.

  5. Hesabat: patch almayan cihazları tapmaq — adətən ən riskli olanlar bunlardır.

{{i:lock}} 5. Disk Şifrələməsi

{{i:hard-drive}} BitLocker

Windows — açar TPM-də; recovery key AD / Entra ID-də saxlanılmalıdır.

{{i:laptop}} FileVault

macOS — recovery key MDM-də.

{{i:terminal}} LUKS

Linux — quraşdırma zamanı aktivləşdirilir.

manage-bde -status C:
Get-BitLockerVolume | Select MountPoint, VolumeStatus, EncryptionPercentage, ProtectionStatus
(Get-BitLockerVolume -MountPoint C:).KeyProtector    # recovery key ID-ləri

{{i:list-checks}} 6. Yeni Cihaz Üçün Yoxlama Siyahısı

  1. OS və bütün proqramlar son versiyadadır; avtomatik yeniləmə aktivdir.

  2. EDR agenti quraşdırılıb və konsolda "healthy" görünür.

  3. Disk şifrələnib, recovery key mərkəzdə saxlanılıb.

  4. İstifadəçi lokal admin deyil; LAPS aktivdir.

  5. Firewall açıqdır, lazımsız proqramlar (bloatware) silinib.

  6. Cihaz inventara (MDM/Intune) əlavə olunub — itəndə uzaqdan kilidləmək/silmək mümkündür.
