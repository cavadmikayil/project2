{{i:mail}} Giriş: Ofisin Gündəlik Aləti

Şirkətlərin çoxu email, sənəd və görüşlər üçün Microsoft 365 istifadə edir. Helpdesk-ə gələn müraciətlərin böyük hissəsi Outlook, Teams və OneDrive ilə bağlıdır. Bir çox problem istifadəçinin kompüterində (profil, keş), bəziləri isə bulud tərəfində (lisenziya, icazə, qayda) olur — fərqi tez görmək vacibdir.

{{i:lightbulb}}

"Proqram aktivləşmir" və ya "mailbox yoxdur" müraciətində əvvəl istifadəçinin lisenziyasını yoxlayın. Hər şeyin əvvəlində isə Service Health-ə baxın — bəlkə problem Microsoft tərəfindədir və hamıya təsir edir.

{{i:file}} OST

Exchange mailbox-un lokal keşidir. Silinsə, serverdən yenidən yüklənir — məlumat itmir.

{{i:file-archive}} PST

Lokal arxiv faylı — serverdə surəti yoxdur. Silinməsi məlumat itkisidir; zədələnəndə SCANPST.EXE.

{{i:video}} 4. Teams və OneDrive

{{i:refresh-cw}}

Teams qəribə davranır: tam çıxış və keşi təmizləmək — yeni Teams-də Settings → Apps → Microsoft Teams → Reset.

{{i:mic}}

Səs/kamera yoxdur: Teams → Settings → Devices; Windows Privacy parametrlərində kamera/mikrofon icazəsi.

{{i:cloud}}

OneDrive sinxronlaşmır: tray ikonundakı xəta; fayl adında icazəsiz simvollar, çox uzun yol, dolu kvota.

{{i:history}}

Silinmiş fayl: OneDrive/SharePoint Recycle Bin (standart 93 gün) və Version History.

{{i:terminal}} 5. Admin Alətləri

Install-Module ExchangeOnlineManagement
Connect-ExchangeOnline -UserPrincipalName admin@example.az

Get-Mailbox aysel | Select DisplayName, RecipientTypeDetails, ProhibitSendQuota
Get-MailboxStatistics aysel | Select TotalItemSize, ItemCount
Add-MailboxPermission -Identity info@example.az -User aysel -AccessRights FullAccess
Get-MessageTraceV2 -SenderAddress partner@firma.az -StartDate (Get-Date).AddDays(-2) -EndDate (Get-Date)
{{i:shield-check}}

Admin hesablarında həmişə MFA olsun və gündəlik iş hesabından ayrı saxlanılsın. Helpdesk-ə Global Admin yox, Helpdesk Administrator və ya User Administrator kimi məhdud rollar verin.
