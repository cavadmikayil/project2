{{i:layers}} Giriş: Niyə Bir Neçə Area?

Single-area OSPF-də hər router bütün şəbəkənin tam xəritəsini saxlayır. Şəbəkə böyüdükcə LSDB böyüyür, hər dəyişiklik bütün routerlərdə SPF hesablamasına səbəb olur. Multi-area dizayn şəbəkəni sahələrə bölür: ətraflı məlumat area daxilində qalır, area-lar arasında isə yalnız xülasə gedir.

{{i:info}}

Qızıl qayda: bütün area-lar Area 0 (backbone)-a birləşməlidir. Area-lar arası trafik həmişə backbone-dan keçir.

{{i:terminal}} 3. Multi-Area Konfiqurasiyası

R2(config)# router ospf 1
R2(config-router)# router-id 2.2.2.2
R2(config)# interface GigabitEthernet0/0
R2(config-if)# ip ospf 1 area 1
R2(config)# interface GigabitEthernet0/1
R2(config-if)# ip ospf 1 area 0
R2(config)# router ospf 1
R2(config-router)# area 1 range 172.16.8.0 255.255.252.0

Bir interfeys Area 1-də, digəri Area 0-dadır — R2 avtomatik ABR olur. Sonuncu sətir Area 1-in şəbəkələrini backbone-a xülasə kimi elan edir.

R1(config)# router ospf 1
R1(config-router)# router-id 1.1.1.1
R1(config-router)# network 172.16.8.0 0.0.3.255 area 1
R1(config-router)# network 10.1.12.0 0.0.0.3 area 1
R1(config-router)# passive-interface GigabitEthernet0/2

Bütün interfeysləri Area 1-dədir. Qonşu interfeysləri (R1–R2 linki) mütləq eyni area-da olmalıdır.

show ip ospf
show ip ospf interface brief
show ip ospf border-routers
show ip ospf database summary
show ip route ospf

Routerin ABR/ASBR olub-olmadığı və hansı area-larda olduğu, interfeys–area uyğunluğu, ABR/ASBR siyahısı, Type 3 LSA-lar və O IA marşrutları.
