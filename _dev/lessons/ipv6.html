{{i:globe}} Giriş: Niyə IPv6?

IPv4-ün 32 bitlik ünvan sahəsi (~4.3 milyard ünvan) internetin böyüməsi ilə tükəndi. IPv6 128 bitlik ünvanlardan istifadə edir (~3.4×1038 ünvan), NAT ehtiyacını aradan qaldırır, sadələşdirilmiş başlığa malikdir və avtomatik konfiqurasiyanı (SLAAC) dəstəkləyir. IPv6-da broadcast yoxdur — onun yerinə multicast işləyir; ARP-ın yerini isə NDP (Neighbor Discovery Protocol) tutur.

{{i:hash}} 128 bit

8 qrup × 16 bit, hex yazılış. Standart LAN subnet-i — /64.

{{i:radio}} Multicast

Broadcast əvəzinə — yalnız maraqlı cihazlar qəbul edir.

{{i:calculator}} Alət

IPv6 Kalkulyatoru ilə qısaltma və EUI-64-ü yoxlayın.

{{i:minimize-2}} 1. Ünvanın Yazılışı və Qısaldılması

IPv6 ünvanı iki nöqtə ilə ayrılmış 8 qrupdan (hextet) ibarətdir; hər qrup 4 hex simvoldur (16 bit).

  1. Qayda 1: hər qrupdakı öndəki sıfırlar atıla bilər: 0db8 → db8, 0001 → 1.

  2. Qayda 2: ardıcıl tam sıfır qruplar :: ilə əvəz oluna bilər — yalnız bir dəfə. RFC 5952-yə görə ən uzun ardıcıllıq qısaldılır, hərflər kiçik yazılır.

Tam:        2001:0db8:0000:0000:0000:ff00:0042:8329
Qayda 1:    2001:db8:0:0:0:ff00:42:8329
Qayda 2:    2001:db8::ff00:42:8329

Tam:        fe80:0000:0000:0000:0000:0000:0000:0001
Qısa:       fe80::1

Səhv:       2001::25de::cade   ← "::" iki dəfə istifadə oluna bilməz

{{i:fingerprint}} 3. SLAAC və EUI-64

SLAAC

Stateless Address Autoconfiguration: host router-in Router Advertisement (RA) mesajından /64 prefiksi öyrənir və interfeys ID-sini özü yaradır — DHCP server olmadan.

EUI-64

48 bitlik MAC ortadan bölünür, arasına FFFE əlavə olunur və 7-ci bit (U/L) çevrilir — 64 bitlik interfeys ID alınır.

DHCPv6

Stateless (yalnız DNS kimi əlavə parametrlər) və stateful (ünvanın özü də) rejimləri var.

MAC:          00:1A:2B:3C:4D:5E
Bölünür:      001A2B | 3C4D5E
FFFE əlavə:   001A2B FFFE 3C4D5E
7-ci bit:     00 → 02
Interface ID: 021A:2BFF:FE3C:4D5E
Prefiks /64:  2001:db8:1:1::/64
Nəticə:       2001:db8:1:1:21a:2bff:fe3c:4d5e

Məxfilik üçün müasir OS-lar EUI-64 əvəzinə təsadüfi interfeys ID-si (privacy extensions) istifadə edir — MAC ünvanı internetə görünmür.

{{i:terminal}} 5. Praktiki Əmrlər

Router(config)# ipv6 unicast-routing
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ipv6 address 2001:db8:1:1::1/64
Router(config-if)# ipv6 address fe80::1 link-local
Router(config-if)# no shutdown
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ipv6 address 2001:db8:1:2::/64 eui-64

ipv6 unicast-routing olmadan router IPv6 paketlərini ötürmür və RA göndərmir. İkinci interfeysdə ünvan EUI-64 ilə yaranır.

Router(config)# ipv6 route ::/0 2001:db8:ffff::1
Router(config)# ipv6 route 2001:db8:2::/48 GigabitEthernet0/1 fe80::2
Router(config)# ipv6 router ospf 1
Router(config-rtr)# router-id 1.1.1.1
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ipv6 ospf 1 area 0

Link-local next-hop istifadə edəndə çıxış interfeysi mütləq göstərilməlidir. OSPFv3 interfeys səviyyəsində aktivləşdirilir, router-id IPv4 formatındadır.

show ipv6 interface brief
show ipv6 interface GigabitEthernet0/0
show ipv6 route
show ipv6 neighbors
show ipv6 ospf neighbor
ping ipv6 2001:db8:1:1::2

İnterfeys ünvanları (link-local daxil), qoşulduğu multicast qrupları, marşrut cədvəli, NDP qonşu cədvəli, OSPFv3 qonşuları və əlçatanlıq.
