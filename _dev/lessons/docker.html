{{i:container}} Giriş: "Mənim kompüterimdə işləyirdi"

Proqram developer-in kompüterində işləyir, serverdə isə fərqli kitabxana versiyası səbəbindən çökür. Konteyner proqramı bütün asılılıqları ilə birlikdə bir paketə (image) yığır — o, istənilən Docker olan serverdə eyni cür işləyir.

{{i:package}} Image

Dəyişməz şablon: OS kitabxanaları + proqram + konfiqurasiya. Qatlardan (layer) ibarətdir.

{{i:play}} Container

Image-dan işə salınmış proses. Silinəndə içindəki dəyişikliklər də silinir.

{{i:cloud}} Registry

Image-lərin saxlandığı yer: Docker Hub, GitHub Container Registry, şirkət daxili registry.

{{i:terminal}} 2. Əsas Əmrlər

docker run -d --name web -p 8080:80 nginx:1.27   # arxa planda, host:8080 → konteyner:80
docker ps                     # işləyən konteynerlər (-a: hamısı)
docker logs -f web            # log-lar
docker exec -it web sh        # konteynerin içinə gir
docker stop web && docker rm web
docker images                 # lokal image-lər
docker pull postgres:16       # image yüklə

# Məlumatın qalıcı olması üçün volume
docker volume create pgdata
docker run -d --name db -e POSTGRES_PASSWORD=GucluParol \
  -v pgdata:/var/lib/postgresql/data postgres:16

docker system df              # disk istifadəsi
docker system prune           # istifadə olunmayan konteyner/image/şəbəkələri təmizlə

-p 8080:80 — host portu:konteyner portu. Volume olmadan verilənlər bazası konteyneri silindikdə bütün məlumat itir.

{{i:file-code}} 3. Dockerfile ilə Öz Image-ınız

# Dockerfile — Python veb tətbiqi
FROM python:3.12-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .
RUN useradd -m appuser
USER appuser

EXPOSE 8000
CMD ["gunicorn", "-b", "0.0.0.0:8000", "app:app"]

# Qurmaq və işə salmaq
docker build -t myapp:1.0 .
docker run -d -p 8000:8000 --name myapp myapp:1.0

requirements.txt kodun qalanından əvvəl kopyalanır: kod dəyişəndə asılılıqlar qatı keşdən götürülür və build sürətlənir. USER appuser — konteyner root kimi işləməsin.

{{i:boxes}} 4. Docker Compose: Çox Konteynerli Tətbiq

# compose.yaml
services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: postgresql://app:${DB_PASSWORD}@db:5432/app
    depends_on:
      - db
    restart: unless-stopped

  db:
    image: postgres:16
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - pgdata:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  pgdata:

# İdarəetmə
docker compose up -d
docker compose ps
docker compose logs -f web
docker compose down          # dayandır (volume qalır)

Compose şəbəkəsində konteynerlər bir-birini xidmət adı ilə tapır (db:5432) — daxili DNS. Parol .env faylından gəlir və git-ə əlavə olunmur.

{{i:shield-check}} 5. Yaxşı Təcrübələr

{{i:tag}}

Versiyanı sabitləyin: nginx:latest yox, nginx:1.27 — gözlənilməz yeniləmə olmasın.

{{i:minimize-2}}

{{i:key-round}}

{{i:user-check}}

Root olmayan istifadəçi və yalnız lazım olan portlar.

{{i:scan-search}}

Image-ları skan edin: docker scout cves və ya Trivy ilə məlum zəiflikləri yoxlayın.
