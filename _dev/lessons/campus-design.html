{{i:building-2}} Giriş: Niyə Hazır Dizayn Modelləri?

Switch-ləri təsadüfi birləşdirmək kiçik ofisdə işləyir, amma 2000 istifadəçili universitetdə problemləri tapmaq, genişlənmək və nasazlıqlara dözümlü olmaq çətinləşir. İerarxik dizayn şəbəkəni hər birinin öz vəzifəsi olan qatlara bölür — modul əlavə etmək və problemi lokallaşdırmaq asanlaşır.

{{i:layers}} 1. Üç Qatlı (3-tier) Kampus

              [ CORE-1 ]═══════[ CORE-2 ]           ← sürətli nəqliyyat
               ║      ╲       ╱      ║
          [ DIST-1 ]═══[ DIST-2 ]   [ DIST-3 ]═══[ DIST-4 ]   ← siyasət, L3 sərhəd
           │   ╲    ╱   │            │   ╲    ╱   │
        [ACC-1] [ACC-2] [ACC-3]   [ACC-4] [ACC-5] [ACC-6]     ← son istifadəçilər
        A binası                    B binası
QatVəzifələr
Accessİstifadəçi, telefon, AP qoşulur: VLAN-lar, PoE, port security, 802.1X, DHCP snooping, QoS marking
DistributionAccess switch-ləri toplayır; VLAN-lararası marşrutlaşdırma, FHRP (HSRP), ACL, marşrut ümumiləşdirmə — adətən Layer 2/Layer 3 sərhədi
CoreBinalar/modullar arasında maksimum sürətlə və etibarlılıqla daşımaq. Mürəkkəb siyasət (ACL, QoS klassifikasiyası) burada edilmir

{{i:layout-grid}} 2. İki Qatlı (Collapsed Core)

Tək binada və ya kiçik kampusda core ilə distribution birləşdirilir — bir cüt güclü Layer 3 switch həm access switch-ləri toplayır, həm də WAN/internet router-lərinə qoşulur.

{{i:circle-check}} Üstünlük

Daha az cihaz, daha ucuz, daha sadə idarəetmə.

{{i:triangle-alert}} Hədd

Bina sayı artanda distribution cütlərini tam əlaqələndirmək (full mesh) kabel sayını sürətlə artırır — N cüt üçün N(N−1)/2 əlaqə. O zaman ayrıca core qatı əlavə olunur.

{{i:share-2}}

Hər leaf hər spine-a qoşulur.

{{i:ban}}

Leaf leaf-ə, spine spine-a qoşulmur.

{{i:arrow-left-right}}

İstənilən iki server arasında yol eynidir: leaf → spine → leaf — gecikmə proqnozlaşdırılandır.

{{i:git-fork}}

Bütün yollar aktivdir (ECMP) — STP ilə bloklanmış link yoxdur.

{{i:plus}}

Daha çox port lazımdır — leaf əlavə et; daha çox bant genişliyi — spine əlavə et.

{{i:server}}

Serverlər, firewall, router — hamısı yalnız leaf-lərə qoşulur.

{{i:arrow-up-down}} 4. North-South və East-West Trafik

{{i:arrow-up-down}} North-South

Klient ↔ data mərkəzi, daxil ↔ internet. Ənənəvi 3-tier dizayn bu trafik üçün qurulub.

{{i:arrow-left-right}} East-West

Server ↔ server: mikroservislər, virtual maşınlar, verilənlər bazası replikasiyası. Müasir data mərkəzlərində trafikin əksəriyyəti budur — spine-leaf məhz bunun üçündür.
