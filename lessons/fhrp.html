Giriş: FHRP Nədir?

First Hop Redundancy Protocol (FHRP) — son istifadəçilər üçün defolt qapı (default gateway) yolunun ehtiyatlaşdırılmasını təmin edən protokollar ailəsidir. Bir neçə router virtual bir IP və MAC ünvanını paylaşır; əsas router (aktiv/master) nasaz olduqda ehtiyat router avtomatik onun yerini alır və istifadəçilər heç bir kəsintini hiss etmir. HSRP Cisco-ya məxsusdur, VRRP isə açıq standartdır (RFC 5798) və müxtəlif istehsalçı cihazları arasında işləyir.

1. HSRP və VRRP Müqayisəsi

Xüsusiyyət HSRP VRRP
İstehsalçı Cisco (mülkiyyət) Açıq standart (RFC 5798)
Rollar Active / Standby / Listen Master / Backup
Virtual IP Ayrıca virtual IP tələb olunur Router-in öz IP-si virtual IP ola bilər
Defolt Hello/Hold 3s / 10s 1s / 3s
Preempt Defolt deaktiv Defolt aktiv

2. HSRP Vəziyyətləri

🟢

Active: Trafiki faktiki ötürən router; virtual IP/MAC-a cavab verir.

🟡

Standby: Active router nasaz olduqda dərhal yerinə keçməyə hazır router.

👂

Listen: Qrupda olan, lakin Active/Standby olmayan digər router-lər.

⭐

Preempt: Daha yüksək prioritetli router bərpa olunduqda Active rolunu geri almasına icazə verir.

3. Praktiki Əmrlər

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.2 255.255.255.0
Router(config-if)# standby 1 ip 192.168.1.1
Router(config-if)# standby 1 priority 110
Router(config-if)# standby 1 preempt

HSRP qrup 1-i yaradır, 192.168.1.1 virtual IP-sini təyin edir, bu router-i daha yüksək prioritetlə (110) Active seçdirir və preempt aktivləşdirir.

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.2 255.255.255.0
Router(config-if)# vrrp 1 ip 192.168.1.1
Router(config-if)# vrrp 1 priority 110
Router(config-if)# vrrp 1 preempt

VRRP qrup 1-i yaradır, virtual IP-ni təyin edir və bu router-i Master seçdirmək üçün prioriteti artırır (VRRP-də preempt defolt aktivdir).
