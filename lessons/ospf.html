Giriş: Link-State Protokol

OSPF (Open Shortest Path First) açıq standart link-state protokoludur. Hər router şəbəkənin tam xəritəsini (LSDB) toplayır və Dijkstra-nın SPF alqoritmi ilə ən qısa yolları özü hesablayır. AD = 110, metrika = cost. Kiçik və orta şəbəkələrdə bütün routerlər adətən bir sahədə — Area 0 (backbone) — olur.

Hello paketləri

Qonşuları tapır və saxlayır. Broadcast şəbəkədə Hello 10 s, Dead 40 s.

LSA / LSDB

Routerlər link-state reklamlarını (LSA) mübadilə edir; eyni sahədəki hamının LSDB-si eynidir.

Multicast

224.0.0.5 — bütün OSPF routerləri, 224.0.0.6 — DR və BDR.

1. Router ID Seçimi

Router ID (RID) 32 bitlik unikal identifikatordur və IP formatında yazılır. Seçim ardıcıllığı:

  1. router-id əmri ilə əl ilə təyin edilmiş dəyər.

  2. Aktiv loopback interfeyslərindən ən yüksək IP.

  3. Aktiv fiziki interfeyslərdən ən yüksək IP.

RID dəyişdirildikdən sonra yalnız OSPF prosesi yenidən başladıqda qüvvəyə minir: clear ip ospf process.

3. DR və BDR Seçimi

Broadcast multiaccess şəbəkələrdə (Ethernet) hər routerin hamı ilə Full qonşuluğu olmasın deyə Designated Router (DR) və ehtiyat BDR seçilir. Digər routerlər (DROTHER) yalnız DR və BDR ilə Full olur.

Ən yüksək interfeys prioriteti qalib gəlir (defolt 1, maks. 255).

Prioritetlər bərabərdirsə — ən yüksək Router ID.

Prioritet 0 olan router heç vaxt DR/BDR olmur.

Seçim preemptive deyil: yeni, daha güclü router qoşulsa da DR dəyişmir.

4. Cost Hesablanması

Cost = Reference bandwidth ÷ interfeys bant genişliyi. Defolt reference 100 Mbps-dir, ona görə FastEthernet, Gigabit və 10 Gigabit linkin hamısı cost = 1 alır. Bunu düzəltmək üçün bütün routerlərdə eyni dəyərlə auto-cost reference-bandwidth təyin edilir.

5. Praktiki Əmrlər

R1(config)# router ospf 1
R1(config-router)# router-id 1.1.1.1
R1(config-router)# network 192.168.10.0 0.0.0.255 area 0
R1(config-router)# network 10.0.0.0 0.0.0.3 area 0
R1(config-router)# passive-interface GigabitEthernet0/1
R1(config-router)# auto-cost reference-bandwidth 10000

OSPF prosesi 1, əl ilə RID, wildcard ilə şəbəkələrin elanı, istifadəçi LAN-ına Hello göndərilməməsi (passive) və 10 Gbps-ə uyğun reference bandwidth.

R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip ospf 1 area 0
R1(config-if)# ip ospf priority 255
R1(config-if)# ip ospf cost 10
R1(config-if)# ip ospf hello-interval 5
R1(config-if)# ip ospf dead-interval 20

R1(config)# interface GigabitEthernet0/2
R1(config-if)# ip ospf network point-to-point

"network" əmri əvəzinə OSPF-i birbaşa interfeysdə aktivləşdirir, bu routeri DR etmək üçün prioriteti artırır, cost və timerləri dəyişir (qonşuda da eyni olmalıdır). Point-to-point şəbəkə tipində DR/BDR seçilmir.

R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
R1(config)# router ospf 1
R1(config-router)# default-information originate

İnternetə çıxışı olan router öz defolt marşrutunu OSPF vasitəsilə digər routerlərə yayır (onlarda "O*E2" kimi görünür).

show ip ospf neighbor
show ip ospf interface brief
show ip ospf interface GigabitEthernet0/0
show ip protocols
show ip route ospf
show ip ospf database
clear ip ospf process

Qonşular və vəziyyətləri (FULL/DR, 2WAY/DROTHER), interfeys cost-u, prioritet və timerlər, RID, OSPF marşrutları, LSDB. Sonuncu əmr prosesi yenidən başladır.
