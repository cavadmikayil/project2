Giriş: Qaydalar Vaxta Görə

Bəzən qayda yalnız müəyyən saatlarda lazımdır: tələbələr dərs vaxtı sosial şəbəkələrə girməsin, qonaq Wi-Fi yalnız iş saatlarında işləsin, gecə backup serverinə yalnız ehtiyat nüsxə trafiki getsin. Time-based ACL genişləndirilmiş ACL sətrinə time-range əlavə edir — sətir yalnız həmin vaxt aralığında aktiv olur.

Vaxt cihazın öz saatına görə yoxlanılır. Saat səhvdirsə, qayda səhv vaxtda işləyəcək — ona görə əvvəlcə NTP və saat qurşağını düzgün qurun.

1. Time-range Növləri

NövSintaksisNümunə

Gün açar sözləri: daily, weekdays (B.e.–Cümə), weekend (Şənbə–Bazar) və ya konkret gün adları (Monday … Sunday).

2. Ssenari: Dərs Saatlarında Məhdudiyyət

Tələbə VLAN-ı (192.168.30.0/24) iş günləri 09:00–17:00 arası yalnız DNS və veb (HTTP/HTTPS) istifadə edə bilər, dərsdən sonra isə tam çıxışı var.

R1(config)# clock timezone AZT 4
R1(config)# ntp server 192.168.1.10

R1(config)# time-range DERS-SAATLARI
R1(config-time-range)# periodic weekdays 09:00 to 17:00

R1(config)# ip access-list extended TELEBE-IN
R1(config-ext-nacl)# 10 permit udp 192.168.30.0 0.0.0.255 any eq domain
R1(config-ext-nacl)# 20 permit tcp 192.168.30.0 0.0.0.255 any eq www
R1(config-ext-nacl)# 30 permit tcp 192.168.30.0 0.0.0.255 any eq 443
R1(config-ext-nacl)# 40 deny ip 192.168.30.0 0.0.0.255 any time-range DERS-SAATLARI
R1(config-ext-nacl)# 50 permit ip 192.168.30.0 0.0.0.255 any

R1(config)# interface GigabitEthernet0/0.30
R1(config-subif)# ip access-group TELEBE-IN in

10–30: DNS və veb həmişə açıqdır. 40: dərs saatlarında qalan hər şey bloklanır — bu sətir yalnız time-range aktiv olanda işləyir. 50: dərsdən sonra digər trafikə icazə verilir.

show clock
show time-range
show access-lists TELEBE-IN
show ip interface GigabitEthernet0/0.30

Cihazın saatı, time-range-in hazırda active və ya inactive olduğu, ACL sətirləri (qeyri-aktiv sətir "(inactive)" kimi göstərilir), match sayğacları və interfeysə tətbiq olunan ACL.

3. ACL-in Yerləşdirilməsi — Xatırlatma

Genişləndirilmiş ACL mənbəyə mümkün qədər yaxın — lazımsız trafik şəbəkəyə daxil olmadan dayandırılır.

Standart ACL təyinata yaxın — yalnız mənbə IP-yə baxdığı üçün mənbəyə yaxın qoyulsa, lazımlı trafiki də bloklaya bilər.

Hər interfeysdə, hər istiqamətdə, hər protokol üçün bir ACL.

Daha spesifik sətirlər yuxarıda, ümumi sətirlər aşağıda olmalıdır.
