Giriş: Cihaz-cihaz İdarəetmədən Şəbəkə-səviyyəli İdarəetməyə

Controller-based networking-də mühəndis ayrı-ayrı cihazları konfiqurasiya etmir — o, niyyəti (intent) bildirir: "Mühasibatlıq istifadəçiləri yalnız ERP serverinə çıxsın". Kontroller bu niyyəti yüzlərlə cihazın konfiqurasiyasına çevirir, tətbiq edir və nəticəni daim yoxlayır. CCNA imtahanında bu mövzular "Automation and Programmability" bölməsinə daxildir.

2. Cisco Catalyst Center (DNA Center)

Discovery və inventar: şəbəkəni skan edib bütün cihazları, topologiyanı göstərir.

Template Editor: Jinja2/Velocity şablonları ilə konfiqurasiya.

SWIM: yüzlərlə cihazın IOS-unu mərhələli yeniləmək.

Assurance: klient və cihaz sağlamlığı, AI ilə problem təhlili.

SD-Access: VXLAN fabric, istifadəçi qruplarına görə seqmentasiya (SGT), ISE ilə inteqrasiya.

import requests
from requests.auth import HTTPBasicAuth

BASE = "https://sandboxdnac.cisco.com"      # DevNet always-on sandbox
tok = requests.post(f"{BASE}/dna/system/api/v1/auth/token",
                    auth=HTTPBasicAuth("devnetuser", "<sandbox-parol>")).json()["Token"]

h = {"X-Auth-Token": tok, "Accept": "application/json"}
devs = requests.get(f"{BASE}/dna/intent/api/v1/network-device", headers=h).json()["response"]
for d in devs:
    print(f"{d['hostname']:25} {d['managementIpAddress']:16} {d['platformId']:20} {d['softwareVersion']}")

Sandbox giriş məlumatları developer.cisco.com-da göstərilir. Intent API-lər /dna/intent/api/v1/... altındadır.

3. SD-WAN

Filialları MPLS, internet və LTE üzərindən birləşdirən, trafiki tətbiqə görə ən yaxşı yola yönəldən WAN.

Cisco Catalyst SD-WAN komponentiPlaneVəzifə
SD-WAN Manager (vManage)ManagementGUI, şablonlar, monitorinq, API
SD-WAN Controller (vSmart)ControlMarşrut və policy paylanması (OMP)
SD-WAN Validator (vBond)OrchestrationYeni cihazların autentifikasiyası, NAT traversal
WAN Edge (vEdge / cEdge)DataFilial routeri, IPsec tunellər

Application-aware routing: Teams trafiki latency və paket itkisi ən az olan linkə.

Zero-touch provisioning: yeni filial routeri qoşulur, konfiqurasiyanı özü alır.

Digər həllər: Fortinet Secure SD-WAN, VMware VeloCloud, Palo Alto Prisma SD-WAN.

4. Meraki: Cloud-Managed Şəbəkə

Meraki cihazları idarəetməni tamamilə cloud-dakı dashboard-dan alır; hər şey həm də Dashboard API ilə edilə bilər.

import os
import meraki                      # pip install meraki

dash = meraki.DashboardAPI(api_key=os.environ["MERAKI_API_KEY"], suppress_logging=True)

orgs = dash.organizations.getOrganizations()
org_id = orgs[0]["id"]
for net in dash.organizations.getOrganizationNetworks(org_id):
    print(net["name"], net["productTypes"])

# Offline cihazlar
statuses = dash.organizations.getOrganizationDevicesStatuses(org_id)
print([d["name"] for d in statuses if d["status"] == "offline"])

# SSID adını dəyişmək (network_id — yuxarıdakı siyahıdan)
network_id = net["id"]
dash.wireless.updateNetworkWirelessSsid(network_id, number=0, name="Ofis-WiFi", enabled=True)
