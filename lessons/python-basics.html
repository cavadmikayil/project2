Giriş: Niyə Python?

Python oxunaqlı sintaksisi, zəngin kitabxanaları (Netmiko, NAPALM, requests, Nornir) və böyük icması sayəsində şəbəkə avtomatlaşdırmasının de-fakto dilidir. Proqramçı olmaq lazım deyil — 2–3 həftəlik əsas bilik gündəlik işin böyük hissəsini avtomatlaşdırmağa kifayət edir.

4. Funksiyalar və Modullar

import ipaddress

def subnet_info(cidr: str) -> dict:
    """Şəbəkə haqqında əsas məlumatı qaytarır."""
    net = ipaddress.ip_network(cidr, strict=False)
    hosts = list(net.hosts())
    return {
        "network": str(net.network_address),
        "mask": str(net.netmask),
        "wildcard": str(net.hostmask),
        "first": str(hosts[0]) if hosts else None,
        "last": str(hosts[-1]) if hosts else None,
        "usable": max(net.num_addresses - 2, 0),
    }

print(subnet_info("192.168.10.77/26"))
# {'network': '192.168.10.64', 'mask': '255.255.255.192', 'wildcard': '0.0.0.63', ...}

# /24-ü /26-lara bölmək
for sub in ipaddress.ip_network("10.1.1.0/24").subnets(new_prefix=26):
    print(sub)

print(ipaddress.ip_address("10.1.1.5") in ipaddress.ip_network("10.1.1.0/25"))   # True

Daxili ipaddress modulu subnetting-i xətasız edir — IP ilə işləyən hər skriptdə istifadə edin.

5. Fayllar və Xətaların İdarəsi

import ipaddress

# devices.txt faylında hər sətirdə bir IP
with open("devices.txt") as f:
    devices = [line.strip() for line in f if line.strip() and not line.startswith("#")]

# Nəticəni yazmaq
from datetime import date
with open(f"report-{date.today()}.txt", "w", encoding="utf-8") as f:
    for ip in devices:
        f.write(f"{ip}\n")

# Xətanı tutmaq — bir cihaz çatılmasa skript dayanmasın
for ip in devices:
    try:
        ipaddress.ip_address(ip)
    except ValueError:
        print(f"Səhv IP: {ip}")
        continue
    print(f"{ip} yoxlanılır...")

Parolu skriptə yazmayın: getpass.getpass() ilə soruşun və ya environment dəyişənindən oxuyun — os.environ["NET_PASS"].
