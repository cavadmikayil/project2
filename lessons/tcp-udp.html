Giriş: Transport Qatı

IP paketi bir hostdan digərinə çatdırır, amma həmin hostda hansı proqrama çatacağını bilmir. Bunu Layer 4 — Transport qatı — həll edir. İki əsas protokol var: etibarlı, bağlantı yönümlü TCP və sürətli, bağlantısız UDP. Hər ikisi proqramları port nömrələri ilə ayırd edir.

Seqmentləşdirmə

Böyük məlumat kiçik hissələrə bölünür (TCP-də segment, UDP-də datagram).

Multiplexing

Port nömrələri sayəsində eyni hostda çoxlu proqram eyni anda şəbəkədən istifadə edir.

Etibarlılıq (yalnız TCP)

Təsdiq (ACK), yenidən göndərmə, sıralama və axın nəzarəti.

1. Port Nömrələri

Well-known

0 – 1023: standart serverlər (HTTP 80, SSH 22).

Registered

1024 – 49151: tətbiqlər üçün qeydiyyatdan keçmiş portlar.

Ephemeral (dinamik)

49152 – 65535: müştəri tərəfində təsadüfi seçilən mənbə portları.

2. TCP: Bağlantı Yönümlü Protokol

Bağlantının qurulması — 3-way handshake

Müştəri                                   Server
   |  ── SYN        (seq=100) ──────────────►  |
   |  ◄── SYN-ACK   (seq=300, ack=101) ──────  |
   |  ── ACK        (ack=301) ──────────────►  |
   |        bağlantı qurulub, məlumat gedir    |

Sıra nömrələri (sequence): seqmentlər qarışıq gəlsə də düzgün ardıcıllıqla yığılır.

Təsdiq (ACK): qəbul edən tərəf növbəti gözlədiyi baytın nömrəsini göndərir.

Yenidən göndərmə: ACK gəlməsə, seqment təkrar göndərilir.

Windowing (axın nəzarəti): qəbul edən tərəf bir anda nə qədər məlumat qəbul edə biləcəyini bildirir; itki olmadıqca pəncərə böyüyür.

Bağlantının bağlanması — 4-way

Hər tərəf öz istiqamətini ayrıca bağlayır: FIN → ACK, sonra FIN → ACK. Qəfil kəsilmə üçün RST bayrağı istifadə olunur.

3. UDP: Sadə və Sürətli

UDP bağlantı qurmur, təsdiq gözləmir və itən məlumatı yenidən göndərmir. Başlığı cəmi 8 baytdır (TCP-də minimum 20 bayt). Gecikmənin itkidən daha zərərli olduğu yerlərdə istifadə olunur.

Səs və video

VoIP (RTP), video zənglər — gecikmiş paketi yenidən göndərməyin mənası yoxdur.

Qısa sorğular

DNS, DHCP, NTP, SNMP — bir sorğu, bir cavab.

Etibarlılıq tətbiqdə

Lazım olduqda etibarlılığı proqramın özü təmin edir (məs. TFTP, QUIC).

5. Praktiki Əmrlər

show control-plane host open-ports
show tcp brief
telnet 192.168.1.10 443

Cihazın özündə açıq portlar, aktiv TCP sessiyaları və uzaq hostun müəyyən TCP portunun açıq olub-olmadığının yoxlanması (bağlantı qurulursa port açıqdır).

netstat -an
ss -tuln
Test-NetConnection 192.168.1.10 -Port 443

Windows/Linux-da açıq və qurulmuş bağlantılar (LISTEN, ESTABLISHED), Linux-da dinləyən TCP/UDP portları və PowerShell ilə TCP port testi.
