Giriş: STP-ni İdarə Etmək

STP-nin əsaslarını (port rolları və vəziyyətləri) "Spanning Tree Protocol" dərsində gördük. Bu dərsdə STP-ni idarə etməyi öyrənəcəyik: root bridge-i özümüz seçmək, cost-u hesablamaq, sürətli Rapid PVST+-a keçmək və topologiyanı qoruyan Guard mexanizmlərini qurmaq.

1. Root Bridge Seçimi və Konfiqurasiyası

Bridge ID = prioritet (4 bit) + Extended System ID (VLAN, 12 bit) + MAC. Defolt prioritet 32768-dir, ona görə VLAN 10-da switch-in görünən prioriteti 32768 + 10 = 32778 olur. Ən kiçik Bridge ID qalib gəlir.

Heç nə konfiqurasiya olunmasa, root ən kiçik MAC-lı — çox vaxt ən köhnə və ən zəif — switch olur. Root bridge-i həmişə əl ilə, güclü core/distribution switch-də təyin edin.

DSW1(config)# spanning-tree vlan 10,20 root primary
DSW2(config)# spanning-tree vlan 10,20 root secondary

DSW1(config)# spanning-tree vlan 30 priority 4096

root primary prioriteti 24576-ya (və ya mövcud root-dan aşağı dəyərə), secondary 28672-yə endirir. Prioriteti birbaşa da (4096-nın misli ilə) təyin etmək olar.

Root port seçimi (bərabərlik olduqda növbəti meyar):

  1. Root-a qədər ən aşağı ümumi cost (root path cost).

  2. Ən aşağı qonşu (göndərən) Bridge ID.

  3. Ən aşağı qonşu port prioriteti (defolt 128).

  4. Ən aşağı qonşu port nömrəsi.

3. Rapid PVST+ (802.1w)

Klassik STP-də port forwarding-ə 30–50 saniyəyə keçir. RSTP isə qonşu ilə birbaşa razılaşaraq (proposal/agreement) bir neçə saniyəyə, çox vaxt daha tez konvergensiya edir. Rapid PVST+ hər VLAN üçün ayrıca RSTP instansıdır.

RSTP port roluİzah
Root portRoot-a ən yaxşı yol
Designated portSeqmentdə trafiki ötürən port
Alternate portRoot-a ehtiyat yol — root port itəndə dərhal onu əvəz edir
Backup portEyni seqmentə (hub vasitəsilə) ikinci port — nadir hal

Link tipləri: point-to-point (full-duplex — sürətli keçid), shared (half-duplex) və edge (PortFast — son istifadəçi portu).

5. Praktiki Əmrlər

SW1(config)# spanning-tree mode rapid-pvst
SW1(config)# spanning-tree pathcost method long
SW1(config)# interface GigabitEthernet0/1
SW1(config-if)# spanning-tree vlan 10 cost 10000
SW1(config-if)# spanning-tree vlan 10 port-priority 64
SW1(config-if)# spanning-tree link-type point-to-point

Rapid PVST+ rejimi, uzun cost metodu, müəyyən VLAN üçün portun cost və prioritetinin dəyişdirilməsi, linkin point-to-point kimi göstərilməsi.

SW1(config)# spanning-tree portfast default
SW1(config)# spanning-tree portfast bpduguard default

SW1(config)# interface GigabitEthernet0/10
SW1(config-if)# spanning-tree guard root

SW1(config)# interface GigabitEthernet0/2
SW1(config-if)# spanning-tree guard loop

SW1(config)# errdisable recovery cause bpduguard
SW1(config)# errdisable recovery interval 300

Bütün access portlarında PortFast və BPDU Guard, access switch-ə baxan portda Root Guard, alternate portda Loop Guard, BPDU Guard-a görə söndürülən portların 5 dəqiqə sonra bərpası.

show spanning-tree vlan 10
show spanning-tree root
show spanning-tree summary
show spanning-tree inconsistentports
show spanning-tree interface GigabitEthernet0/1 detail

Root bridge və port rolları, bütün VLAN-lar üzrə root, aktiv funksiyalar (PortFast/BPDU Guard default), root/loop-inconsistent portlar və portun ətraflı STP statusu.

Lab: PortFast, BPDU Guard və Root Guard

Məqsəd

Access portlarını sürətləndirmək və icazəsiz switch-in STP topologiyasını pozmasının qarşısını almaq.

Alət

Cisco Packet Tracer

Müddət

35 dəq · Orta

Topologiya

  SW1 (root) ==== SW2 (Fa0/1) --- PC
                      (Fa0/2) --- "Rogue" SW3 (priority 0)

Tapşırıqlar

  1. SW1-i root edin. SW2-nin Fa0/1-Fa0/2 portlarında spanning-tree portfast və bpduguard enable konfiqurasiya edin.

  2. PC-ni Fa0/1-ə qoşun: port dərhal forwarding olur (30 saniyə gözləmədən).

  3. Fa0/2-yə priority 0 olan SW3 qoşun: BPDU Guard portu err-disabled edir — log mesajını tapın.

  4. Alternativ: Fa0/2-də BPDU Guard əvəzinə spanning-tree guard root sınayın — port root-inconsistent olur.

  5. errdisable recovery cause bpduguard ilə avtomatik bərpanı qurun.

Yoxlama

show spanning-tree interface fa0/1 portfast
show interfaces status err-disabled
show spanning-tree inconsistentports
show errdisable recovery
show logging | include BPDU

Uğur meyarları

PortFast portu dərhal forwarding olur.

BPDU gələn access portu err-disabled olur, root dəyişmir.

Root Guard ilə root bridge SW1 olaraq qalır.

Həll — əvvəlcə özünüz cəhd edin 
SW2(config)# interface range fa0/1 - 2
SW2(config-if-range)# switchport mode access
SW2(config-if-range)# spanning-tree portfast
SW2(config-if-range)# spanning-tree bpduguard enable
SW2(config)# errdisable recovery cause bpduguard
SW2(config)# errdisable recovery interval 60
! Root Guard variantı
SW2(config)# interface fa0/2
SW2(config-if)# no spanning-tree bpduguard enable
SW2(config-if)# spanning-tree guard root

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
