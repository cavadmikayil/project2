Giriş: Niyə IPv6?

IPv4-ün 32 bitlik ünvan sahəsi (~4.3 milyard ünvan) internetin böyüməsi ilə tükəndi. IPv6 128 bitlik ünvanlardan istifadə edir (~3.4×1038 ünvan), NAT ehtiyacını aradan qaldırır, sadələşdirilmiş başlığa malikdir və avtomatik konfiqurasiyanı (SLAAC) dəstəkləyir. IPv6-da broadcast yoxdur — onun yerinə multicast istifadə olunur, ARP-ın yerini isə NDP (Neighbor Discovery Protocol) tutur.

1. Ünvanın Yazılışı və Qısaldılması

IPv6 ünvanı iki nöqtə ilə ayrılmış 8 qrupdan (hextet), hər biri 4 hex simvoldan (16 bit) ibarətdir.

1

Qayda 1: Hər qrupdakı öndəki sıfırlar atıla bilər: 0db8 → db8, 0001 → 1.

2

Qayda 2: Ardıcıl tam sıfır qruplar :: ilə əvəz oluna bilər — yalnız bir dəfə.

Tam:        2001:0db8:0000:0000:0000:ff00:0042:8329
Qayda 1:    2001:db8:0:0:0:ff00:42:8329
Qayda 2:    2001:db8::ff00:42:8329

Tam:        fe80:0000:0000:0000:0000:0000:0000:0001
Qısa:       fe80::1

Səhv:       2001::25de::cade   ← "::" iki dəfə istifadə oluna bilməz

2. Ünvan Növləri

Növ Prefiks IPv4 analoqu / izah
Global Unicast 2000::/3 Public IP — internetdə marşrutlaşdırılır
Link-Local FE80::/10 Yalnız öz seqmentində; hər IPv6 interfeysində avtomatik yaranır
Unique Local FC00::/7 Private IP (10.x, 192.168.x) analoqu
Multicast FF00::/8 Qrupa göndərmə (FF02::1 bütün node-lar, FF02::2 bütün router-lər)
Loopback ::1/128 127.0.0.1 analoqu
Unspecified ::/128 0.0.0.0 analoqu — ünvan hələ yoxdur

3. SLAAC və EUI-64

SLAAC

Stateless Address Autoconfiguration: host router-dən Router Advertisement (RA) mesajı ilə /64 prefiksi öyrənir və interfeys ID-sini özü yaradır — DHCP server lazım olmadan.

EUI-64

48 bitlik MAC ünvanı ortadan ikiyə bölünür, arasına FFFE əlavə olunur və 7-ci bit (U/L) çevrilir — nəticədə 64 bitlik interfeys ID alınır.

MAC:          00:1A:2B:3C:4D:5E
Bölünür:      001A2B | 3C4D5E
FFFE əlavə:   001A2B FFFE 3C4D5E
7-ci bit:     00 → 02
Interface ID: 021A:2BFF:FE3C:4D5E
Prefiks /64:  2001:db8:1:1::/64
Nəticə:       2001:db8:1:1:21a:2bff:fe3c:4d5e

4. Praktiki Əmrlər

Router(config)# ipv6 unicast-routing

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ipv6 address 2001:db8:1:1::1/64
Router(config-if)# ipv6 address fe80::1 link-local
Router(config-if)# no shutdown

Router(config)# interface GigabitEthernet0/1
Router(config-if)# ipv6 address 2001:db8:1:2::/64 eui-64

Router-də IPv6 marşrutlaşdırmanı aktivləşdirir (bu olmadan router paketləri ötürmür və RA göndərmir), statik global və link-local ünvan, ikinci interfeysdə isə EUI-64 ilə ünvan təyin edir.

Router(config)# ipv6 route ::/0 2001:db8:ffff::1
Router(config)# ipv6 route 2001:db8:2::/48 GigabitEthernet0/1 fe80::2

Router(config)# ipv6 router ospf 1
Router(config-rtr)# router-id 1.1.1.1
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ipv6 ospf 1 area 0

IPv6 defolt marşrut, çıxış interfeysi + link-local next-hop ilə statik marşrut və OSPFv3 konfiqurasiyası (OSPFv3 interfeys səviyyəsində aktivləşdirilir).

show ipv6 interface brief
show ipv6 interface GigabitEthernet0/0
show ipv6 route
show ipv6 neighbors
show ipv6 ospf neighbor
ping ipv6 2001:db8:1:1::2

İnterfeys ünvanları (link-local daxil), qoşulduğu multicast qrupları, IPv6 marşrut cədvəli, NDP qonşu cədvəli (ARP analoqu), OSPFv3 qonşuları və əlçatanlıq.
