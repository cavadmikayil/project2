Spanning Tree Protocol (STP)

Giriş: STP Nədir?

Spanning Tree Protocol (STP, IEEE 802.1D) Layer 2 şəbəkələrdə switch-lər arasında yaranan fiziki dövrələri (loop) aşkarlayaraq şəbəkəni məntiqi olaraq ağac (tree) topologiyasına çevirir. Loop-lar olmadan Ethernet çərçivələri sonsuza qədər dövr edə bilər (broadcast storm), MAC ünvan cədvəli qeyri-sabit olar. STP artıq yolları "blocking" vəziyyətinə salaraq yalnız bir aktiv yol saxlayır, lakin ehtiyat yolları itirmir — əsas yol kəsildikdə avtomatik aktivləşir.

1. Port Rolları

Root Bridge: Ən aşağı Bridge ID-yə malik switch; bütün STP hesablamaları ondan başlayır.

Root Port: Hər qeyri-root switch-də Root Bridge-ə ən aşağı xərcli (cost) port.

Designated Port: Hər seqmentdə trafiki ötürən, seçilmiş port (forwarding vəziyyətində).

Blocking (Alternate) Port: Loop yaratmamaq üçün trafik ötürməyən, ehtiyat port.

2. Port Vəziyyətləri

Klassik STP (802.1D) portu forwarding vəziyyətinə keçirməzdən əvvəl bir neçə mərhələdən keçirir, bu da 30-50 saniyə çəkə bilər. RSTP (802.1w) bu prosesi sürətləndirir.

STP (802.1D) RSTP (802.1w) Açıqlama
Blocking Discarding Çərçivə qəbul/ötürmür, yalnız BPDU dinləyir
Listening Discarding Topologiyanı öyrənir, hələ MAC öyrənmir
Learning Learning MAC ünvan cədvəlini doldurmağa başlayır
Forwarding Forwarding Tam işlək — trafik ötürülür

3. STP Növləri

PVST+

Cisco-ya məxsus, hər VLAN üçün ayrı STP instansı yaradır. Defolt Cisco IOS rejimidir.

Rapid-PVST+

RSTP-nin VLAN-başına versiyası. Çox sürətli konvergensiya (saniyələr ərzində).

MSTP

Bir neçə VLAN-ı instansda qruplaşdırır, böyük şəbəkələrdə CPU yükünü azaldır.

4. Praktiki Əmrlər

Switch(config)# spanning-tree mode rapid-pvst
Switch(config)# spanning-tree vlan 10 priority 4096

Switch(config)# interface FastEthernet0/1
Switch(config-if)# spanning-tree portfast
Switch(config-if)# spanning-tree bpduguard enable

RSTP (PVST+) rejimini aktivləşdirir, VLAN 10 üçün bu switch-i Root Bridge etməyə çalışır (aşağı prioritet), son istifadəçi portunda PortFast və BPDU Guard aktivləşdirir.

show spanning-tree
show spanning-tree vlan 10
show spanning-tree interface FastEthernet0/1
show spanning-tree summary

STP statusunu, Root Bridge məlumatını, port rollarını/vəziyyətlərini və ümumi xülasəni göstərir.
