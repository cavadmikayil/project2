Giriş: IPv4 Ünvanının Quruluşu

IPv4 ünvanı 32 bitdir və nöqtələrlə ayrılmış 4 oktetlə yazılır (məs. 192.168.10.77). Subnet maskası ünvanın hansı hissəsinin şəbəkəni, hansı hissəsinin hostu göstərdiyini müəyyən edir: maskadakı 1 bitləri şəbəkə, 0 bitləri host hissəsidir. 

IP:     192.168.10.77   = 11000000.10101000.00001010.01001101
Maska:  255.255.255.192 = 11111111.11111111.11111111.11000000   (/26)
Şəbəkə: 192.168.10.64   = 11000000.10101000.00001010.01000000

Hesablamalarınızı yoxlamaq və məşq etmək üçün portaldakı Subnet Kalkulyatorundan istifadə edin.

2. Subnetting: Addım-addım

  1. Lazım olan host sayına görə host bitlərini (h) tapın: 2h − 2 ≥ host sayı.

  2. Prefiks = 32 − h.

  3. "Maraqlı" oktetdə blok ölçüsü = 256 − maska dəyəri.

  4. Şəbəkələr blok ölçüsü addımı ilə artır; hər blokun ilk ünvanı şəbəkə, sonuncusu broadcast ünvanıdır.

3. VLSM: Fərqli Ölçülü Alt Şəbəkələr

VLSM (Variable Length Subnet Mask) hər alt şəbəkəyə ehtiyacı qədər ünvan verir və ünvan israfının qarşısını alır. Qayda: ən böyük ehtiyacdan başlayın və blokları ardıcıl yerləşdirin.

Tapşırıq: 192.168.10.0/24 — LAN A: 100 host, LAN B: 50 host, LAN C: 20 host, 2 ədəd router-router (WAN) linki.

SeqmentEhtiyacPrefiks (host)ŞəbəkəHost aralığıBroadcast
LAN A100/25 (126)192.168.10.0.1 – .126.127
LAN B50/26 (62)192.168.10.128.129 – .190.191
LAN C20/27 (30)192.168.10.192.193 – .222.223
WAN 12/30 (2)192.168.10.224.225 – .226.227
WAN 22/30 (2)192.168.10.228.229 – .230.231

192.168.10.232 – 192.168.10.255 gələcək ehtiyaclar üçün boş qalır.

4. Tətbiq: Planı Router-ə Yazmaq

Router(config)# interface GigabitEthernet0/0
Router(config-if)# description LAN-A
Router(config-if)# ip address 192.168.10.1 255.255.255.128
Router(config-if)# no shutdown

Router(config)# interface GigabitEthernet0/1
Router(config-if)# description LAN-B
Router(config-if)# ip address 192.168.10.129 255.255.255.192
Router(config-if)# no shutdown

Router(config)# interface Serial0/0/0
Router(config-if)# description WAN-1
Router(config-if)# ip address 192.168.10.225 255.255.255.252
Router(config-if)# no shutdown

VLSM planındakı hər seqmentin ilk istifadə oluna bilən ünvanı router interfeysinə (defolt gateway) verilir.

show ip interface brief
show ip route connected
show running-config interface GigabitEthernet0/0

İnterfeys IP-ləri və statusu, "C" (connected) və "L" (local /32) marşrutları.
