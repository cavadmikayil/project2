Giriş Yaddaş növləri Fayl sistemləri Image adı Ehtiyat nüsxə Yeniləmə Portal

Giriş: Cihazın İçində Nə Var?

Router və switch də kompüterdir: əməliyyat sistemi (IOS) fayl kimi saxlanılır, konfiqurasiya mətn faylıdır. Onları kopyalamaq, yedəkləmək və yeniləmək şəbəkə mühəndisinin gündəlik işidir.

1. Yaddaş Növləri

YaddaşNə saxlayırSöndürüləndə
ROMPOST, bootstrap, ROMMONQalır
FlashIOS image faylları (switch-də həm də config.text, vlan.dat)Qalır
NVRAMstartup-configQalır
RAMİşləyən IOS, running-config, marşrut və MAC cədvəlləri, buferlərSilinir

2. Fayl Sistemləri

IOS hər yaddaşı və şəbəkə protokolunu "prefiks:" şəklində fayl sistemi kimi göstərir.

PrefiksNöv
flash: / bootflash:Daxili flash yaddaş
nvram:NVRAM — nvram:startup-config
system:RAM — system:running-config
usbflash0:USB yaddaş
tftp:, ftp:, scp:, http(s):Şəbəkə serverləri
 
R1# show file systems
R1# dir flash:
Directory of flash:/
    1  -rw-   111233316  c2900-universalk9-mz.SPA.157-3.M8.bin
256487424 bytes total (145250304 bytes free)

R1# more nvram:startup-config
R1# show flash:

copy əmri həmişə copy mənbə təyinat formasındadır: copy running-config startup-config = copy system:running-config nvram:startup-config.

3. IOS Image Adını Oxumaq

c2900 - universalk9 - mz . SPA . 157-3.M8 . bin
  │          │         │     │       │
  │          │         │     │       └─ versiya 15.7(3)M8
  │          │         │     └───────── rəqəmsal imzalı (Cisco)
  │          │         └─────────────── RAM-da işləyir (m), sıxılıb (z)
  │          └───────────────────────── funksiya dəsti (universal, k9 = şifrələmə)
  └──────────────────────────────────── platforma (ISR 2900)

Universal image-da bütün funksiyalar var, lakin istifadəsi lisenziya ilə açılır. Müasir cihazlarda Cisco Smart Licensing istifadə olunur — lisenziyalar Cisco bulud portalında hesabda saxlanılır: show license summary.

4. Konfiqurasiyanın Ehtiyat Nüsxəsi

R1# copy running-config tftp:
Address or name of remote host []? 10.0.0.50
Destination filename [r1-confg]? R1-2026-09-27.cfg

R1# copy tftp: running-config
R1# copy running-config flash:R1-backup.cfg

Diqqət: tftp → running-config konfiqurasiyanı birləşdirir (merge) — faylda olmayan sətirlər silinmir. Tam əvəz etmək üçün configure replace istifadə olunur.

R1(config)# archive
R1(config-archive)# path tftp://10.0.0.50/$h-$t
R1(config-archive)# write-memory
R1(config-archive)# time-period 1440

R1# show archive
R1# configure replace flash:R1-backup.cfg list

Hər write memory-də və gündə bir dəfə (1440 dəqiqə) konfiqurasiya host adı ($h) və vaxt ($t) ilə serverə yazılır. configure replace cari konfiqurasiyanı fayla tam uyğunlaşdırır və fərqləri göstərir.

5. IOS Yenilənməsi

  1. Yeni image-ı Cisco saytından yükləyin, platformaya, RAM və flash tutumuna uyğunluğunu yoxlayın (show version, dir flash:).

  2. Konfiqurasiyanın ehtiyat nüsxəsini götürün.

  3. Faylı flash-a köçürün və MD5/SHA hash-ını Cisco saytındakı ilə müqayisə edin.

  4. boot system ilə yeni image-ı göstərin, köhnəsini ehtiyat kimi saxlayın, yadda saxlayın və texniki xidmət pəncərəsində reload edin.

R1# copy tftp://10.0.0.50/c2900-universalk9-mz.SPA.159-3.M9.bin flash:
R1# verify /md5 flash:c2900-universalk9-mz.SPA.159-3.M9.bin

R1(config)# no boot system
R1(config)# boot system flash:c2900-universalk9-mz.SPA.159-3.M9.bin
R1(config)# boot system flash:c2900-universalk9-mz.SPA.157-3.M8.bin
R1(config)# end
R1# copy running-config startup-config
R1# reload

R1# show version | include image file

Birinci image yüklənməsə, cihaz ikinci boot system sətrinə keçir. Böyük faylı TFTP əvəzinə SCP/FTP ilə köçürmək daha sürətli və etibarlıdır.
