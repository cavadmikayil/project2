3. running-config və startup-config

running-config

RAM-da saxlanılan aktiv konfiqurasiya. Hər əmr dərhal bura yazılır, amma cihaz yenidən başlayanda itir.

startup-config

NVRAM-da saxlanılır, cihaz açılanda yüklənir. Dəyişiklikləri qorumaq üçün yadda saxlamaq lazımdır.

R1# copy running-config startup-config
R1# write memory
R1# show running-config | section interface
R1# show startup-config
R1# erase startup-config
R1# reload

Konfiqurasiyanı yadda saxlamaq (iki üsul), aktiv və saxlanılmış konfiqurasiyaya baxmaq, cihazı zavod vəziyyətinə qaytarmaq (erase + reload).

4. User və Privileged Rejimlərin Qorunması

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# no ip domain-lookup
R1(config)# enable secret Guclu!Enable26
R1(config)# line console 0
R1(config-line)# password Konsol!26
R1(config-line)# login
R1(config-line)# logging synchronous
R1(config-line)# exec-timeout 5 0
R1(config)# service password-encryption
R1(config)# banner motd # Yalniz icazeli giris! #
R1(config)# end
R1# copy running-config startup-config

Konsol girişi parolla, Privileged rejim isə hash-lənmiş enable secret ilə qorunur. logging synchronous log mesajlarının yazdığınız əmri kəsməsinin qarşısını alır.

show version
show running-config | include secret|password
show history
show users

IOS versiyası, uptime və konfiqurasiya registri; parolların şifrəli göründüyünü yoxlamaq; son yazılmış əmrlər və qoşulmuş istifadəçilər.
