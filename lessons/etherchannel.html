Giriş: EtherChannel Nədir?

EtherChannel (link aggregation) bir neçə fiziki Ethernet linkini tək məntiqi link — Port-channel — kimi birləşdirir. Bant genişliyi artır (məs. 4 × 1 Gbps = 4 Gbps), linklərdən biri kəsiləndə trafik digərlərinə keçir və, ən vacibi, STP bu linkləri tək link kimi gördüyü üçün heç birini bloklamır.

Bant genişliyi

Bir qrupda 8 aktiv link (LACP ilə üstəlik 8 hot-standby).

Ehtiyat

Link kəsiləndə trafik saniyənin kəsri içində qalan linklərə keçir — STP yenidən hesablanmır.

STP ilə uyğun

STP bir məntiqi port görür, heç bir link bloklanmır.

1. PAgP və LACP

LACP

IEEE 802.3ad (indi 802.1AX) açıq standartı. Rejimlər: active (danışıq başladır), passive (yalnız cavab verir).

PAgP

Cisco-ya məxsus. Rejimlər: desirable (danışıq başladır), auto (yalnız cavab verir).

Statik (on)

Danışıq protokolu yoxdur — hər iki tərəf on olmalıdır. Səhv konfiqurasiya loop yarada bilər.

2. Uyğunluq Tələbləri

Qrupdakı bütün fiziki portlar eyni parametrlərə malik olmalıdır, əks halda portlar suspended vəziyyətinə düşür.

Eyni speed və duplex.

Eyni switchport mode (hamısı access və ya hamısı trunk).

Eyni access VLAN və ya eyni allowed / native VLAN siyahısı.

Eyni channel-group nömrəsi və protokol; L2 və L3 portları qarışdırıla bilməz.

Konfiqurasiyanı həmişə Port-channel interfeysində dəyişin — ayarlar üzv portlara avtomatik ötürülür və uyğunsuzluq yaranmır.

3. Yük Bölgüsü

EtherChannel trafiki paket-paket yox, axın (flow) üzrə bölür: seçilmiş sahələrin hash-i hansı linkin istifadə olunacağını müəyyən edir. Ona görə bir faylın kopyalanması (bir axın) 1 Gbps-dən sürətli olmur, amma 100 istifadəçi birlikdə bütün linkləri istifadə edir.

4. Praktiki Əmrlər

Switch(config)# interface range GigabitEthernet0/1 - 2
Switch(config-if-range)# channel-group 1 mode active
Switch(config-if-range)# exit
Switch(config)# interface Port-channel1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30

Gi0/1–2 portlarını LACP active rejimində Port-channel1-ə birləşdirir və məntiqi interfeysi trunk kimi konfiqurasiya edir.

Switch(config)# interface range GigabitEthernet0/3 - 4
Switch(config-if-range)# channel-group 2 mode desirable
Switch(config-if-range)# exit
Switch(config)# port-channel load-balance src-dst-ip

Gi0/3–4 portlarını PAgP desirable rejimində Port-channel2-yə birləşdirir və yük bölgüsünü mənbə + təyinat IP əsasında təyin edir.

Switch(config)# interface range GigabitEthernet0/5 - 6
Switch(config-if-range)# no switchport
Switch(config-if-range)# channel-group 3 mode active
Switch(config-if-range)# exit
Switch(config)# interface Port-channel3
Switch(config-if)# no switchport
Switch(config-if)# ip address 10.0.0.1 255.255.255.252

Multilayer switch-də routed (L3) EtherChannel: həm fiziki portlar, həm də Port-channel no switchport olmalıdır; IP ünvanı Port-channel-a verilir.

show etherchannel summary
show etherchannel port-channel
show interfaces Port-channel1
show lacp neighbor
show pagp neighbor
show etherchannel load-balance

summary bayraqları: SU — Layer 2, işləyir; RU — Layer 3, işləyir; üzv portda (P) — bundle-dadır, (s) — suspended, (D) — down, (I) — stand-alone.

Lab: LACP EtherChannel və L3 Port-channel

Məqsəd

İki switch arasında LACP ilə Layer 2 trunk EtherChannel və multilayer switch-lər arasında routed Port-channel qurmaq.

Alət

Cisco Packet Tracer (3650 switch)

Müddət

40 dəq · Orta

Topologiya

 SW1 (Gi1/0/1-2) ==Po1 LACP trunk== (Gi1/0/1-2) SW2
 SW1 (Gi1/0/3-4) ==Po2 L3 10.0.0.0/30== (Gi1/0/3-4) SW2

Tapşırıqlar

  1. Gi1/0/1-2 portlarını channel-group 1 mode active ilə Po1-ə birləşdirin, Po1-i trunk edin.

  2. show etherchannel summary ilə SU və (P) bayraqlarını tapın; STP-də Po1-in tək port kimi göründüyünü göstərin.

  3. Bir tərəfdə passive, sonra hər iki tərəfdə passive edin — hansı halda channel qurulmur?

  4. Bir üzv portunda speed-i dəyişib (s) suspended vəziyyətini yaradın, sonra düzəldin.

  5. Gi1/0/3-4 ilə L3 EtherChannel qurun: no switchport, Po2-yə 10.0.0.1/30 və 10.0.0.2/30, ping edin.

  6. Bir fiziki linki söndürün — ping davam edirmi?

Yoxlama

show etherchannel summary
show etherchannel port-channel
show lacp neighbor
show interfaces port-channel 1 trunk
show spanning-tree vlan 1

Uğur meyarları

Po1 — SU, Po2 — RU, üzv portlar (P).

passive + passive kombinasiyasında channel qurulmur.

Bir link kəsiləndə trafik digər linklə davam edir.
