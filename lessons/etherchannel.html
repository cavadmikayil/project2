Giriş: EtherChannel Nədir?

EtherChannel (Link Aggregation) bir neçə fiziki Ethernet linkini tək məntiqi link (Port-channel) kimi birləşdirir. Nəticədə bant genişliyi artır (məs. 4×1 Gbps = 4 Gbps), linklərdən biri kəsiləndə trafik digərlərinə keçir və — ən vacibi — STP bu linkləri tək link kimi gördüyü üçün heç birini bloklamır. Bir EtherChannel-də maksimum 8 aktiv link ola bilər.

1. PAgP və LACP

LACP

IEEE 802.3ad (802.1AX) açıq standartı. Rejimlər: active (danışıq başladır), passive (yalnız cavab verir).

PAgP

Cisco-ya məxsus. Rejimlər: desirable (danışıq başladır), auto (yalnız cavab verir).

Statik (on)

Heç bir danışıq protokolu yoxdur — hər iki tərəf on olmalıdır. Səhv konfiqurasiya loop yarada bilər.

2. Uyğunluq Tələbləri

Bir qrupdakı bütün fiziki portlar eyni parametrlərə malik olmalıdır, əks halda portlar "suspended" vəziyyətinə düşür.

Eyni speed və duplex

Eyni switchport mode (hamısı access və ya hamısı trunk)

Eyni access VLAN və ya eyni allowed / native VLAN siyahısı

Eyni channel-group nömrəsi və protokol

3. Praktiki Əmrlər

Switch(config)# interface range GigabitEthernet0/1 - 2
Switch(config-if-range)# channel-group 1 mode active
Switch(config-if-range)# exit

Switch(config)# interface Port-channel1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30

Gi0/1–2 portlarını LACP active rejimində Port-channel1-ə birləşdirir və məntiqi interfeysi trunk kimi konfiqurasiya edir (Port-channel-a verilən ayarlar üzv portlara ötürülür).

Switch(config)# interface range GigabitEthernet0/3 - 4
Switch(config-if-range)# channel-group 2 mode desirable
Switch(config-if-range)# exit

Switch(config)# port-channel load-balance src-dst-ip

Gi0/3–4 portlarını PAgP desirable rejimində Port-channel2-yə birləşdirir və yük bölgüsü üsulunu mənbə+təyinat IP əsasında təyin edir.

Switch(config)# interface range GigabitEthernet0/5 - 6
Switch(config-if-range)# no switchport
Switch(config-if-range)# channel-group 3 mode active
Switch(config-if-range)# exit

Switch(config)# interface Port-channel3
Switch(config-if)# no switchport
Switch(config-if)# ip address 10.0.0.1 255.255.255.252

Multilayer switch-də routed (L3) EtherChannel: həm fiziki portlar, həm də Port-channel interfeysi no switchport olmalıdır; IP ünvanı Port-channel-a verilir.

show etherchannel summary
show etherchannel port-channel
show interfaces Port-channel1
show lacp neighbor
show pagp neighbor
show etherchannel load-balance

"summary" çıxışında bayraqlar: SU = Layer 2, işləyir; RU = Layer 3, işləyir; üzv portda (P) = bundle-dadır, (s) = suspended, (D) = down.
