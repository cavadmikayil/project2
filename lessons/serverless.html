Giriş: Server Var, Sadəcə Sizin Deyil

Serverless o demək deyil ki, server yoxdur — o deməkdir ki, serveri siz görmürsünüz və idarə etmirsiniz. Siz yalnız funksiyanı yazırsınız; provayder onu hadisə gələndə işə salır, lazım olduqca paralel nüsxələr açır və yalnız işləyən millisaniyələr üçün pul alır. Heç kim çağırmırsa — xərc sıfırdır.

FaaS

AWS Lambda, Azure Functions, Google Cloud Functions.

Serverless data

DynamoDB, Aurora Serverless, Cosmos DB serverless, S3.

Serverless inteqrasiya

API Gateway, SQS/SNS, EventBridge, Azure Service Bus, Step Functions, Logic Apps.

1. Funksiya Necə İşləyir

  1. Hadisə gəlir: HTTP sorğu, S3-ə fayl yüklənməsi, növbədə mesaj, cron.

  2. Platforma boş execution environment tapır; yoxdursa yenisini yaradır — bu, cold start-dır (100 ms – bir neçə saniyə).

  3. Handler funksiyası hadisə obyekti ilə çağırılır, nəticə qaytarılır.

  4. Environment bir müddət "isti" saxlanılır — növbəti sorğular sürətli olur (warm start).

  5. Eyni anda 100 sorğu gəlsə, 100 paralel nüsxə açılır (concurrency limitinə qədər).

Funksiya stateless olmalıdır: iki çağırış arasında yaddaşda və ya diskdə məlumatın qalacağına güvənməyin. Vəziyyət DB-də, S3-də və ya cache-də saxlanılır.

3. Nümunə: Sağlamlıq Yoxlayan Funksiya

import json, os, urllib.request

SITES = os.environ.get("SITES", "https://cavadmikayil.com").split(",")

def handler(event, context):
    results = {}
    for url in SITES:
        try:
            with urllib.request.urlopen(url, timeout=5) as r:
                results[url] = r.status
        except Exception as e:
            results[url] = str(e)
    down = {u: s for u, s in results.items() if s != 200}
    print(json.dumps({"checked": len(SITES), "down": down}))   # CloudWatch Logs-a düşür
    return {"statusCode": 200, "body": json.dumps(results)}

# EventBridge Scheduler ilə hər 5 dəqiqədən bir: rate(5 minutes)
import azure.functions as func
import logging, os, urllib.request

app = func.FunctionApp()

@app.timer_trigger(schedule="0 */5 * * * *", arg_name="timer")   # NCRONTAB: saniyə ilə başlayır
def check_sites(timer: func.TimerRequest) -> None:
    for url in os.environ.get("SITES", "").split(","):
        try:
            with urllib.request.urlopen(url, timeout=5) as r:
                logging.info("%s %s", url, r.status)
        except Exception as e:
            logging.error("DOWN %s %s", url, e)          # Application Insights-da alert qurulur

Cold start: kiçik paket, az asılılıq, provisioned concurrency / Premium plan ilə azaldılır.

Idempotency: platforma hadisəni təkrar göndərə bilər — eyni sifarişi iki dəfə emal etməyin.

Dead-letter queue: uğursuz hadisələr itmir, ayrıca növbəyə düşür.

5. Serverless Nə Vaxt Uyğundur?

Uyğundur

Qeyri-bərabər trafik, hadisəyə əsaslanan iş, avtomatlaşdırma skriptləri, kiçik API-lər, inteqrasiyalar, prototiplər.

Uyğun deyil

Uzun işləyən proseslər, sabit yüksək yük (VM/konteyner ucuz başa gəlir), çox aşağı latency tələbi, xüsusi OS asılılıqları.

Sistem administratoru üçün ən praktik istifadə: ops avtomatlaşdırması — gecə dev VM-lərini söndürmək, tag-sız resursları tapmaq, sertifikat müddəti bitənə 30 gün qalanda email göndərmək.
