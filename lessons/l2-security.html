Giriş: Layer 2 Təhlükəsizliyi

Firewall-lar adətən şəbəkənin kənarını qoruyur, amma daxili switch portuna qoşulan hücumçu Layer 2-də ciddi ziyan vura bilər. Bu dərsdə DHCP Snooping üzərində qurulan iki əlavə müdafiəni — Dynamic ARP Inspection və IP Source Guard — və porta qoşulmağı istifadəçi autentifikasiyasına bağlayan 802.1X-i öyrənəcəksiniz.

2. Dynamic ARP Inspection (DAI)

Untrusted portlardan gələn ARP paketlərini DHCP snooping binding cədvəli ilə müqayisə edir; IP–MAC uyğun gəlmirsə paket atılır.

Uplink/trunk portlar trusted edilir — onlardan gələn ARP yoxlanmır.

Untrusted portlarda defolt limit 15 ARP paketi/saniyə; aşıldıqda port err-disabled olur.

Statik IP-li cihazlar üçün ARP ACL yaradılmalıdır, əks halda onların ARP-ı bloklanır.

Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 10
Switch(config)# ip arp inspection vlan 10
Switch(config)# ip arp inspection validate src-mac dst-mac ip

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip dhcp snooping trust
Switch(config-if)# ip arp inspection trust

Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# ip arp inspection limit rate 20

DAI DHCP snooping-ə əsaslanır, ona görə əvvəlcə snooping aktivləşdirilir. Uplink həm snooping, həm DAI üçün trusted edilir; istifadəçi portlarında ARP limiti 20 pps-ə qaldırılır.

3. IP Source Guard (IPSG)

IPSG untrusted portda yalnız binding cədvəlində həmin porta yazılmış IP (və istəyə görə MAC) ünvanından gələn trafikə icazə verir. Başqasının IP-sini "götürən" host dərhal bloklanır. 

Switch(config)# interface FastEthernet0/5
Switch(config-if)# ip verify source

Switch(config)# interface FastEthernet0/6
Switch(config-if)# switchport port-security
Switch(config-if)# ip verify source port-security

Switch(config)# ip source binding 0011.2233.4455 vlan 10 192.168.10.50 interface FastEthernet0/7

Birinci port yalnız IP-ni, ikincisi IP + MAC-ı yoxlayır (port security tələb olunur). Statik IP-li cihaz üçün binding əl ilə əlavə edilir.

4. 802.1X: Port Əsaslı Autentifikasiya

Supplicant

Qoşulmaq istəyən cihaz (PC-dəki 802.1X klient).

Authenticator

Switch və ya AP — EAPOL mesajlarını RADIUS-a ötürür, nəticəyə görə portu açır.

Authentication server

RADIUS server (məs. Cisco ISE) — istifadəçini yoxlayır.

Autentifikasiya uğurlu olana qədər portdan yalnız EAPOL (802.1X) trafiki keçir.

Switch(config)# aaa new-model
Switch(config)# radius server ISE
Switch(config-radius-server)# address ipv4 10.0.0.100 auth-port 1812 acct-port 1813
Switch(config-radius-server)# key RadiusKey2026
Switch(config)# aaa authentication dot1x default group radius
Switch(config)# dot1x system-auth-control

Switch(config)# interface FastEthernet0/10
Switch(config-if)# switchport mode access
Switch(config-if)# authentication port-control auto
Switch(config-if)# dot1x pae authenticator

RADIUS serveri təyin edir, 802.1X-i qlobal aktivləşdirir və Fa0/10 portunu autentifikasiyadan keçməyən cihazlar üçün bağlı saxlayır.

5. Doğrulama

show ip arp inspection
show ip arp inspection vlan 10
show ip arp inspection statistics
show ip verify source
show ip source binding
show dot1x all
show authentication sessions

DAI statusu və atılan paketlər, IPSG filtrləri və binding-lər, 802.1X portları və autentifikasiya sessiyaları.
