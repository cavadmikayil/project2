Giriş: Elektrik Təchizatı Sistemləri

Ən yaxşı server və switch belə elektrik olmadan dəyərsizdir. Qəfil kəsilmə diskdəki məlumatı zədələyir, gərginlik sıçrayışı power supply-ı yandırır, aşağı gərginlik isə cihazların təsadüfi yenidən başlamasına səbəb olur. Bu dərsdə IT mütəxəssisinin bilməli olduğu əsas elektrik anlayışlarını və qoruma avadanlıqlarını öyrənirik.

Anlayışlar

Volt, Amper, Watt və VA — güc hesablamasının əsası.

Qoruma

Generator, UPS və stabilizator — hər biri fərqli problemi həll edir.

Diqqət

Etibarlı elektrik təchizatı olmadan heç bir IT sistemi etibarlı işləyə bilməz.

1. Volt, Amper və Watt

Volt (V) — gərginlik

Elektronları "itələyən" təzyiq. Ev şəbəkəsi 220–230 V AC; kompüter PSU-su bunu 12 V, 5 V, 3.3 V DC-yə çevirir.

Amper (A) — cərəyan

Dövrədən keçən cərəyanın miqdarı. Avtomat açarlar (məs. 16 A) və kabel kəsiyi buna görə seçilir.

Watt (W) — güc

Sərf olunan enerjinin sürəti. Hesab (kWh) və istilik (soyutma) watt ilə hesablanır.

2. Generator

Generator mexaniki enerjini elektrik enerjisinə çevirir və uzunmüddətli kəsilmələrdə — saatlar, günlər — enerji verir.

ATS (Automatic Transfer Switch) — şəbəkə kəsiləndə generatoru avtomatik işə salıb yükü ona keçirir.

Start vaxtı 10–30 saniyədir — bu boşluğu UPS doldurur.

Yanacaq ehtiyatı, səs-küy, havalandırma və müntəzəm test (ayda bir yük altında).

3. UPS — Fasiləsiz Enerji Təchizatı

UPS (Uninterruptible Power Supply) kəsilmə anında batareyadan dərhal enerji verir: serverlərin düzgün söndürülməsi və ya generatorun işə düşməsi üçün vaxt qazandırır.

NövNecə işləyirKeçid vaxtıHarada
Standby (offline)Normalda şəbəkədən, kəsilmədə batareyaya keçir~5–12 msFərdi kompüter
Line-interactive+ AVR: kiçik gərginlik dəyişmələrini batareyasız düzəldir~2–4 msOfis, kiçik server, switch
Online (double conversion)AC → DC → AC daim; çıxış həmişə təmizdir0 msServer otağı, data mərkəzi

VA və W: VA = W / power factor. Köhnə UPS-lərdə PF ~0.6–0.7, müasirlərdə ~0.9–1.0. 400 W yük üçün ən azı 600–700 VA.

Backup müddəti növdən yox, batareya tutumundan və yükdən asılıdır — istehsalçının runtime cədvəlinə baxın.

İdarəetmə kartı (SNMP/USB): batareya bitmədən serverlərə avtomatik "shutdown" əmri.

Batareya ömrü 3–5 ildir; ildə bir dəfə runtime testi edin.

4. Stabilizator (AVR)

Stabilizator dəyişkən şəbəkə gərginliyini (məs. 170–260 V) sabit 220 V-a gətirir. Kəsilmədən qorumur — bunun üçün UPS lazımdır.

Dəyişkən girişTənzimləməSabit çıxış

Relay tipli

Ucuz, pilləli tənzimləmə, klik səsi; dəqiqlik ~±8–10%.

Servo tipli

Mühərrikli, dəqiq (~±1–3%), amma nisbətən yavaş reaksiya.

Elektron (tiristor/triak)

Səssiz və sürətli (millisaniyələr), dəqiqlik ~±2–5%.

Giriş diapazonu (məs. 150–280 V) — regionun şəbəkəsinə uyğun seçilməlidir.

Çıxış dəqiqliyi və reaksiya vaxtı.

Həddindən artıq yük və qısa qapanma qoruması; gücü yükdən 25–30% çox seçin.

UPS: bütün ofis yerinə tez-tez yalnız server və şəbəkə rack-ı (≈1.7 kW) üçün 3 kVA online UPS — kompüterlər üçün fərdi 800 VA UPS-lər.

Stabilizator: ~12 kVA (8.5 kW + 25–30% ehtiyat).

Generator: ~15 kVA dizel + ATS — kondisionerlər və işıqlandırma da qoşulacaqsa, daha böyük.

Hər watt həm də istilikdir: 1.7 kW-lıq rack ~5 800 BTU/saat istilik verir (1 W ≈ 3.41 BTU/h) — server otağının kondisioneri buna görə seçilir.

Lab: Server Otağı üçün Enerji Hesablaması

Məqsəd

Real rack üçün güc sərfiyyatını, UPS ölçüsünü, backup müddətini və soyutma tələbini hesablamaq.

Alət

Kalkulyator və istehsalçı datasheet-ləri (APC/Eaton runtime cədvəlləri)

Müddət

Tapşırıqlar

  1. Cədvəldəki avadanlıqların ümumi gücünü hesablayın (W).

  2. Power factor 0.9 qəbul edərək VA-nı hesablayın və 25% ehtiyatla UPS ölçüsünü seçin.

  3. İstehsalçının runtime cədvəlindən (məs. 3 kVA line-interactive UPS) bu yük üçün təxmini backup müddətini tapın. 15 dəqiqə üçün hansı əlavə batareya paketi lazımdır?

  4. İstilik yükünü BTU/saat ilə hesablayın (1 W ≈ 3.41 BTU/h) və kondisioner gücünü müəyyənləşdirin.

  5. 230 V şəbəkədə ümumi cərəyanı (A) hesablayın — 16 A avtomat kifayətdirmi?

  6. Nəticəni bir səhifəlik "enerji planı" kimi yazın: sxem (şəbəkə → stabilizator → UPS → rack), seçimlər və əsaslandırma.

Uğur meyarları

Ümumi güc: 3×350 + 520 + 2×60 + 120 = 1810 W; VA ≈ 2011; ehtiyatla ≈ 2.5 kVA → 3 kVA UPS.

İstilik ≈ 6 170 BTU/h; cərəyan ≈ 7.9 A — 16 A xətt kifayətdir.

Planınızda UPS növünün (line-interactive və ya online) seçimi əsaslandırılıb.

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
