VTP (VLAN Trunking Protocol)

Giriş Modlar Vacib Xəbərdarlıq Əmrlər Portal

Giriş: VTP Nədir?

VLAN Trunking Protocol (VTP) — Cisco-ya məxsus protokoldur ki, VTP domenindəki switch-lər arasında VLAN məlumatlarını (VLAN ID, ad) mərkəzləşdirilmiş şəkildə paylaşmağa imkan verir. Bu, hər switch-də VLAN-ları əl ilə yaratmaq ehtiyacını aradan qaldırır — bir "server" switch-də edilən dəyişiklik bütün trunk bağlantılı "client" switch-lərə avtomatik yayılır.

1. VTP Modları

Mod VLAN yarada bilər? VLAN-ları yayır? VLAN-ları qəbul edir?
Server (defolt) Bəli Bəli Bəli
Client Xeyr Xeyr Bəli
Transparent Bəli (yalnız lokal) Yayımı ötürür, özü göndərmir Xeyr (öz VLAN bazasını dəyişmir)

2. Vacib Xəbərdarlıq: Revision Nömrəsi

Diqqət: Hər VTP dəyişikliyi konfiqurasiya revision nömrəsini artırır. Eyni VTP domenində, lakin daha yüksək revision nömrəsi olan yeni bir "server" və ya "client" switch şəbəkəyə qoşularsa, o öz (bəlkə köhnə/boş) VLAN bazasını bütün digər switch-lərə yayaraq mövcud VLAN-ları silə bilər. Yeni switch əlavə etməzdən əvvəl həmişə onun revision nömrəsini show vtp status ilə yoxlayın və ya VTP mode-unu transparent edərək riski aradan qaldırın.

3. Praktiki Əmrlər

Switch(config)# vtp domain MYCOMPANY
Switch(config)# vtp mode server
Switch(config)# vtp password Cisco123
Switch(config)# vtp pruning

VTP domenini təyin edir, switch-i server rejiminə qoyur, domenə parol əlavə edir və lazımsız VLAN trafikini trunk-lardan kəsən pruning funksiyasını aktivləşdirir.

show vtp status
show vtp password
show vtp counters

VTP domen, mod, versiya və revision nömrəsini, konfiqurasiya edilmiş parolu və VTP mesaj statistikasını göstərir.
