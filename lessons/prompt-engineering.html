Giriş: Yaxşı Sual — Yarı Cavabdır

LLM-ə "VLAN qur" yazsanız, ümumi cavab alacaqsınız. Kontekst, məqsəd və format versəniz — birbaşa istifadə oluna bilən nəticə. Prompt engineering modelə nə istədiyinizi aydın, tam və yoxlanıla bilən şəkildə izah etmək bacarığıdır. Bu, yeni kollegaya tapşırıq verməyə bənzəyir: o ağıllıdır, amma sizin şəbəkənizi tanımır.

2. Əsas Texnikalar

Few-shot: 1–3 nümunə göstərin — model formatı və üslubu nümunədən götürür.

Addım-addım düşünmə: "Əvvəl mümkün səbəbləri sadala, sonra hər birini necə yoxlayacağını yaz" — mürəkkəb troubleshooting-də daha yaxşı nəticə.

Tapşırığı bölün: böyük işi ardıcıl kiçik prompt-lara (plan → kod → test → sənəd).

Ayırıcılar: məlumatı təlimatdan ayırın — <log>...</log> və ya """ blokları.

Sual verməyə icazə: "Məlumat çatmırsa, cavab verməzdən əvvəl soruş."

Özünü yoxlama: "Cavabı yenidən nəzərdən keçir: IOS versiyasına uyğundurmu?"

3. Zəif və Güclü Prompt

OSPF işləmir, düzəlt.

Nəticə: OSPF troubleshooting haqqında ümumi siyahı — sizin problemə aid olub-olmadığı bəlli deyil.

Sən CCNA səviyyəli şəbəkə mühəndisisən.

Kontekst: iki Cisco router (R1, R2) Gi0/1 üzərindən birbaşa qoşulub, OSPF area 0.
Problem: R1-də "show ip ospf neighbor" boşdur, ping 10.0.12.2 işləyir.

Aşağıda hər iki router-in "show ip ospf interface Gi0/1" çıxışı var:
<R1>
...
</R1>
<R2>
...
</R2>

Tapşırıq:
1. Qonşuluğun qurulmamasının mümkün səbəblərini çıxışlara əsasən müəyyən et.
2. Ən ehtimallı səbəbi və onu düzəldən əmrləri yaz.
3. Düzəlişdən sonra yoxlama əmrlərini göstər.
Format: qısa izah + kod bloku. Çıxışda cavab üçün məlumat çatmırsa, bunu açıq de.

Burada model konkret məlumata (hello/dead taymerləri, area, subnet, autentifikasiya) baxıb dəqiq səbəbi göstərə bilər.

4. Çıxış Formatını İdarə Etmək

Aşağıdakı helpdesk müraciətini təsnif et və YALNIZ bu JSON formatında cavab ver:
{"kateqoriya": "şəbəkə|hardware|hesab|proqram|digər",
 "prioritet": "P1|P2|P3|P4",
 "qısa_xülasə": "maksimum 15 söz"}

Müraciət: """Səhərdən bütün mühasibatda 1C açılmır, hesabat bu gün təhvil verilməlidir."""

Dəqiq format (JSON, cədvəl, markdown) cavabı skriptlə emal etməyə imkan verir — ticket sistemlərinin avtomatlaşdırılması belə qurulur.

5. İterasiya: Prompt Kod Kimidir

  1. İlk cavaba baxın: nə çatışmır, nə artıqdır?

  2. Söhbəti davam etdirin: "Daha qısa", "IOS-XE sintaksisi ilə", "hər əmrə şərh əlavə et".

  3. Yaxşı işləyən prompt-u şablon kimi saxlayın — komanda ilə paylaşın.

  4. Kritik nəticəni həmişə laboratoriyada (Packet Tracer, GNS3, test serveri) yoxlayın.

6. Tipik Səhvlər

Sirləri yapışdırmaq

Parollar, açarlar, SNMP community, müştəri məlumatları — prompt-a qoymazdan əvvəl silin və ya əvəz edin (<PAROL>).

Qeyri-müəyyənlik

"Yaxşılaşdır" — nəyi? sürəti? oxunaqlılığı? təhlükəsizliyi?

Kor-koranə kopyalamaq

Əmri başa düşmədən istehsalat cihazına yapışdırmayın. "Bu əmr nə edir?" sualı həmişə yerindədir.
