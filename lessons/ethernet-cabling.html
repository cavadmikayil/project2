Giriş: Fiziki Qat Niyə Vacibdir?

Şəbəkə problemlərinin böyük bir hissəsi fiziki qatda — səhv kabel, zədələnmiş konnektor, uzunluq limitinin aşılması və ya speed/duplex uyğunsuzluğu səbəbindən yaranır. Bu dərsdə mis (UTP) və optik kabelləri, onların hansı hallarda istifadə olunduğunu və interfeys xətalarının necə oxunduğunu öyrənəcəksiniz.

Mis (UTP)

Ucuz və quraşdırılması asandır, PoE ilə cihazlara enerji ötürə bilir. Elektromaqnit müdaxiləsinə həssasdır və 100 metr limiti var.

Optik (Fiber)

İşıq siqnalı ilə işləyir: elektromaqnit müdaxiləsindən təsirlənmir, uzun məsafə və yüksək sürət təmin edir. SMF lazer, MMF isə daha qısa məsafələr üçün istifadə olunur.

Konsol (Rollover)

Kompüteri Cisco cihazının konsol portuna qoşmaq üçündür. Şəbəkə trafiki ötürmür, yalnız cihazın ilkin konfiqurasiyası üçün istifadə olunur.

2. Straight-through və Crossover

Kabelin iki ucu eyni standartla (T568B–T568B) sıxılıbsa straight-through, fərqli standartla (T568A–T568B) sıxılıbsa crossover alınır.

BirləşməKabelSəbəb
PC → SwitchStraight-throughFərqli tip cihazlar (MDI ↔ MDI-X)
Router → SwitchStraight-throughFərqli tip cihazlar
Switch → SwitchCrossoverEyni tip cihazlar
PC → PCCrossoverEyni tip cihazlar
PC → RouterCrossoverHər ikisi MDI portudur

Auto-MDIX: müasir switch və kartlar kabel növünü avtomatik tanıyır, ona görə praktikada adətən istənilən kabel işləyir. Amma imtahanlarda və köhnə avadanlıqda bu cədvəli bilmək vacibdir.

4. Speed, Duplex və İnterfeys Xətaları

Hər iki tərəf ya auto-negotiation-da olmalı, ya da eyni dəyərlərlə əl ilə təyin edilməlidir. Bir tərəf full, digəri half duplex olduqda link qalxır, amma performans kəskin düşür.

CRC xətaları: çərçivə zədələnib — pis kabel, müdaxilə və ya duplex uyğunsuzluğu (full-duplex tərəfdə).

Runts / Giants: 64 baytdan kiçik və ya 1518 baytdan (MTU) böyük çərçivələr.

Late collisions: 64 baytdan sonra baş verən toqquşma — demək olar ki, həmişə duplex uyğunsuzluğudur (half-duplex tərəfdə).

Input/Output drops: bufer dolub — interfeys trafik həcminə çatmır.

5. Praktiki Əmrlər

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# description Uplink-to-Core
Switch(config-if)# speed 1000
Switch(config-if)# duplex full
Switch(config-if)# mdix auto
Switch(config-if)# no shutdown

İnterfeysə təsvir verir, sürəti və duplex-i əl ilə təyin edir, auto-MDIX-i aktivləşdirir. Qarşı tərəfdə də eyni dəyərlər olmalıdır.

show interfaces status
show interfaces GigabitEthernet0/1
show interfaces counters errors
show controllers ethernet-controller GigabitEthernet0/1 phy

Portların speed/duplex vəziyyəti ("a-full" = avtomatik, "full" = əl ilə), CRC, runt, late collision sayğacları və fiziki qat məlumatı.

Lab: Kabel Növləri və Interfeys Xətaları

Məqsəd

Düzgün kabel növünü seçmək, speed/duplex uyğunsuzluğunu yaratmaq və interfeys sayğaclarında tapmaq.

Alət

Cisco Packet Tracer

Müddət

30 dəq · Başlanğıc

Topologiya

 PC1 ---(Fa0/1) SW1 (Gi0/1)=====(Gi0/1) SW2 (Fa0/1)--- PC2
                 |
               R1 (Gi0/0 — Fa0/24)

Ünvanlama cədvəli

CihazInterfeysIP / maska
PC1NIC192.168.1.10 /24
PC2NIC192.168.1.20 /24
R1Gi0/0192.168.1.1 /24

Tapşırıqlar

  1. Cihazları yerləşdirin və Automatic kabel seçimindən istifadə etmədən hər link üçün düzgün kabeli özünüz seçin (PC–SW, SW–SW, SW–R).

  2. Ünvanlama cədvəlinə görə IP-ləri təyin edin, PC1-dən PC2 və R1-ə ping edin.

  3. SW1 və SW2-nin Gi0/1 portlarında description yazın.

  4. SW2 Gi0/1-də speed 100 və duplex half, SW1-də duplex full təyin edin (uyğunsuzluq).

  5. Hər iki tərəfdə show interfaces gi0/1 ilə duplex, CRC, late collision sayğaclarını müqayisə edin; CDP-nin duplex mismatch xəbərdarlığını tapın.

  6. Hər iki tərəfi speed auto / duplex auto qaytarın və sayğacları clear counters ilə sıfırlayın.

Yoxlama

show interfaces status
show interfaces gi0/1 | include duplex|CRC|collision
show cdp neighbors detail

Uğur meyarları

PC–SW və SW–R üçün straight-through, SW–SW üçün (Auto-MDIX olmasa) crossover seçilib.

Duplex mismatch zamanı half tərəfdə late collision, full tərəfdə CRC/runt artır.

Auto rejimə qayıtdıqdan sonra interfeys Full-duplex və sayğaclar artmır.

Həll — əvvəlcə özünüz cəhd edin 
SW1(config)# interface gi0/1
SW1(config-if)# description Uplink-SW2
SW2(config)# interface gi0/1
SW2(config-if)# description Uplink-SW1
SW2(config-if)# speed 100
SW2(config-if)# duplex half
! ... müşahidədən sonra
SW2(config-if)# speed auto
SW2(config-if)# duplex auto
SW2# clear counters gi0/1

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
