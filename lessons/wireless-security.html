Giriş: Havada Hər Kəs Eşidir

Simli şəbəkəyə qoşulmaq üçün fiziki porta çıxış lazımdır, simsiz siqnal isə binanın hüdudlarından kənara da yayılır. Radio diapazonunda olan hər kəs çərçivələri tuta bilər. Ona görə simsiz şəbəkədə təhlükəsizlik üç məsələni birlikdə həll etməlidir.

1. Simsiz Təhlükəsizliyin Üç Sütunu

Autentifikasiya

Yalnız icazəli istifadəçilər qoşulsun, müştəri də saxta (rogue) AP-yə deyil, həqiqi AP-yə qoşulduğuna əmin olsun.

Məxfilik (şifrələmə)

Tutulmuş çərçivələr oxuna bilməsin.

Bütövlük (integrity)

Çərçivə yolda dəyişdirilməsin. Hər çərçivəyə MIC (Message Integrity Check) əlavə olunur.

3. Şifrələmə və Bütövlük

TKIP

WEP avadanlığında işləmək üçün müvəqqəti həll (WPA). Hər çərçivəyə ayrı açar və MIC əlavə etdi, amma artıq köhnəlib.

CCMP

AES əsaslı şifrələmə (AES-CTR) və CBC-MAC ilə bütövlük. WPA2-nin əsasıdır.

GCMP

AES-GCM — daha sürətli və güclü. WPA3-də, xüsusilə 192-bitlik Enterprise rejimində (GCMP-256) istifadə olunur.

Lab: WPA2-Enterprise: RADIUS ilə Wi-Fi

Məqsəd

Paylaşılan parol əvəzinə hər istifadəçinin öz hesabı ilə Wi-Fi-a qoşulmasını (802.1X) qurmaq.

Alət

Cisco Packet Tracer (WRT300N və ya WLC + Server-PT AAA)

Müddət

40 dəq · Orta

Topologiya

  Noutbuk ~~~ (Wi-Fi) ~~~ [AP / Wireless Router] ---- SW ---- [RADIUS Server 192.168.1.100]

Tapşırıqlar

  1. Server-PT-də AAA xidmətini aktivləşdirin: klient (AP) IP-si, shared secret Radius!23, istifadəçilər ali/Pa55, leyla/Pa55.

  2. Wireless router-də təhlükəsizlik rejimini WPA2-Enterprise edin, RADIUS server IP və secret yazın.

  3. Noutbukda WPA2-Enterprise profili ilə ali hesabı ilə qoşulun.

  4. Səhv parol ilə qoşulmağa cəhd edin — nəticə nədir?

  5. Eyni şəbəkəni WPA2-Personal ilə müqayisə edin: işçi işdən çıxanda nə etmək lazımdır?

Uğur meyarları

Yalnız RADIUS-da olan istifadəçilər qoşula bilir.

Səhv parolla autentifikasiya rədd edilir.

Enterprise rejimdə bir işçinin hesabını söndürmək kifayətdir — hamının parolunu dəyişmək lazım deyil.

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
