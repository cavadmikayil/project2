Giriş: Bütün Trafik Bərabər Deyil

Link doluduqda bütün paketlər eyni növbədə gözləyir. Faylın yüklənməsi bir az gecikə bilər, amma səs zəngində 200 ms gecikmə söhbəti pozur. QoS (Quality of Service) trafiki növlərə ayırır (klassifikasiya), onları işarələyir (marking) və vacib trafikə üstünlük verir.

1. QoS-un Həll Etdiyi Dörd Problem

GöstəriciMənasıSəs (VoIP) üçün tövsiyə
Bant genişliyiLinkin tutumuZəng başına ~30–130 kbps (kodekdən asılı)
Gecikmə (delay)Paketin mənbədən təyinata çatma müddətiBir istiqamətdə ≤ 150 ms
JitterGecikmənin dəyişkənliyi≤ 30 ms
İtki (loss)Atılan paketlərin faizi≤ 1%

Klassifikasiya

Paketin hansı sinfə aid olduğunu müəyyən etmək: ACL, port, protokol, NBAR (tətbiq tanıma) və ya mövcud işarəyə görə.

Marking

Sinfi başlıqdakı sahəyə yazmaq — sonrakı cihazlar yenidən analiz etmədən işarəyə baxır.

DSCP IP başlığında olduğu üçün router-lərdən keçəndə itmir, CoS isə hər Layer 2 hop-da yenidən yaranmalıdır.

3. Əsas DSCP Dəyərləri (PHB)

AdDSCPTipik trafik
EF (Expedited Forwarding)46Səs — ən aşağı gecikmə
AF41 / AF42 / AF4334 / 36 / 38İnteraktiv video
AF3126Kritik biznes tətbiqləri

CS648Marşrutlaşdırma protokolları (OSPF və s.)
CS3 / CS0 (Default)24 / 0Səs siqnalizasiyası / best effort

AFxy formulu: DSCP = 8x + 2y. x — sinif (1–4, böyük olan daha vacib), y — atılma prioriteti (1–3, böyük olan tıxac zamanı daha əvvəl atılır). Məs. AF31 = 8×3 + 2×1 = 26. CS dəyərləri = sinif × 8.

4. Trust Boundary

İstifadəçi öz kompüterində paketlərini EF ilə işarələyib şəbəkədə "VIP" ola bilər. Buna görə işarələrə yalnız müəyyən nöqtədən — trust boundary-dən — etibar edilir. Onun xaricindən gələn işarələr silinir və ya yenidən yazılır. 

PC ──── IP telefon ──── Access switch ──── Distribution ──── Router
[etibar yox]  [trust boundary burada — telefonun CoS 5 işarəsinə etibar edilir]
               PC-nin işarələri telefon tərəfindən 0-a yazılır

Ən yaxşı təcrübə: klassifikasiya və marking-i mənbəyə mümkün qədər yaxın — access switch-də və ya IP telefonda etmək.

5. MQC ilə Klassifikasiya və Marking

R1(config)# class-map match-any VOICE
R1(config-cmap)# match protocol rtp audio
R1(config)# class-map match-any WEB
R1(config-cmap)# match protocol http
R1(config-cmap)# match protocol ssl

R1(config)# policy-map MARKING-IN
R1(config-pmap)# class VOICE
R1(config-pmap-c)# set dscp ef
R1(config-pmap)# class WEB
R1(config-pmap-c)# set dscp af21
R1(config-pmap)# class class-default
R1(config-pmap-c)# set dscp default

R1(config)# interface GigabitEthernet0/0
R1(config-if)# service-policy input MARKING-IN

R1# show policy-map interface GigabitEthernet0/0

MQC (Modular QoS CLI) üç addımdan ibarətdir: class-map (nəyi tanıyırıq — burada NBAR ilə), policy-map (hər sinfə nə edirik), service-policy (interfeysə tətbiq). Sonuncu əmr hər sinfə düşən paket sayını göstərir.

Lab: Trust Boundary və DSCP Marking

Məqsəd

IP telefon trafikinin DSCP EF ilə işarələnməsini və switch-də etibar sərhədini qurmaq, Wireshark-da işarələri görmək.

Alət

Real Catalyst switch / CML və ya Packet Tracer (məhdud) + Wireshark

Müddət

40 dəq · Çətin

Tapşırıqlar

  1. Access switch-də IP telefon portunda mls qos trust device cisco-phone və mls qos trust cos (və ya yeni platformalarda trust device) konfiqurasiya edin.

  2. PC portunda etibar etməyin: PC-nin özünün qoyduğu DSCP-nin 0-a yenidən yazıldığını göstərin.

  3. Router-də class-map ilə RTP portlarını (udp 16384–32767) tanıyıb policy-map ilə set dscp ef tətbiq edin (inbound).

  4. Wireshark-da səs paketinin IP başlığında DSCP = 46 (EF), signaling üçün CS3 olduğunu yoxlayın.

  5. Təsnifat cədvəli hazırlayın: səs, video, iş tətbiqləri, qalan trafik — hər biri üçün DSCP.

Yoxlama

show mls qos interface fa0/5
show class-map
show policy-map interface gi0/0
Wireshark: ip.dsfield.dscp == 46

Uğur meyarları

Telefon portunda trust aktivdir, PC portunda işarələr sıfırlanır.

Policy-map sayğaclarında səs sinfi paketləri artır.

Səs EF (46), signaling CS3 (24), qalan trafik default (0).

Həll — əvvəlcə özünüz cəhd edin 
class-map match-any VOICE
 match ip dscp ef
 match protocol rtp audio
policy-map MARK-IN
 class VOICE
  set dscp ef
 class class-default
  set dscp default
interface gi0/0
 service-policy input MARK-IN

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
