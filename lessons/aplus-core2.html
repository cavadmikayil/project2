Core 2 (220-1202) Domenləri

Core 2 "proqram tərəfi" haqqındadır: Windows, macOS, Linux, mobil OS-lar, təhlükəsizlik, proqram problemləri və peşəkar iş prosedurları. Burada ən çox itirilən ballar Windows alətlərinin adları və malware silmə addımlarının ardıcıllığı ilə bağlıdır.

Operating Systems

Windows edition-ları, quraşdırma, alətlər, əmrlər, macOS və Linux əsasları.

Security

Fiziki və məntiqi təhlükəsizlik, Windows təhlükəsizlik ayarları, SOHO router, sosial mühəndislik.

Software Troubleshooting

Windows, mobil OS və tətbiq problemləri, malware əlamətləri.

Operational Procedures

Sənədləşmə, change management, backup, təhlükəsizlik, ətraf mühit, peşəkarlıq, skriptlər, uzaqdan giriş.

3. Təhlükəsizlik

Fiziki: access control vestibule (mantrap), badge, biometrika, kilidli rack, video müşahidə, privacy filter.

Windows: UAC, Microsoft Defender Antivirus və Firewall, BitLocker, NTFS vs share icazələri (ən sərt olanı qalib gəlir).

SOHO router: defolt parolu dəyiş, firmware yenilə, WPA3, WPS söndür, UPnP-ni lazım deyilsə söndür, guest şəbəkə.

Sosial mühəndislik: phishing, vishing, smishing, tailgating, shoulder surfing, impersonation, dumpster diving.

Məlumatın məhvi: shredding, degaussing (HDD), drilling, incineration; üçüncü tərəfdən certificate of destruction.

Mobil: ekran kilidi, biometrika, remote wipe, locator tətbiqləri, OS yeniləmələri.

4. Malware Silmənin 7 Addımı (ardıcıllıq soruşulur!)

  1. Investigate and verify — malware əlamətlərini araşdır və təsdiqlə.

  2. Quarantine — yoluxmuş sistemi şəbəkədən təcrid et.

  3. Disable System Restore (Windows) — köhnə restore point-lərdə malware qalmasın.

  4. Remediate — anti-malware-i yenilə, skan et və sil (safe mode, pre-installation environment).

  5. Schedule scans and run updates.

  6. Enable System Restore və yeni təmiz restore point yarat.

  7. Educate the end user — istifadəçini maarifləndir.

Əlamətlər: brauzer yönləndirmələri, saxta antivirus pəncərələri, yavaşlıq, naməlum proseslər, deaktiv edilmiş antivirus, fayl uzantılarının dəyişməsi (ransomware), dostlara göndərilmiş spam.

5. Əməliyyat Prosedurları

Change management

Sorğu, məqsəd, əhatə, risk təhlili, rollback planı, CAB təsdiqi, end-user acceptance, sənədləşmə.

Backup

Full, incremental, differential, synthetic; 3-2-1 qaydası; GFS rotasiyası; restore testi.

Təhlükəsizlik

ESD strap və mat, düzgün qaldırma, yanğın söndürən (elektrik üçün CO₂), MSDS/SDS sənədləri.

Skriptlər

.bat, .ps1, .sh, .py, .js, .vbs — tapşırıqları avtomatlaşdırmaq.

Uzaqdan giriş

RDP, SSH, VPN, RMM alətləri; istifadəçinin razılığı və sessiyanın loglanması.

Peşəkarlıq

Vaxtında gəlmək, aktiv dinləmək, jargon olmadan danışmaq, istifadəçinin məlumatına hörmət.
