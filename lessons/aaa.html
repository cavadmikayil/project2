Giriş: Mərkəzi Hesablar

100 switch-in hər birində lokal istifadəçi saxlamaq idarə olunmazdır: işçi işdən çıxanda onun hesabını hər cihazdan ayrıca silmək lazımdır. AAA hesabları mərkəzi serverdə (Cisco ISE, FreeRADIUS, Windows NPS) saxlayır və hər girişi orada yoxlayır.

Authentication

Kimdir? — istifadəçi adı, parol, sertifikat, MFA.

Authorization

Nə edə bilər? — privilege səviyyəsi, icazəli əmrlər, VLAN təyinatı.

Accounting

Nə etdi? — giriş vaxtı, icra olunan əmrlər, sessiya müddəti.

2. Metod Siyahıları

aaa authentication login default group tacacs+ local — metodlar soldan sağa sınanır. Növbəti metoda yalnız əvvəlki cavab vermədikdə (server əlçatmaz) keçilir. Server "parol səhvdir" deyirsə, lokal hesab yoxlanılmır.

Həmişə sonda local ehtiyat metodu və lokal admin hesabı saxlayın. Əks halda server əlçatmaz olanda cihaza heç kim daxil ola bilməz. aaa new-model yazıldığı anda VTY xətləri avtomatik olaraq defolt AAA metoduna keçir — konfiqurasiyanı konsoldan edin.

3. Admin Girişi — TACACS+

R1(config)# username backup-admin privilege 15 algorithm-type scrypt secret Ehtiyat!2026
R1(config)# aaa new-model
R1(config)# tacacs server ISE
R1(config-server-tacacs)# address ipv4 10.0.0.100
R1(config-server-tacacs)# key TacacsKey!2026

R1(config)# aaa authentication login default group tacacs+ local
R1(config)# aaa authorization exec default group tacacs+ local
R1(config)# aaa authorization commands 15 default group tacacs+ local
R1(config)# aaa accounting commands 15 default start-stop group tacacs+

R1(config)# line vty 0 15
R1(config-line)# transport input ssh

Girişlər TACACS+ serverində yoxlanılır, privilege 15 əmrlərinin hər biri serverdə avtorizasiya olunur və qeydə alınır. Server əlçatmaz olduqda lokal "backup-admin" hesabı işləyir.

4. İstifadəçi Girişi — RADIUS

RADIUS-dan adətən şəbəkəyə giriş üçün istifadə olunur: switch portunda 802.1X, simsiz WPA2/3-Enterprise və uzaqdan VPN.

SW1(config)# aaa new-model
SW1(config)# radius server NPS
SW1(config-radius-server)# address ipv4 10.0.0.110 auth-port 1812 acct-port 1813
SW1(config-radius-server)# key RadiusKey!2026
SW1(config)# aaa authentication dot1x default group radius
SW1(config)# aaa authorization network default group radius
SW1(config)# aaa accounting dot1x default start-stop group radius
SW1(config)# dot1x system-auth-control

802.1X istifadəçiləri RADIUS-da yoxlanılır; authorization network serverin istifadəçiyə dinamik VLAN təyin etməsinə imkan verir. Port səviyyəsində konfiqurasiya "DAI, IP Source Guard və 802.1X" dərsindədir.

Lab: AAA: TACACS+ Server və Yerli Fallback

Məqsəd

Cihaz girişini mərkəzi TACACS+ serverinə bağlamaq və server əlçatmaz olanda yerli hesabla girişi saxlamaq.

Alət

Cisco Packet Tracer (Server-PT AAA xidməti)

Müddət

40 dəq · Orta

Topologiya

 Admin-PC --- SW --- R1 (192.168.1.1) --- AAA Server (192.168.1.100, TACACS+)

Tapşırıqlar

  1. Server-PT-də AAA: network configuration-a R1-i əlavə edin (IP, key Tacacs!23, TACACS), istifadəçi netadmin yaradın.

  2. R1-də aaa new-model, TACACS+ server tərifi və key.

  3. aaa authentication login default group tacacs+ local — əvvəl server, əlçatmazdırsa yerli baza.

  4. Yerli ehtiyat hesabı username breakglass secret ... yaradın.

  5. Admin-PC-dən netadmin ilə SSH/Telnet girişini yoxlayın.

  6. Serveri söndürün və breakglass ilə girişin işlədiyini göstərin.

Yoxlama

show aaa servers
show tacacs
show running-config | section aaa
debug aaa authentication

Uğur meyarları

Server işləyəndə yalnız TACACS+ hesabları qəbul olunur.

Server əlçatmaz olanda yerli hesabla giriş mümkündür.

Konsol xəttinin də eyni siyahı ilə qorunduğu yoxlanılıb (özünüzü kilidləməyin!).

Həll — əvvəlcə özünüz cəhd edin 
R1(config)# username breakglass privilege 15 secret Br3ak-Gl4ss!
R1(config)# aaa new-model
R1(config)# tacacs server TAC1
R1(config-server-tacacs)# address ipv4 192.168.1.100
R1(config-server-tacacs)# key Tacacs!23
R1(config)# aaa authentication login default group tacacs+ local
R1(config)# aaa authorization exec default group tacacs+ local
R1(config)# line vty 0 4
R1(config-line)# login authentication default
! Köhnə Packet Tracer versiyalarında: tacacs-server host 192.168.1.100 key Tacacs!23
