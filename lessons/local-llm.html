Giriş: Model Öz Kompüterinizdə

Açıq çəkili (open-weight) modelləri — Llama, Mistral, Gemma, Qwen, Phi və s. — öz noutbukunuzda və ya serverinizdə işlətmək olar. Ollama bunu sadələşdirən alətdir: bir əmrlə modeli yükləyir, işə salır və localhost:11434 ünvanında API təqdim edir.

2. Hansı Hardware Lazımdır?

Əsas məhdudiyyət yaddaşdır: model tam olaraq RAM-a (və ya GPU VRAM-ına) sığmalıdır. Kvantlaşdırılmış (4-bit) modellər üçün təxmini tələb:

Model ölçüsüTəxmini yaddaş (4-bit)Harada işləyir
1–4B parametr2–4 GBAdi noutbuk (CPU ilə də)
7–9B5–8 GB16 GB RAM-lı noutbuk, 8 GB VRAM-lı GPU
13–14B9–12 GB12–16 GB VRAM
30B+20+ GBGüclü GPU və ya çox yaddaşlı iş stansiyası

GPU olmadan da işləyir, sadəcə yavaş olur. Apple Silicon (M-seriya) Mac-larda ortaq yaddaş sayəsində lokal modellər yaxşı işləyir.

3. Ollama: Quraşdırma və Əmrlər

# Linux (macOS və Windows üçün ollama.com-dan installer)
curl -fsSL https://ollama.com/install.sh | sh

ollama pull llama3.2          # modeli yüklə
ollama run llama3.2           # interaktiv çat (çıxış: /bye)
ollama list                   # yüklənmiş modellər
ollama ps                     # hazırda yaddaşda olan modellər
ollama rm llama3.2            # modeli sil

# Birdəfəlik sorğu
ollama run llama3.2 "OSPF-in DR/BDR seçimini 3 cümlədə izah et"

Mövcud modellərin siyahısı və ölçüləri ollama.com/library səhifəsindədir. Model adları və versiyaları zamanla dəyişir — ən son siyahıya ordan baxın.

4. REST API

curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2",
  "messages": [
    {"role": "system", "content": "Sən helpdesk assistentisən. Qısa cavab ver."},
    {"role": "user", "content": "Outlook hər dəfə parol soruşur. İlk 3 addım?"}
  ],
  "stream": false
}'

API standart olaraq yalnız localhost-da dinləyir. Onu şəbəkəyə açsanız (OLLAMA_HOST=0.0.0.0), autentifikasiyası olmadığını unutmayın — firewall və ya reverse proxy + autentifikasiya ilə qoruyun.

5. Python ilə: Ticket Təsnifatı

import json
import requests

def classify(ticket_text: str) -> dict:
    prompt = (
        "Helpdesk müraciətini təsnif et. YALNIZ JSON qaytar: "
        '{"kateqoriya": "şəbəkə|hardware|hesab|proqram|digər", "prioritet": "P1|P2|P3|P4"}\n'
        f"Müraciət: {ticket_text}"
    )
    r = requests.post(
        "http://localhost:11434/api/generate",
        json={"model": "llama3.2", "prompt": prompt, "format": "json", "stream": False},
        timeout=120,
    )
    r.raise_for_status()
    return json.loads(r.json()["response"])

print(classify("Bütün 3-cü mərtəbədə Wi-Fi yoxdur, kabel ilə işləyir"))

"format": "json" modeli etibarlı JSON qaytarmağa məcbur edir. Kiçik modellərin nəticəsini bir neçə onlarla real ticket üzərində yoxlayın — səhv təsnifat faizini bilmək vacibdir.
