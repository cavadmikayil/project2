Giriş: Router Nə Edir?

Router müxtəlif IP şəbəkələrini birləşdirir və hər paket üçün marşrut cədvəlinə baxaraq növbəti hop-u seçir. Switch-dən fərqli olaraq broadcast-ları ötürmür və hər interfeysi ayrıca şəbəkədədir.

İnterfeyslər

Defolt olaraq shutdown vəziyyətindədir — no shutdown lazımdır (switch portlarının əksinə).

Marşrut cədvəli

Connected, local, statik və dinamik marşrutlar.

Yaddaş

ROM (bootstrap), Flash (IOS), NVRAM (startup-config), RAM (running-config, cədvəllər).

1. Defolt Gateway

Host paketi göndərməzdən əvvəl öz IP-si ilə maskasını təyinat IP-si ilə müqayisə edir:

Eyni şəbəkədədir: təyinatın MAC-ını ARP ilə tapır və birbaşa göndərir.

Fərqli şəbəkədədir: paketi defolt gateway-ə (router interfeysinə) göndərir; ARP gateway-in MAC-ı üçün edilir.

Gateway yoxdur və ya səhvdir: host öz şəbəkəsinə ping ata bilir, başqa şəbəkələrə isə yox — ən çox rast gəlinən problemlərdən biridir.

2. Paket Router-dən Necə Keçir?

  1. Çərçivə gəlir; FCS yoxlanılır, təyinat MAC routerin interfeysidirsə qəbul olunur.

  2. Layer 2 başlığı atılır (de-enkapsulyasiya), IP paketi qalır.

  3. Təyinat IP üçün marşrut cədvəlində ən uzun prefiks uyğunluğu axtarılır. Uyğunluq yoxdursa və defolt marşrut da yoxdursa paket atılır (ICMP Unreachable).

  4. TTL 1 azaldılır; 0 olarsa paket atılır və ICMP Time Exceeded göndərilir. IP başlığının checksum-u yenidən hesablanır.

  5. Çıxış interfeysi üçün yeni Layer 2 başlığı qurulur: mənbə MAC — routerin çıxış interfeysi, təyinat MAC — növbəti hop (ARP ilə).

Seçim ardıcıllığı: 1) ən uzun prefiks; 2) eyni prefiks bir neçə protokoldan gəlirsə — ən aşağı AD; 3) eyni protokol daxilində — ən aşağı metrika. Metrikalar bərabərdirsə, trafik yollar arasında bölünür (ECMP).

4. Router-in Əsas Konfiqurasiyası

Router(config)# hostname R1
R1(config)# interface GigabitEthernet0/0
R1(config-if)# description LAN
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config)# interface GigabitEthernet0/1
R1(config-if)# description WAN-to-R2
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# no shutdown
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
R1# copy running-config startup-config

İnterfeyslərə ünvan verir, onları aktivləşdirir və defolt marşrut yazır. Hər aktiv interfeys cədvəldə bir "C" və bir "L" marşrutu yaradır.

show ip interface brief
show ip route
show ip route 10.2.2.50
show interfaces GigabitEthernet0/0
show protocols

İnterfeys statusu (up/up, administratively down), marşrut cədvəli, konkret ünvan üçün seçilən marşrut, interfeys statistikası və IP ünvanlar.
