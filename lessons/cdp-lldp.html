Giriş: Şəbəkə Kəşf Protokolları

Şəbəkə cihazlarının bir-birini avtomatik kəşf etməsi və məlumat mübadiləsi şəbəkə idarəçiliyində çox vacibdir. Bu dərs iki əsas kəşf protokolunu — Cisco Discovery Protocol (CDP) və Link Layer Discovery Protocol (LLDP) — araşdırır. Onlar topologiya xəritəsini qurmağa, problemləri aradan qaldırmağa və "bu kabel hansı porta gedir?" sualına saniyələr içində cavab tapmağa kömək edir.

Topologiya

Sənəd olmayan şəbəkənin xəritəsini qonşuluq məlumatlarından bərpa etmək.

Kabel yoxlaması

Port-to-port bağlantısını fiziki olaraq otağa getmədən təsdiqləmək.

IP telefonlar

Voice VLAN məlumatı və PoE gücü CDP/LLDP-MED ilə danışılır.

1. Cisco Discovery Protocol (CDP)

CDP Cisco-nun qonşu Cisco cihazları haqqında məlumat toplamaq üçün hazırladığı mülkiyyət (proprietary) protokoludur. Layer 2 səviyyəsində işləyir və yalnız birbaşa qoşulmuş cihazlar haqqında məlumat mübadiləsi aparır — router-dən keçmir.

Qonşu məlumatı: device ID, local/remote port, platforma, IOS versiyası, IP ünvanı, native VLAN, duplex.

Cisco mülkiyyəti: yalnız Cisco (və CDP dəstəkləyən bəzi) cihazlar arasında işləyir.

Timer-lər: hər 60 saniyədən bir elan göndərir, holdtime 180 saniyədir.

Layer 2: multicast MAC 0100.0CCC.CCCC ünvanına göndərilir, IP konfiqurasiyası tələb etmir.

! Qlobal
cdp run
no cdp run
cdp timer 30
cdp holdtime 120

! İnterfeysdə
interface GigabitEthernet0/1
 cdp enable
 no cdp enable

CDP Cisco cihazlarında defolt olaraq aktivdir. İnternetə və ya etibarsız şəbəkəyə baxan interfeyslərdə söndürülməlidir.

show cdp
show cdp neighbors
show cdp neighbors detail
show cdp entry SW2
show cdp interface
show cdp traffic

show cdp neighbors-da Local Intrfce sizin portunuz, Port ID isə qonşunun portudur. IP ünvanını görmək üçün detail lazımdır.

2. Link Layer Discovery Protocol (LLDP)

LLDP IEEE 802.1AB standartına əsaslanan, istehsalçıdan asılı olmayan (vendor-neutral) kəşf protokoludur. Cisco, Juniper, HPE, Aruba, MikroTik, serverlər və IP telefonlar arasında işləyir.

Multi-vendor: müxtəlif istehsalçıların cihazları bir-birini görür.

Standart: IEEE 802.1AB; LLDP-MED genişlənməsi IP telefonlar üçün.

Ayrı istiqamətlər: göndərmə (transmit) və qəbul (receive) ayrıca idarə olunur.

TLV formatı: Type-Length-Value — yeni məlumat növlərini əlavə etmək asandır.

Timer-lər: elan hər 30 saniyə, holdtime 120 saniyə, reinit delay 2 saniyə.

! Qlobal (Cisco-da defolt olaraq söndürülüdür)
lldp run
lldp timer 30
lldp holdtime 120

! İnterfeysdə
interface GigabitEthernet0/1
 lldp transmit
 lldp receive
 no lldp transmit
 no lldp receive

Cisco IOS-da LLDP defolt olaraq söndürülüdür — multi-vendor mühitdə lldp run ilə aktivləşdirin.

show lldp
show lldp neighbors
show lldp neighbors detail
show lldp interface
show lldp traffic

Linux serverdə LLDP üçün lldpd paketi: lldpcli show neighbors — server hansı switch portuna qoşulub, dərhal görünür.

4. Təhlükəsizlik

Kəşf protokolları açıq mətnlə göndərilir: hücumçu bir paket tutaraq cihazın modelini, IOS versiyasını və idarəetmə IP-sini öyrənir — zəiflik axtarmaq üçün ideal başlanğıc.

İstifadəçi portlarında söndürün: no cdp enable, no lldp transmit (IP telefon yoxdursa).

İnternetə baxan interfeyslərdə həmişə söndürün.

Infrastruktur linklərində (switch–switch, switch–router) aktiv saxlayın — troubleshooting üçün dəyərlidir.

Lab: Kəşf Protokolları ilə Topologiya Xəritəsi

Məqsəd

CDP və LLDP ilə naməlum şəbəkənin xəritəsini çıxarmaq və təhlükəsizlik üçün lazımsız yerlərdə söndürmək.

Alət

Cisco Packet Tracer

Müddət

30 dəq · Orta

Topologiya

          R1 (Gi0/0)
           |
       (Gi0/1) SW1 (Gi0/2) ---- (Gi0/1) SW2 (Fa0/1) --- IP Phone
           |
       (Fa0/5) PC-Admin

Tapşırıqlar

  1. Topologiyanı qurun, cihazlara IP ünvanlar verin (switch-lərdə VLAN 1-də).

  2. SW1-də show cdp neighbors və detail ilə qonşuların modelini, portunu və IP-sini tapın.

  3. Hər iki switch və router-də lldp run aktivləşdirin, eyni məlumatı show lldp neighbors detail ilə alın.

  4. CDP timer-i 30 s, holdtime 90 s edin və show cdp ilə yoxlayın.

  5. PC-Admin portunda (Fa0/5) CDP və LLDP-ni söndürün; infrastruktur linklərində aktiv saxlayın.

Yoxlama

show cdp neighbors
show cdp neighbors detail
show lldp neighbors detail
show cdp interface fa0/5
show lldp interface fa0/5

Uğur meyarları

Qonşu cədvəlindən tam topologiya diaqramı çəkilir.

Fa0/5-də CDP/LLDP elanı göndərilmir.

Uplink-lərdə hər iki protokol işləyir.

Həll — əvvəlcə özünüz cəhd edin 
SW1(config)# lldp run
SW1(config)# cdp timer 30
SW1(config)# cdp holdtime 90
SW1(config)# interface fa0/5
SW1(config-if)# no cdp enable
SW1(config-if)# no lldp transmit
SW1(config-if)# no lldp receive

Packet Tracer faylı (.pkt) verilmir — topologiyanı özünüz qurmaq labın bir hissəsidir.
