Access Control Lists (ACL)

Giriş Növlər Wildcard Mask Əmrlər Portal

Giriş: ACL Nədir?

Access Control List (ACL) — router və ya switch-in interfeysindən keçən trafiki qaydalar əsasında icazə verən (permit) və ya rədd edən (deny) siyahıdır. ACL-lər paket filterləmə, trafik təhlükəsizliyi, NAT-ın hansı ünvanlara tətbiq olunacağının müəyyənləşdirilməsi və marşrutlaşdırma yeniləmələrinin filterlənməsi kimi məqsədlər üçün istifadə olunur. Siyahı yuxarıdan aşağıya doğru, ilk uyğunluq tapılana qədər emal edilir; sonda gizli "deny any" var.

1. Standart və Genişləndirilmiş ACL

Xüsusiyyət Standart ACL Genişləndirilmiş ACL
Nömrə diapazonu 1–99, 1300–1999 100–199, 2000–2699
Filter meyarı Yalnız mənbə IP Mənbə/təyinat IP, protokol, port
Tövsiyə olunan yer Təyinata yaxın (dəqiqlik azdır) Mənbəyə yaxın

2. Wildcard Mask

ACL-lərdə subnet maskası əvəzinə wildcard mask istifadə olunur. "0" bit — dəqiq uyğunluq tələb edir, "1" bit — həmin bit önəmsizdir (hər dəyərə uyğun gəlir).

0.0.0.0 — yalnız dəqiq IP ünvanı (host açar sözü ilə eyni).

255.255.255.255 — istənilən ünvan (any açar sözü ilə eyni).

0.0.0.255 — /24 subnetin bütün host-ları (məs. 192.168.1.0/24).

Hesablama qaydası: wildcard = 255.255.255.255 − subnet maskası.

3. Praktiki Əmrlər

Router(config)# access-list 10 permit 192.168.1.0 0.0.0.255
Router(config)# access-list 10 deny any

Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group 10 in

192.168.1.0/24 şəbəkəsinə icazə verir, qalan hər şeyi rədd edir və interfeysin giriş (in) istiqamətinə tətbiq edir.

Router(config)# access-list 110 permit tcp 192.168.1.0 0.0.0.255 any eq 80
Router(config)# access-list 110 permit tcp 192.168.1.0 0.0.0.255 any eq 443
Router(config)# access-list 110 deny ip any any

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip access-group 110 out

192.168.1.0/24-dən yalnız HTTP/HTTPS trafikinə icazə verir, qalanını rədd edir.

Router(config)# ip access-list extended BLOCK-FTP
Router(config-ext-nacl)# deny tcp any any eq 21
Router(config-ext-nacl)# permit ip any any

Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group BLOCK-FTP in

Adlandırılmış ACL-lər sıra nömrələrini əl ilə idarə etməyə və daha oxunaqlı konfiqurasiyaya imkan verir.

show access-lists
show ip interface GigabitEthernet0/1
show running-config | section access-list

Bütün ACL-ləri, match sayğaclarını və interfeysə tətbiq olunan ACL-ləri göstərir.
