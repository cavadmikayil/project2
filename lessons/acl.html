Giriş: ACL Nədir?

Access Control List (ACL) router və ya switch interfeysindən keçən trafiki qaydalar əsasında buraxan (permit) və ya rədd edən (deny) siyahıdır. ACL-lər paket filtrləmə, NAT-ın hansı ünvanlara tətbiq olunacağını seçmək, VTY girişini məhdudlaşdırmaq, QoS təsnifatı və marşrut filtrləmə üçün istifadə olunur.

Təhlükəsizlik

Qonaq VLAN-ı serverlərə buraxmamaq, yalnız admin şəbəkəsindən SSH.

NAT və QoS

"Hansı trafik?" sualına cavab — ACL seçici kimi.

Alət

Wildcard Mask Kalkulyatoru ilə qaydaları yoxlayın.

1. Emal Məntiqi

  1. Siyahı yuxarıdan aşağıya yoxlanılır.

  2. İlk uyğun qayda tətbiq olunur, qalanlarına baxılmır — sıra vacibdir: xüsusi qaydalar əvvəl, ümumilər sonra.

  3. Heç bir qayda uyğun gəlməzsə — sonda gizli implicit deny any işləyir. Ən azı bir permit olmayan ACL bütün trafiki bloklayır.

  4. Hər interfeysdə hər istiqamət (in/out) və protokol (IPv4/IPv6) üçün yalnız bir ACL.

3. Wildcard Mask

ACL-lərdə subnet maskası əvəzinə wildcard mask istifadə olunur: 0 bit — dəqiq uyğunluq tələb edir, 1 bit — həmin bit önəmsizdir.

0.0.0.0 — yalnız dəqiq IP (host 10.1.1.5 ilə eyni).

255.255.255.255 — istənilən ünvan (any ilə eyni).

0.0.0.255 — /24 subnetin bütün host-ları (məs. 192.168.1.0/24).

Hesablama: wildcard = 255.255.255.255 − subnet maska. /20 → 0.0.15.255.

4. Praktiki Əmrlər

Router(config)# access-list 10 permit 192.168.1.0 0.0.0.255
Router(config)# access-list 10 deny any
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group 10 out

192.168.1.0/24 şəbəkəsinə icazə verir, qalan hər şeyi rədd edir; standart ACL təyinata yaxın interfeysə tətbiq olunur.

Router(config)# access-list 110 permit tcp 192.168.1.0 0.0.0.255 any eq 80
Router(config)# access-list 110 permit tcp 192.168.1.0 0.0.0.255 any eq 443
Router(config)# access-list 110 permit udp 192.168.1.0 0.0.0.255 any eq 53
Router(config)# access-list 110 deny ip any any log
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip access-group 110 in

192.168.1.0/24-dən yalnız HTTP, HTTPS və DNS; qalanı rədd edilir və loglanır. Mənbəyə yaxın interfeysdə, in istiqamətində.

Router(config)# ip access-list extended BLOCK-FTP
Router(config-ext-nacl)# 10 deny tcp any any eq 21
Router(config-ext-nacl)# 20 permit ip any any
Router(config-ext-nacl)# 15 deny tcp any any eq 23      ! 10 və 20 arasına əlavə
Router(config-ext-nacl)# no 15                           ! tək sətri sil
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group BLOCK-FTP in

Named ACL-də sıra nömrələri ilə istənilən yerə qayda əlavə etmək və tək sətri silmək olur — nömrəli ACL-ə nisbətən çox rahatdır.

Router(config)# ip access-list standard MGMT
Router(config-std-nacl)# permit 10.0.99.0 0.0.0.255
Router(config)# line vty 0 4
Router(config-line)# access-class MGMT in

SSH/Telnet girişini yalnız idarəetmə şəbəkəsinə açır. VTY xətlərində ip access-group yox, access-class istifadə olunur.

show access-lists
show ip interface GigabitEthernet0/1 | include access list
show running-config | section access-list
clear access-list counters

Hər qaydanın yanında (N matches) sayğacı görünür — qaydanın işləyib-işləmədiyini yoxlamağın ən sürətli yolu.

5. Yerləşdirmə Qaydaları

Extended — mənbəyə yaxın: lazımsız trafik şəbəkədən keçmədən dayandırılır.

Standard — təyinata yaxın: yalnız mənbəni gördüyü üçün mənbəyə yaxın qoyulsa, digər təyinatlara da girişi kəsər.

Uzaq router-də ACL dəyişikliyi: əvvəl reload in 10 — özünüzü kilidləsəniz, router 10 dəqiqəyə köhnə konfiqurasiyaya qayıdacaq.

Remark yazın: remark Qonaq VLAN-ı serverlərə bağlıdır — 1 il sonra qaydanın niyə olduğunu biləcəksiniz.

Məqsəd

Tələblərə uyğun ACL yazmaq, düzgün interfeys və istiqamətə tətbiq etmək və hər qaydanı sınaqdan keçirmək.

Alət

Cisco Packet Tracer

Müddət

50 dəq · Orta

Topologiya

 VLAN 10 İşçilər 192.168.10.0/24 --\
 VLAN 20 Qonaq   192.168.20.0/24 --- R1 (router-on-a-stick) --- (Gi0/1) Server-LAN 10.0.0.0/24
 VLAN 99 Admin   192.168.99.0/24 --/                               Web 10.0.0.10, DNS 10.0.0.53

Tapşırıqlar

  1. Tələb 1: Qonaq şəbəkəsi Server-LAN-a heç çıxmasın, yalnız DNS (UDP 53) istifadə edə bilsin.

  2. Tələb 2: İşçilər Web serverə yalnız HTTP/HTTPS ilə çatsın, ping icazəlidir.

  3. Tələb 3: Router-ə SSH yalnız Admin VLAN-dan.

  4. Hər tələb üçün ACL növünü, adını, interfeysi və istiqaməti planlaşdırın (mənbəyə yaxın).

  5. Named extended ACL-lər yazın, qaydaları remark ilə izah edin və tətbiq edin.

  6. Hər qaydanı PC-lərdən sınayın və show access-lists-də match sayğaclarını izləyin.

Yoxlama

show access-lists
show ip interface gi0/0.20 | include access list
show running-config | section access-list

Uğur meyarları

Qonaq PC-dən web server açılmır, DNS sorğusu işləyir.

İşçi PC-dən web açılır, FTP/Telnet bloklanır.

Yalnız Admin VLAN-dan SSH mümkündür.

Həll — əvvəlcə özünüz cəhd edin 
ip access-list extended GUEST-IN
 remark Qonaq: yalniz DNS, server LAN-a qalan hec ne
 permit udp 192.168.20.0 0.0.0.255 host 10.0.0.53 eq 53
 deny   ip 192.168.20.0 0.0.0.255 10.0.0.0 0.0.0.255
 permit ip 192.168.20.0 0.0.0.255 any
ip access-list extended STAFF-IN
 permit tcp 192.168.10.0 0.0.0.255 host 10.0.0.10 eq 80
 permit tcp 192.168.10.0 0.0.0.255 host 10.0.0.10 eq 443
 permit icmp 192.168.10.0 0.0.0.255 10.0.0.0 0.0.0.255
 permit udp 192.168.10.0 0.0.0.255 host 10.0.0.53 eq 53
 deny   ip 192.168.10.0 0.0.0.255 10.0.0.0 0.0.0.255
 permit ip 192.168.10.0 0.0.0.255 any
ip access-list standard MGMT
 permit 192.168.99.0 0.0.0.255
interface gi0/0.20
 ip access-group GUEST-IN in
interface gi0/0.10
 ip access-group STAFF-IN in
line vty 0 4
 access-class MGMT in
