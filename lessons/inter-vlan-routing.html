Giriş: VLAN-lar Arası Əlaqə

Hər VLAN ayrıca broadcast domeni və ayrıca IP alt şəbəkəsidir. Switch Layer 2-də VLAN-ları bir-birindən təcrid edir, ona görə VLAN 10-dakı kompüter VLAN 20-dəki printerə birbaşa çata bilməz. Onları əlaqələndirmək üçün Layer 3 cihaz — router və ya multilayer switch — lazımdır.

2. Router-on-a-stick

Switch-in router-ə baxan portu trunk olur. Router-də fiziki interfeys subinterfeyslərə bölünür; hər subinterfeys bir VLAN-ın defolt gateway-idir. 

Router(config)# interface GigabitEthernet0/0
Router(config-if)# no shutdown

Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0

Router(config)# interface GigabitEthernet0/0.99
Router(config-subif)# encapsulation dot1Q 99 native
Router(config-subif)# ip address 192.168.99.1 255.255.255.0

Fiziki interfeys "no shutdown" olmalıdır, IP ünvanı isə yalnız subinterfeyslərə verilir. "native" açar sözü switch-dəki native VLAN ilə uyğun olmalıdır.

Switch(config)# vlan 10
Switch(config-vlan)# name Satis
Switch(config)# vlan 20
Switch(config-vlan)# name Muhasibat

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# switchport trunk allowed vlan 10,20,99

Switch(config)# interface FastEthernet0/5
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

Router-ə gedən port trunk, istifadəçi portları isə access. Hostların defolt gateway-i müvafiq subinterfeysin IP-si olmalıdır (məs. 192.168.10.1).

3. Layer 3 Switch və SVI

SVI

interface vlan 10 — VLAN üçün virtual L3 interfeys. Həmin VLAN-dakı hostların gateway-i olur.

Routed port

no switchport — fiziki portu router portuna çevirir (məs. router və ya firewall-a uplink).

ip routing

L3 switch-də marşrutlaşdırma defolt olaraq sönülüdür — bu əmr olmadan SVI-lər arasında paket ötürülmür.

Switch(config)# ip routing

Switch(config)# interface vlan 10
Switch(config-if)# ip address 192.168.10.1 255.255.255.0
Switch(config-if)# no shutdown

Switch(config)# interface vlan 20
Switch(config-if)# ip address 192.168.20.1 255.255.255.0
Switch(config-if)# no shutdown

Switch(config)# interface GigabitEthernet0/24
Switch(config-if)# no switchport
Switch(config-if)# ip address 10.0.0.2 255.255.255.252
Switch(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.1

Marşrutlaşdırmanı aktivləşdirir, VLAN 10 və 20 üçün SVI yaradır, Gi0/24-ü routed porta çevirib kənar router-ə defolt marşrut verir.

show ip interface brief
show ip route
show interfaces trunk
show vlan brief
show interfaces GigabitEthernet0/0.10

SVI/subinterfeyslərin up/up olması, connected marşrutlar, trunk-da VLAN-ların icazəli olması və subinterfeysin VLAN teqi.

4. Tez-tez Rast Gəlinən Problemlər

SVI down/down: VLAN yaradılmayıb və ya həmin VLAN-da heç bir aktiv port yoxdur.

Trunk qalxmayıb: switch portu access-də qalıb və ya VLAN "allowed" siyahısında deyil.

Səhv teq: encapsulation dot1Q nömrəsi VLAN ID ilə uyğun gəlmir.

Hostda səhv gateway: PC-nin defolt gateway-i subinterfeys/SVI IP-si deyil.

ip routing yoxdur: L3 switch-də VLAN-lar öz gateway-inə ping atır, amma bir-birinə çatmır.

Fiziki interfeys sönülüdür: router-də Gi0/0 "shutdown"-dadırsa bütün subinterfeyslər də down olur.

Lab: Router-on-a-Stick və Layer 3 Switch

Məqsəd

VLAN-lar arası marşrutlaşdırmanı əvvəlcə router subinterfeysləri, sonra L3 switch SVI-ləri ilə qurmaq.

Alət

Cisco Packet Tracer (2911 router, 3650 multilayer switch)

Müddət

50 dəq · Orta

Topologiya

Hissə A:  PC10 --\
                  SW1 (Gi0/1) ==trunk== (Gi0/0) R1
          PC20 --/

Hissə B:  PC10 --\
                  SW-L3 (SVI Vlan10, Vlan20, ip routing)
          PC20 --/

Ünvanlama cədvəli

CihazInterfeysIP / maska
R1Gi0/0.10192.168.10.1 /24
R1Gi0/0.20192.168.20.1 /24
PC10NIC192.168.10.10 /24, gw .1
PC20NIC192.168.20.10 /24, gw .1

Tapşırıqlar

  1. A: SW1-də VLAN 10, 20, access portlar və router-ə trunk qurun.

  2. R1-də Gi0/0.10 və Gi0/0.20 subinterfeysləri yaradın, encapsulation dot1Q və IP ünvanlar verin; fiziki interfeysi no shutdown.

  3. PC10 → PC20 ping edin; show ip route-da iki connected şəbəkəni göstərin.

  4. B: Eyni tapşırığı L3 switch-də SVI-lərlə edin: ip routing, interface vlan 10/20.

  5. İki üsulu müqayisə edin: performans, tək nöqtəli nasazlıq, miqyas.

Yoxlama

R1# show ip interface brief
R1# show interfaces gi0/0.10
R1# show ip route connected
SW-L3# show ip route
SW-L3# show interfaces vlan 10

Uğur meyarları

Hər iki üsulda VLAN-lar arası ping uğurludur.

Subinterfeys üçün encapsulation dot1Q VLAN nömrəsi switch-dəki VLAN-la eynidir.

L3 switch-də ip routing olmadan SVI-lər arasında marşrutlaşdırma olmur.

Həll — əvvəlcə özünüz cəhd edin

R1(config)# interface gi0/0
R1(config-if)# no shutdown
R1(config)# interface gi0/0.10
R1(config-subif)# encapsulation dot1Q 10

R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0
SW1(config)# interface gi0/1
SW1(config-if)# switchport mode trunk
! Hissə B
SW-L3(config)# ip routing
SW-L3(config)# interface vlan 10
SW-L3(config-if)# ip address 192.168.10.1 255.255.255.0
SW-L3(config-if)# no shutdown
SW-L3(config)# interface vlan 20
SW-L3(config-if)# ip address 192.168.20.1 255.255.255.0
SW-L3(config-if)# no shutdown
