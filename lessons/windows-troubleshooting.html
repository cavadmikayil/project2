2. "Kompüter Yavaşdır"

  1. Task Manager → Performance: hansı resurs 100%-dədir? Disk 100% və HDD-dirsə — SSD-yə keçid ən effektiv həlldir.

  2. Startup tabında lazımsız proqramları söndürün.

  3. Boş disk yeri: C: 10–15%-dən az olmasın — cleanmgr, Storage Sense.

  4. Antivirus tam skanı; brauzerdə şübhəli extension-lar.

  5. Uptime-a baxın — kompüter 40 gündür yenidən başladılmayıbsa, restart çox şeyi həll edir.

systeminfo | findstr /i "Boot Time Memory"
wmic diskdrive get model,status
Get-PhysicalDisk | Select FriendlyName, MediaType, HealthStatus
Get-Process | Sort-Object CPU -Descending | Select -First 10

3. Sistem Fayllarının Bərpası

Qəribə xətalar, açılmayan Windows komponentləri və yeniləmə xətalarında sistem faylları zədələnmiş ola bilər. Əmrlər administrator terminalında və bu ardıcıllıqla icra olunur:

DISM /Online /Cleanup-Image /CheckHealth
DISM /Online /Cleanup-Image /ScanHealth
DISM /Online /Cleanup-Image /RestoreHealth   # komponent anbarını Windows Update-dən bərpa edir
sfc /scannow                                 # sistem fayllarını anbardan bərpa edir

chkdsk C: /scan                              # fayl sistemi xətaları (onlayn yoxlama)

# Windows Update keşini sıfırlamaq
net stop wuauserv & net stop bits
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
net start wuauserv & net start bits

Əvvəl DISM, sonra SFC: SFC faylları komponent anbarından götürür — anbar zədəlidirsə, SFC bərpa edə bilmir.

4. Windows Açılmır / Mavi Ekran (BSOD)

VəziyyətAddım
Yeniləmədən sonra açılmırWinRE → Troubleshoot → Uninstall Updates / System Restore
Yeni driver-dən sonra BSODSafe Mode → Device Manager → Roll Back Driver
Təsadüfi BSOD-larStop code-u yazın (məs. MEMORY_MANAGEMENT → RAM testi: mdsched)
"No bootable device"BIOS-da boot ardıcıllığı, disk görünürmü, SATA/NVMe rejimi
BitLocker recovery key soruşurAçarı AD/Entra ID və ya Microsoft hesabından tapın — heç vaxt diski formatlamayın

WinRE-yə girmək: açılış zamanı üç dəfə ardıcıl kəsilmə və ya Shift + Restart. Oradan Safe Mode, Command Prompt, Startup Repair və System Restore əlçatandır.
