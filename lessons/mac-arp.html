Giriş: İki Ünvan, İki Vəzifə

Hər host iki ünvandan istifadə edir: IP ünvanı (Layer 3) paketin son təyinatını, MAC ünvanı (Layer 2) isə çərçivənin eyni seqmentdə növbəti hansı cihaza çatacağını göstərir. Bu ikisini bir-birinə bağlayan protokol ARP-dır.

1. MAC Ünvanının Quruluşu

MAC:  00:1A:2B : 3C:4D:5E      (48 bit = 12 hex rəqəm)
      └─ OUI ─┘ └─ NIC ─┘
      istehsalçı   cihaza məxsus hissə

Cisco yazılışı:  001a.2b3c.4d5e
Windows:         00-1A-2B-3C-4D-5E
Linux:           00:1a:2b:3c:4d:5e

Unicast

Tək bir cihaza. Birinci baytın ən kiçik biti 0-dır.

Broadcast

FF:FF:FF:FF:FF:FF — seqmentdəki bütün cihazlara.

Multicast

Qrupa (məs. 01:00:5E:xx:xx:xx — IPv4 multicast, 33:33:xx… — IPv6).

2. ARP Necə İşləyir?

PC1 (192.168.1.10) eyni şəbəkədəki PC2-yə (192.168.1.20) ping atır, amma PC2-nin MAC ünvanını bilmir:

  1. PC1 öz ARP cədvəlinə baxır — qeyd yoxdur.

  2. ARP Request göndərir: "192.168.1.20 kimdir? 192.168.1.10-a cavab ver". Təyinat MAC — FF:FF:FF:FF:FF:FF (broadcast).

  3. Switch broadcast-ı VLAN-dakı bütün portlara göndərir (flood). Yalnız PC2 cavab verir.

  4. ARP Reply birbaşa PC1-ə gedir (unicast): "192.168.1.20 = 00:1A:2B:3C:4D:5E".

  5. PC1 bu cütü ARP cədvəlinə yazır və ICMP paketini göndərir.

Gratuitous ARP: cihaz heç kim soruşmadan öz IP–MAC cütünü elan edir (məs. IP konflikti yoxlamaq və ya HSRP keçidindən sonra switch-lərin cədvəlini yeniləmək üçün).

3. Uzaq Şəbəkəyə Göndərəndə Nə Dəyişir?

Təyinat başqa şəbəkədədirsə host defolt gateway-in MAC ünvanını ARP ilə tapır. Hər hop-da MAC ünvanları dəyişir, IP ünvanları isə (NAT olmadıqca) eyni qalır.

R1 → R2R1 Gi0/1R2 Gi0/1192.168.1.1010.2.2.50

4. Praktiki Əmrlər

show arp
show ip arp 192.168.1.20
show mac address-table dynamic
show interfaces GigabitEthernet0/0 | include address
clear arp-cache
R1(config)# arp 192.168.1.50 0011.2233.4455 arpa

Router-in ARP cədvəli (Age "-" = öz interfeysi), switch-in MAC cədvəli, interfeysin öz MAC-ı, ARP keşinin təmizlənməsi və statik ARP qeydi.

arp -a
arp -d *
ipconfig /all
ip neigh show

Windows-da ARP cədvəli və onun təmizlənməsi (admin hüququ lazımdır), kartın MAC ünvanı ("Physical Address") və Linux-da qonşu cədvəli.
