Giriş: Hər VLAN-ın Rolu Var

VLAN-lar yalnız şöbələri ayırmaq üçün deyil. Yaxşı dizayn edilmiş şəbəkədə istifadəçi, idarəetmə, səs və istifadə olunmayan portlar üçün ayrıca VLAN-lar olur. Bu dərsdə hər birinin məqsədini və IP telefonların Voice VLAN ilə necə qoşulduğunu öyrənəcəksiniz.

Normal diapazon VLAN-lar 1–1005 (vlan.dat faylında saxlanılır), genişləndirilmiş diapazon 1006–4094. VLAN 1 və 1002–1005 silinə bilməz.

2. Native VLAN və VLAN Hopping

802.1Q trunk-da native VLAN-ın çərçivələri teqsiz göndərilir. İki tərəfdə native VLAN fərqlidirsə, trafik yanlış VLAN-a düşür və CDP "native VLAN mismatch" xəbərdarlığı verir.

Double tagging hücumu

Hücumçu native VLAN-dadırsa, iki teqli çərçivə göndərir: birinci switch xarici teqi silir, ikinci switch daxili teqə görə çərçivəni hədəf VLAN-a ötürür.

Müdafiə

Native VLAN-ı heç bir hostun olmadığı VLAN-a dəyişin, DTP-ni söndürün (switchport nonegotiate) və ya native VLAN-ı da teqləyin (vlan dot1q tag native).

3. Voice VLAN

IP telefonun daxilində kiçik 3 portlu switch var: bir port divara (switch-ə), biri kompüterə, biri isə telefonun özünə. Beləliklə, bir kabel həm telefonu, həm kompüteri qoşur. 

          Switch Fa0/5 (access VLAN 10, voice VLAN 110)
                       │
                  ┌────┴─────┐
                  │ IP telefon│ ── səs trafiki: VLAN 110 ilə teqlənir (CoS 5)
                  └────┬─────┘
                       │
                     PC  ── data trafiki: teqsiz → VLAN 10

Telefon voice VLAN ID-ni switch-dən CDP (və ya LLDP-MED) ilə öyrənir.

Səs çərçivələri 802.1p CoS 5 ilə işarələnir — QoS-da prioritet alır.

Port trunk deyil, access portdur — Cisco onu "multi-VLAN access port" adlandırır.

4. Praktiki Əmrlər

SW1(config)# vlan 10
SW1(config-vlan)# name DATA
SW1(config)# vlan 110
SW1(config-vlan)# name VOICE

SW1(config)# interface FastEthernet0/5
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10
SW1(config-if)# switchport voice vlan 110
SW1(config-if)# mls qos trust device cisco-phone
SW1(config-if)# mls qos trust cos
SW1(config-if)# spanning-tree portfast

PC-nin data trafiki VLAN 10-a, telefonun səsi VLAN 110-a düşür. QoS markalanmasına yalnız qarşıda Cisco telefonu olduqda etibar edilir (bu əmrlər Catalyst modelindən asılıdır).

SW1(config)# vlan 99
SW1(config-vlan)# name MGMT
SW1(config)# interface vlan 99
SW1(config-if)# ip address 192.168.99.11 255.255.255.0
SW1(config-if)# no shutdown
SW1(config)# ip default-gateway 192.168.99.1

SW1(config)# vlan 999
SW1(config-vlan)# name PARKING
SW1(config)# interface range FastEthernet0/20 - 24
SW1(config-if-range)# switchport mode access
SW1(config-if-range)# switchport access vlan 999
SW1(config-if-range)# shutdown

Switch-i idarə etmək üçün VLAN 99-da SVI və defolt gateway (L2 switch-də ip routing olmadığı üçün); istifadə olunmayan portlar parking VLAN-a köçürülüb söndürülür.

show vlan brief
show interfaces FastEthernet0/5 switchport
show interfaces trunk
show cdp neighbors detail

"Access Mode VLAN" və "Voice VLAN" dəyərləri, trunk-larda native VLAN, telefonun CDP məlumatı.
