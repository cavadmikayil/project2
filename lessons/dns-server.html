İnsanlar cavadmikayil.com yadda saxlayır, kompüterlər isə IP ünvanla işləyir. DNS adı IP-yə (və əksinə) çevirir. DNS işləməsə, internet "işləmir" kimi görünür — halbuki bağlantı var. Sorğular adətən UDP 53, böyük cavablar və zona transferi TCP 53 ilə gedir.

1. Ad Necə Həll Olunur?

  1. Brauzer və OS öz keşinə və hosts faylına baxır.

  2. Tapılmasa, sorğu recursive resolver-ə gedir (şirkət DNS serveri, provayder və ya 1.1.1.1/8.8.8.8).

  3. Resolver root server-dən soruşur: ".com-u kim bilir?" — cavab: .com TLD serverləri.

  4. TLD server: "cavadmikayil.com-u kim bilir?" — cavab: domenin authoritative serverləri (NS).

  5. Authoritative server A qeydini qaytarır. Resolver cavabı TTL müddəti qədər keşləyir və klientə verir.

Recursive

Klient adından bütün yolu gedib son cavabı gətirir və keşləyir.

Authoritative

Zonanın "sahibi" — qeydlər onda saxlanılır, cavabı qəti verir.

3. Zona Faylı Nümunəsi (BIND)

$TTL 3600
@   IN SOA ns1.example.az. admin.example.az. (
        2026092701 ; serial (YYYYMMDDnn) — hər dəyişiklikdə artır!
        3600       ; refresh
        900        ; retry
        1209600    ; expire
        300 )      ; negative cache TTL
    IN NS   ns1.example.az.
    IN NS   ns2.example.az.
    IN MX 10 mail.example.az.
ns1 IN A    203.0.113.2
ns2 IN A    198.51.100.2
@   IN A    203.0.113.10
www IN CNAME example.az.
mail IN A   203.0.113.20

Secondary serverlər dəyişikliyi serial nömrəsi artanda götürür. Serial-ı artırmağı unutmaq — "qeydi dəyişdim, amma ikinci serverdə köhnədir" probleminin ən çox rast gəlinən səbəbidir. Zonanı yoxlamaq: named-checkzone example.az db.example.az.

4. Diaqnostika Alətləri

dig example.az                 # A qeydi
dig example.az MX +short       # yalnız cavab
dig @8.8.8.8 example.az        # konkret serverdən soruş
dig +trace example.az          # root-dan başlayaraq bütün yol
dig -x 203.0.113.10            # reverse (PTR)
dig example.az SOA +short      # serial nömrəsini yoxla
nslookup example.az
nslookup -type=mx example.az 8.8.8.8
Resolve-DnsName example.az -Type TXT
ipconfig /displaydns      # klient keşi
ipconfig /flushdns        # keşi təmizlə
Get-DnsClientServerAddress   # hansı DNS serverlər istifadə olunur
