Şübhəli Fayllar üçün Təhlükəsiz Zona

Müəllimin qeydi · Cavad Mikayil

Heç olub ki, bir faylı yükləmisən və içinə şübhə düşüb?
"Görəsən virusdur?", "Bunu açsam sistemimə nəsə olar?" deyə düşündüyün anlar mütləq olub.

Məhz belə vəziyyətlər üçün Windows-un içində gizlənmiş əfsanəvi bir xüsusiyyət var: Windows Sandbox.

Bir kliklə təmiz Windows kompüteri: Windows Sandbox ilə tanış olaq.

Windows Sandbox Nədir?

Windows Sandbox-u kompüterinin içində açılan müvəqqəti, təhlükəsiz bir otaq kimi təsəvvür et.

  • Təmiz, yeni bir Windows mühiti açılır (sanki bir VM-dir).
  • İçində istədiyin proqramı quraşdıra bilərsən.
  • Şübhəli faylı rahatlıqla açıb test edə bilərsən.

Ən gözəl tərəfi isə budur ki, Sandbox-u bağladığın anda içində olan hər şey TAMAMİLƏ silinir. Yəni əsas sisteminə (Windows 11 OS) heç bir zərər dəymir, heç bir iz qalmır.

Sandbox nə üçün bu qədər faydalıdır? Nə verir bizə?

Gündəlik IT işləri görən mütəxəssislər, IT oxuyan tələbələr və ya sadəcə maraqlı adamlar üçün Sandbox əsl xilaskardır:

  • Naməlum .exe faylı yoxlamaq – vendor göndərib mail ilə.
  • Crack, portable proqramları test etmək – məsələn, crack AutoCAD.
  • Təlim üçün proqram qurub-silmək – dərs keçirsən, nəyisə göstərirsən.
  • Risk etmədən təcrübə aparmaq – məsələn, Kaspersky test edirik deyək.

Hamısı təhlükəsiz şəkildə.

Windows Sandbox Necə Aktiv Edilir?

Virtual maşınsız test mühiti: Sandbox standart olaraq (default) bağlı olur, amma aktiv etmək çox asandır:

  1. Axtarış yerinə Windows Features yaz.

  2. Açılan pəncərədə Windows Sandbox seçimini tap.

  3. Yanındakı quşu işarələ (buna checkbox deyilir).

  4. OK düyməsinə bas.

  5. Sonda kompüteri restart elə.

Restartdan sonra artıq hazırdır: Start menyusuna girib Windows Sandbox yazmağın kifayətdir.

İçinə girəndən sonra brauzerdən nəsə yükləyə bilərik, öz kompüterimizdən nəsə kopyalayıb yapışdıra bilərik və s.

Sandbox-un İstifadəsi Necədir?

Sandbox açıldıqda qarşına tam təmiz Windows masaüstü çıxır. Daha sonra:

  • Copy & Paste – proqramı kopyalayıb ora yapışdırırsan
  • Install app – proqramı quraşdırırsan
  • Run – test edirsən, baxırsan, yoxlayırsan

İşin bitdi? Pəncərəni bağladın — BİTDİ!

Sandbox bağlandısa:

  • Proqramlar silindi
  • Fayllar yox oldu
  • Virus varsa belə → əsas sistemə keçmədi

Sadə, sürətli, təhlükəsiz.

VirtualBox, Hyper-V və ya VMware Varkən Niyə Sandbox?

Deyə sual verdiyini hiss edirəm sanki :D

Əlbəttə ki, VirtualBox və VMware əla virtuallaşdırma həlləridir, o sözsüz.
Amma gündəlik kiçik testlər üçün Sandbox daha məntiqlidir, daha yaxşıdır. Sandbox-un üstünlükləri onlarla müqayisədə daha çoxdur.

Çünki Sandbox-da:

  • ISO yükləmək yoxdur, birbaşa Windows OS açılır.
  • Saatlarla VM qurmağa, lisenziya və s. şeylərə ehtiyac yoxdur.
  • Əlavə proqram install etmirsən, yerin dolmur.
  • 5 saniyəyə açılır, sürətli qoşulursan.
  • Ən əsası da sistemi yormur.

Ağır laboratoriyalar üçün VM

Məsələn, DC, File Server quraşdırırsınız deyək.

Sürətli testlər üçün Sandbox

Məsələn, crack-li bir proqram qurub yoxlamaq üçün.

Windows Sandbox — çoxlarının bilmədiyi, amma bir dəfə istifadə edəndən sonra vazkeçilməz olan bir xüsusiyyətdir. Windows-un gizli silahıdır: lazım oldu, çıxart vur, sonra qoy belinə, davam elə.

Əgər:

  • Təhlükəsiz test etmək istəyirsənsə
  • Sistemini riskə atmaq istəmirsənsə
  • Vaxta qənaət etmək istəyirsənsə

Windows Sandbox mütləq sənin üçün əla seçimdir.

Windows Sandbox-u Silmək (Deaktiv Etmək)

  1. Axtarışa Windows Features yaz və aç.

  2. Siyahıdan Windows Sandbox seçimini tap.

  3. Quş işarəsini götür (disable).

  4. OK düyməsinə bas.

  5. Daha sonra kompüteri restart et.

Restartdan sonra Windows Sandbox deaktiv edilmiş (silinmiş) olacaq.
