Giriş: Model Necə Öyrənir?

Machine learning modeli nümunələrə baxıb giriş (features) ilə nəticə (label) arasındakı əlaqəni riyazi funksiya kimi öyrənir. Sonra görmədiyi yeni məlumat üçün proqnoz verir. Bu dərsdə nümunə: şəbəkə girişinin normal və ya şübhəli olduğunu təsnif edən model.

1. ML Layihəsinin İş Axını

  1. Problemi müəyyən et: təsnifat (spam/normal), regressiya (qiymət, disk dolma tarixi), klasterləşdirmə?

  2. Məlumat topla: log-lar, cədvəllər, tarixi hadisələr.

  3. Təmizlə və hazırla: boş dəyərlər, təkrarlar, feature-lərin seçilməsi.

  4. Böl: train / validation / test.

  5. Öyrət (train) və parametrləri tənzimlə.

  6. Qiymətləndir — yalnız test dəstində.

  7. Yerləşdir və izlə: zamanla dəqiqlik düşə bilər (data drift).

2. Features və Labels

Feature engineering: xam log-dan mənalı sütunlar çıxarmaq çox vaxt alqoritm seçimindən daha vacibdir.

Balanssız məlumat: 10 000 normal, 20 şübhəli giriş — model "hamısı normaldır" deyib 99.8% dəqiqlik göstərə bilər, amma faydasızdır.

3. Train, Validation, Test

Bütün məlumat (100%)
├── Train (70%)       → model buradan öyrənir
├── Validation (15%)  → parametrləri tənzimləmək, modelləri müqayisə
└── Test (15%)        → yalnız sonda, bir dəfə — real performans

Data leakage: test məlumatı hər hansı yolla öyrənməyə qarışarsa (məs. eyni istifadəçinin qeydləri hər iki dəstdə), nəticələr real olduğundan yaxşı görünür və istehsalatda model uğursuz olur. Zaman sıralı məlumatda test dəsti həmişə sonrakı dövrdən olmalıdır.

4. Overfitting və Underfitting

Underfitting

Model çox sadədir, qanunauyğunluğu tuta bilmir — həm train, həm test nəticəsi zəifdir.

Yaxşı uyğunluq

Train və test nəticələri yaxındır və yüksəkdir.

Overfitting

Model nümunələri "əzbərləyib": train-də 99%, test-də 70%. Həll: daha çox məlumat, sadə model, regularization, cross-validation.

6. Python ilə İlk Model (scikit-learn)

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

df = pd.read_csv("logins.csv")          # saat, failed, new_country, new_device, label
X = df[["saat", "failed", "new_country", "new_device"]]
y = df["label"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

model = RandomForestClassifier(n_estimators=200, class_weight="balanced", random_state=42)
model.fit(X_train, y_train)

print(classification_report(y_test, model.predict(X_test)))
print(model.predict([[3, 15, 1, 1]]))   # yeni giriş üçün proqnoz

stratify=y — hər iki dəstdə sinif nisbəti eyni qalır; class_weight="balanced" — nadir sinfə (şübhəli) daha çox çəki verir. Quraşdırma: pip install pandas scikit-learn.
