Giriş: Niyə Linux?

İnternetdəki serverlərin böyük əksəriyyəti Linux üzərində işləyir: veb serverlər, verilənlər bazaları, konteynerlər, bulud. Serverdə adətən qrafik interfeys olmur — hər şey terminal və SSH ilə idarə olunur.

Debian / Ubuntu

Paket meneceri apt. Ubuntu Server ən çox yayılan server distributivlərindəndir.

RHEL / Rocky / Alma

Paket meneceri dnf. Korporativ mühitdə geniş istifadə olunur.

LTS versiyalar

Serverdə uzunmüddətli dəstək (LTS) versiyası seçin — 5+ il təhlükəsizlik yeniləmələri.

1. Fayl Sistemi İerarxiyası

Linux-da disk hərfləri (C:, D:) yoxdur — hər şey / (root) qovluğundan başlayır.

QovluqNə saxlanılır
/etcKonfiqurasiya faylları (/etc/ssh/sshd_config, /etc/hosts)
/var/logLog faylları
/homeİstifadəçilərin şəxsi qovluqları
/rootroot istifadəçisinin qovluğu
/usr/bin, /usr/sbinProqramlar və admin əmrləri
/tmpMüvəqqəti fayllar (yenidən yüklənmədə silinə bilər)
/dev, /procCihazlar və kernel/proses məlumatı (virtual fayllar)

2. Gündəlik Əmrlər

pwd                      # hazırkı qovluq
ls -lah                  # gizli fayllar daxil, ətraflı siyahı
cd /var/log              # qovluğa keç
mkdir -p /srv/app/data   # iç-içə qovluq yarat
cp -r src/ backup/       # qovluğu kopyala
mv old.txt new.txt       # yerini/adını dəyiş
rm -r tmpdir/            # sil (geri qaytarmaq olmur!)
du -sh /var/*            # qovluqların həcmi
df -h                    # disk bölmələrində boş yer
cat /etc/os-release           # faylı göstər
less /var/log/syslog          # səhifə-səhifə oxu (q — çıxış)
tail -f /var/log/nginx/error.log   # faylın sonunu canlı izlə
grep -i "error" app.log       # sətirlərdə axtar
grep -r "listen" /etc/nginx/  # qovluqda rekursiv axtar
find / -name "*.conf" -mtime -1 2>/dev/null   # son 1 gündə dəyişən .conf fayllar
nano /etc/hosts               # sadə redaktor
uname -a        # kernel versiyası
uptime          # nə qədər işləyir və yük ortalaması
free -h         # RAM istifadəsi
top             # və ya htop — canlı proses siyahısı
ps aux | grep nginx   # prosesi tap
kill -15 1234   # prosesə düzgün bağlanma siqnalı (SIGTERM)
ip a            # IP ünvanlar
ss -tulpn       # dinlənilən portlar və proseslər

ss -tulpn — hansı xidmətin hansı portu dinlədiyini göstərir; "server işləyir, amma qoşulmaq olmur" problemlərində ilk baxılan əmrlərdəndir.

3. İstifadəçilər və sudo

Birbaşa root kimi işləmək təhlükəlidir. Adi istifadəçi yaradılır və admin əmrləri sudo ilə icra olunur — hər sudo əmri log-a yazılır.

sudo adduser aysel              # istifadəçi yarat (Debian/Ubuntu)
sudo usermod -aG sudo aysel     # sudo qrupuna əlavə et (RHEL-də: wheel)
sudo passwd aysel               # parolu dəyiş
id aysel                        # UID, GID və qruplar
sudo deluser aysel              # istifadəçini sil
getent passwd | tail -5         # son istifadəçilər (/etc/passwd)

4. Fayl İcazələri

ls -l nəticəsində -rwxr-x--- üç qrup icazəni göstərir: sahib (user), qrup (group), digərləri (others).

HərfRəqəmFayldaQovluqda
r4OxumaqSiyahını görmək
w2DəyişməkFayl yaratmaq/silmək
x1İcra etməkQovluğa daxil olmaq
 
chmod 640 config.env        # rw- r-- --- : sahib oxuyur/yazır, qrup oxuyur
chmod 750 deploy.sh         # rwx r-x --- : sahib icra edir, qrup oxuyur/icra edir
chmod u+x script.sh         # sahibə icra icazəsi əlavə et
chown www-data:www-data /var/www/site -R   # sahibi və qrupu dəyiş

Heç vaxt problem "həll etmək" üçün chmod 777 yazmayın — bu hər kəsə yazma icazəsi verir. Düzgün sahib və minimal icazə təyin edin.

5. Paket İdarəetməsi və Yeniləmələr

sudo apt update                 # paket siyahısını yenilə
sudo apt upgrade                # quraşdırılmış paketləri yenilə
sudo apt install nginx htop     # paket quraşdır
sudo apt remove nginx           # paketi sil
apt list --upgradable           # yenilənə bilən paketlər
sudo apt install unattended-upgrades   # avtomatik təhlükəsizlik yeniləmələri
sudo dnf check-update
sudo dnf upgrade
sudo dnf install nginx
sudo dnf remove nginx
sudo dnf install dnf-automatic   # avtomatik yeniləmələr

Yeniləmələri əvvəl test serverində yoxlayın, kernel yeniləməsindən sonra planlı vaxtda sudo reboot edin. /var/run/reboot-required faylı varsa, Ubuntu yenidən yükləmə tələb edir.
