Port Security

Giriş Violation Modları Əmrlər Portal

Giriş: Port Security Nədir?

Port Security — switch portuna qoşula bilən cihazların sayını və/və ya MAC ünvanlarını məhdudlaşdıran Layer 2 təhlükəsizlik funksiyasıdır. MAC flooding hücumlarının və icazəsiz cihazların şəbəkəyə qoşulmasının qarşısını almaq üçün istifadə olunur. Bir port üçün icazə verilən maksimum MAC sayı aşıldıqda, konfiqurasiya edilmiş "violation" rejiminə uyğun tədbir görülür.

1. Violation (Pozuntu) Rejimləri

Rejim Naməlum trafik Loglama Port statusu
Protect Atılır Yoxdur Aktiv qalır
Restrict Atılır SNMP/syslog xəbərdarlığı Aktiv qalır
Shutdown (defolt) Atılır SNMP/syslog xəbərdarlığı err-disabled olur

Sticky MAC: Dinamik öyrənilən MAC-ları avtomatik olaraq running-config-ə əlavə edir.

Errdisable Recovery: Shutdown rejimində düşən portu avtomatik bərpa etmək üçün istifadə olunur.

2. Praktiki Əmrlər

Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum 2
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security violation restrict

Switch(config)# errdisable recovery cause psecure-violation
Switch(config)# errdisable recovery interval 60

Portda maksimum 2 MAC ünvanına icazə verir, öyrənilən MAC-ları sticky olaraq saxlayır, pozuntu zamanı "restrict" rejimini tətbiq edir və shutdown olan portların 60 saniyə sonra avtomatik bərpasını təmin edir.

show port-security
show port-security interface FastEthernet0/1
show port-security address
show interface status err-disabled

Bütün portlarda port security statusunu, konkret bir interfeysin təfərrüatlarını, öyrənilmiş MAC ünvanlarını və err-disabled portları göstərir.
