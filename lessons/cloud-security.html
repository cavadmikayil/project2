Giriş: Bulud Özü-Özlüyündə Təhlükəsiz Deyil

AWS, Azure və Google Cloud infrastrukturu yüksək səviyyədə qoruyur. Amma bulud insidentlərinin böyük hissəsi provayderin yox, müştərinin konfiqurasiya səhvlərindən yaranır: hamıya açıq storage, həddən artıq icazəli hesablar, kodda unudulmuş açarlar.

2. IAM — Buludun Əsas Nəzarət Nöqtəsi

Root / Global Admin hesabı: güclü MFA, gündəlik işdə istifadə olunmur, açarları yoxdur.

Least privilege: *:* (hər şeyə icazə) siyasətlərindən qaçın; rolları konkret resurslara məhdudlaşdırın.

Uzunmüddətli access key-lərdən qaçın: VM-lər və tətbiqlər üçün role / managed identity istifadə edin.

Kodda sir yoxdur: açarlar Git-ə düşərsə, dəqiqələr içində avtomatik botlar tərəfindən tapılır — secrets manager / Key Vault.

// AWS IAM: yalnız bir bucket-dan oxumaq icazəsi (least privilege)
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:GetObject"],
    "Resource": "arn:aws:s3:::company-reports/*"
  }]
}

4. Bulud Şəbəkəsi

VPC / VNet 10.10.0.0/16
├── Public subnet  10.10.1.0/24   → Load balancer, (lazımdırsa) bastion
├── Private subnet 10.10.2.0/24   → Tətbiq serverləri (internetə yalnız NAT gateway ilə çıxış)
└── Data subnet    10.10.3.0/24   → Verilənlər bazası (yalnız tətbiq subnet-indən giriş)

Security Group / NSG: stateful firewall qaydaları — 0.0.0.0/0 üçün 22/3389 portlarını açmayın.

Admin girişi: SSM Session Manager, Azure Bastion və ya VPN — public IP-li RDP/SSH yox.

Private endpoint: PaaS xidmətlərinə (DB, storage) internetsiz, daxili şəbəkədən giriş.

6. Yeni Bulud Hesabı Üçün İlk 10 Addım

  1. Root/Global Admin-ə MFA; onu gündəlik istifadə etməmək.

  2. SSO ilə adlı istifadəçi hesabları; paylaşılan hesab yoxdur.

  3. Audit log-ları bütün regionlarda aktiv və ayrı hesabda saxlanılır.

  4. Storage üçün "block public access".

  5. Standart şifrələmə aktivdir.

  6. Təhdid aşkarlama xidməti açıqdır.

  7. Büdcə və anomaliya xəbərdarlıqları.

  8. İstifadə olunmayan regionları siyasətlə bağlamaq.

  9. Infrastructure as Code (Terraform/Bicep) — dəyişikliklər review ilə.

  10. Resurslara sahib (owner) və mühit (prod/test) teqləri.
