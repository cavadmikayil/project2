Giriş: Nə vaxt statik marşrut?

Statik marşrut administratorun əl ilə yazdığı marşrutdur. Router onu dəyişmir və qonşulara elan etmir. Kiçik şəbəkələrdə, tək çıxışlı (stub) filiallarda və internetə defolt çıxış üçün idealdır. İnzibati məsafəsi (AD) 1-dir, yəni dinamik protokollardan daha etibarlı sayılır.

Üstünlüklər

CPU/bant genişliyi sərf etmir, proqnozlaşdırıla biləndir, təhlükəsizdir (heç nə elan olunmur).

Çatışmazlıqlar

Topologiya dəyişəndə avtomatik uyğunlaşmır; böyük şəbəkələrdə idarə etmək çətindir.

1. Statik Marşrut Növləri

NövNümunəİzah
Standartip route 192.168.2.0 255.255.255.0 10.0.0.2Konkret uzaq şəbəkəyə yol
Defolt (default)ip route 0.0.0.0 0.0.0.0 203.0.113.1Cədvəldə uyğunluq olmayan bütün trafik (məs. internet)
Floating staticip route 0.0.0.0 0.0.0.0 198.51.100.1 5AD daha yüksəkdir — əsas marşrut itəndə ehtiyat kimi aktivləşir

Summaryip route 172.16.0.0 255.255.252.0 10.0.0.2172.16.0.0 – 172.16.3.0 şəbəkələrini bir sətirlə əhatə edir

Next-hop, çıxış interfeysi, yoxsa hər ikisi?

Next-hop IP: router next-hop-u tapmaq üçün cədvəldə ikinci axtarış edir (recursive lookup).

Çıxış interfeysi: point-to-point (serial) linklər üçün uyğundur; Ethernet-də tövsiyə olunmur (ARP yükü).

Fully specified: interfeys + next-hop — Ethernet üçün ən etibarlı variant.

2. Marşrut Cədvəlini Oxumaq

R1# show ip route
Codes: L - local, C - connected, S - static, O - OSPF, * - candidate default

Gateway of last resort is 203.0.113.1 to network 0.0.0.0

S*    0.0.0.0/0 [1/0] via 203.0.113.1
      10.0.0.0/8 is variably subnetted, 2 subnets, 2 masks
C        10.0.0.0/30 is directly connected, GigabitEthernet0/1
L        10.0.0.1/32 is directly connected, GigabitEthernet0/1
S     192.168.2.0/24 [1/0] via 10.0.0.2
                      ↑  ↑
                     AD  metrika

Longest prefix match: 192.168.2.50-yə gedən paket üçün həm 0.0.0.0/0, həm də 192.168.2.0/24 uyğundur — router həmişə ən uzun prefiksli (/24) marşrutu seçir. AD yalnız eyni prefiks müxtəlif mənbələrdən öyrənildikdə müqayisə olunur.

3. Praktiki Əmrlər

R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
R1(config)# ip route 192.168.3.0 255.255.255.0 GigabitEthernet0/1 10.0.0.2
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

Next-hop ilə standart marşrut, fully specified marşrut və internetə defolt marşrut.

R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
R1(config)# ip route 0.0.0.0 0.0.0.0 198.51.100.1 5

Əsas ISP (AD 1) işləyərkən ikinci marşrut cədvələ düşmür. Əsas link qopduqda AD 5 olan ehtiyat marşrut avtomatik aktivləşir.

R1(config)# ipv6 unicast-routing
R1(config)# ipv6 route 2001:db8:2::/64 2001:db8:ffff::2
R1(config)# ipv6 route ::/0 GigabitEthernet0/1 fe80::2

IPv6 statik marşrut və link-local next-hop ilə defolt marşrut (link-local istifadə olunduqda çıxış interfeysi mütləqdir).

show ip route static
show ip route 192.168.2.0
show ipv6 route static
ping 192.168.2.1
traceroute 192.168.2.1

Yalnız statik marşrutlar, konkret şəbəkə üçün seçilmiş marşrut, IPv6 statik marşrutlar və yolun yoxlanması.

Lab: Statik, Default və Floating Static Marşrut

Məqsəd

Filial ilə mərkəz arasında əsas və ehtiyat linki olan statik marşrutlaşdırma qurmaq.

Alət

Cisco Packet Tracer

Müddət

45 dəq · Orta

Topologiya

 LAN-B 192.168.2.0/24 --- BRANCH (Gi0/1) ---- 10.0.0.0/30 (əsas) ---- (Gi0/1) HQ --- LAN-HQ 192.168.1.0/24
                                 (Gi0/2) ---- 10.0.0.4/30 (ehtiyat) --- (Gi0/2)       \
                                                                                        ISP 203.0.113.0/30

Ünvanlama cədvəli

CihazInterfeysIP
BRANCHGi0/0 / Gi0/1 / Gi0/2192.168.2.1 · 10.0.0.1 /30 · 10.0.0.5 /30
HQGi0/0 / Gi0/1 / Gi0/2 / Gi0/3192.168.1.1 · 10.0.0.2 · 10.0.0.6 · 203.0.113.2 /30
ISPGi0/0203.0.113.1 /30 (+ Loopback 8.8.8.8/32)

Tapşırıqlar

  1. BRANCH-da HQ LAN-ı üçün statik marşrut (next-hop 10.0.0.2) və default route yazın.

  2. HQ-da BRANCH LAN-ı üçün marşrut və ISP-yə default route yazın; ISP-də hər iki LAN üçün marşrut (NAT olmadığından).

  3. BRANCH-da ehtiyat link üzərindən floating static marşrutlar (AD 200) əlavə edin; HQ-da da eyni.

  4. PC-B-dən 8.8.8.8-ə ping və traceroute edin.

  5. Əsas linki söndürün (BRANCH Gi0/1 shutdown). show ip route-da floating marşrutun aktivləşdiyini göstərin, ping davam etsin.

  6. Linki qaytarın və əsas marşrutun geri qayıtdığını təsdiqləyin.

Yoxlama

show ip route
show ip route static
show ip interface brief
traceroute 8.8.8.8

Uğur meyarları

Normal halda trafik 10.0.0.0/30 üzərindən gedir.

Əsas link kəsiləndə [200/0] marşrutu cədvələ düşür və trafik ehtiyat linkə keçir.

Qeyd: floating static yalnız interfeys down olanda işləyir — uzaqdakı nasazlığı görmək üçün IP SLA lazımdır.

Həll — əvvəlcə özünüz cəhd edin 
BRANCH(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.2
BRANCH(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
BRANCH(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.6 200
BRANCH(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.6 200
HQ(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.1
HQ(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.5 200
HQ(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
ISP(config)# ip route 192.168.0.0 255.255.252.0 203.0.113.2
