Giriş: Qalan Üç Domen

Network Operations (19%), Network Security (14%) və Network Troubleshooting (24%) birlikdə imtahanın yarısından çoxunu təşkil edir. Bu dərs şəbəkənin gündəlik istismarında lazım olan prosesləri, təhlükəsizlik anlayışlarını və alətləri əhatə edir.

1. Monitorinq

SNMP: v1/v2c (community string, açıq mətn), v3 (autentifikasiya + şifrələmə). Trap — cihazın özü göndərdiyi xəbərdarlıq (UDP 162).

Syslog səviyyələri: 0 Emergency, 1 Alert, 2 Critical, 3 Error, 4 Warning, 5 Notice, 6 Informational, 7 Debug.

NetFlow / sFlow: kim kiminlə nə qədər danışır — trafik analizi.

Baseline: normal vəziyyətin ölçüləri — anomaliyanı yalnız baseline ilə müqayisədə görmək olar.

Interfeys metrikaları: CRC, giants, runts, drops, utilization, errors.

SIEM: log-ların mərkəzləşdirilməsi və korrelyasiyası.

Active-active və active-passive klasterlər, NIC teaming, çoxlu ISP, tabletop exercise və DR testləri.

4. Şəbəkə Təhlükəsizliyi

Hücumlar: DoS/DDoS, VLAN hopping, MAC flooding, ARP poisoning, DNS spoofing, rogue DHCP, rogue AP, evil twin, on-path (MITM).

Müdafiə: port security, DHCP snooping, Dynamic ARP Inspection, 802.1X/NAC, BPDU guard, istifadə olunmayan portları söndürmək.

Seqmentasiya: VLAN, screened subnet (DMZ), IoT/OT və qonaq şəbəkəsi ayrı; zero trust — heç bir şəbəkəyə avtomatik etibar yoxdur.

AAA: RADIUS (UDP, yalnız parolu şifrələyir), TACACS+ (TCP 49, bütün paketi şifrələyir, əmr avtorizasiyası), SSO, MFA.
