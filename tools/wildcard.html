Wildcard Mask Kalkulyatoru

Subnet maska, CIDR və wildcard mask arasında çevirmə, ACL və OSPF sətirləri yaratmaq və bir IP ünvanının ACL qaydasına uyğun gəlib-gəlmədiyini yoxlamaq.

Çevirici

Prefiks

Subnet maska

Wildcard mask

Əhatə olunan aralıq

Wildcard bitləri: 0 = yoxla, 1 = fərqi yoxdur

Standart və genişləndirilmiş ACL, həmçinin OSPF network əmri eyni wildcard məntiqindən istifadə edir.

ACL Uyğunluq Testi

ACE-də yazılan ünvan və wildcard ilə yoxlanılan IP-ni daxil edin: router IP-nin wildcard-da 0 olan bitlərini müqayisə edir.

Yadda Saxla

Wildcard = 255.255.255.255 − maska. /20 → 255.255.240.0 → 0.0.15.255.

host 10.1.1.5 = 10.1.1.5 0.0.0.0; any = 0.0.0.0 255.255.255.255.

Wildcard bitləri ardıcıl olmaya da bilər: 10.1.0.1 0.0.254.0 — tək üçüncü oktetli ünvanlar kimi xüsusi uyğunluqlar.
